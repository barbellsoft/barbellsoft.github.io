An AI chatbot said "image the drive first". Here is how to do it

Your USB stick says "You need to format the disk in drive E: before you can use it", and it has photos on it. So you asked ChatGPT, Gemini or Copilot what to do.

We asked two AI assistants that exact question in November 2026. Both gave sound advice:

  • Don't format the drive, and don't copy anything onto it.
  • Hold off on chkdsk until your files are safe.
  • Recover the files first and save them to another drive.
  • Only after that, format and test the stick. If it fails again, replace it.

One of them added the step that protects you most: make a sector-by-sector image of the drive first, and recover from that copy instead of the stick itself. Neither said how to make that image on a normal Windows PC. That is what this post covers.

Why the order matters

The drive is usually not dead. Windows just can't read the index that says where each file lives. The files themselves are normally still on the drive, until something writes over them.

Everything on the "don't do it yet" list writes to the drive:

  • Formatting builds a new, empty file table. Microsoft's documentation describes quick format as deleting the file table and root directory, which is exactly the map you need to get your files back with their names.
  • chkdsk /f changes the drive while it repairs. Microsoft notes that repairs on FAT drives (most USB sticks and SD cards) usually change the file allocation table and sometimes cause a loss of data.
  • diskpart clean removes the partition information, and clean all sets every sector to zero, which deletes everything.

Reading the drive is safe. An image is a sector-by-sector copy of the whole drive, made only by reading, so once you have it, the stick can fail completely and you still have something to recover from.

Making the image with ReviveUSB

ReviveUSB is a free Windows tool built around the order those answers describe: copy the drive, recover from the copy, and only then repair it. It runs on Windows 10 or 11 (64-bit), needs no installation, and needs administrator rights because it reads the disk directly.

You need free space on another drive as large as the stick. A 64 GB stick needs 64 GB free.

  1. Run ReviveUSB.exe, allow administrator rights, click Refresh and select your USB drive. The Filesystem column will probably say RAW.
  2. Click Back up to image and save the file, for example disk2.img, on your PC's own drive. ReviveUSB only reads the stick here. It skips regions it can't read so the copy doesn't stall, then offers to retry them sector by sector at the end.
  3. If the copy gets interrupted, click Back up to image again and pick the same file. It continues where it stopped.

Recovering from the image

  1. Click Recover files (names/paths), pick the image file and choose a folder on a healthy drive. This reads NTFS, FAT32 and exFAT, often even when Windows calls the drive RAW, and brings files back with their names and folders.
  2. If it finds nothing, click Recover files (signature) with the same image. It looks for photos, videos, PDFs and other files by their content. Names are lost this way, so files come back numbered.

Your recovered files go to your PC, never back onto the stick. ReviveUSB refuses to save them on the drive you are recovering.

Then repair the stick

Once your files are safe, the repair buttons (Full rebuild for a RAW drive, Format for a drive that still has a letter) wipe the stick and make it usable again. You confirm by typing, for example ERASE DISK 2. Then Test drive checks the free space. If the test fails, do what the chatbot said and replace it.

The full walkthrough, with what to do when the backup is very slow or the drive shows 0 bytes, is in our guide to the format message.

What a chatbot can't see

An AI assistant only knows what you tell it. It can't see whether the stick shows its real capacity, whether reads are failing, or whether the controller has dropped into a state where the drive shows up as "No Media" or 0 bytes. ReviveUSB checks those signs before it writes anything. If the drive looks like it is failing, it won't repair it and says so in the log.

If the stick shows 0 bytes or disappears and doesn't come back after you replug it, no software can read it. A professional data recovery service is the remaining option, and recovery is never guaranteed.
