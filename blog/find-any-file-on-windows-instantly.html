Find a file you just saved or downloaded on Windows

You clicked Save, or a download finished, and a minute later you have no idea where the file went. Now you're opening Documents, Desktop and Downloads one after another.

It happens to everyone. Many programs save to whatever folder you used last time, so a file can land in a place you haven't opened for weeks. This post covers the quick places to check first, and then how to find any file on your PC by a piece of its name with Chatda, a free search app for Windows 10 and 11 that also runs on macOS.

Check the usual places first

Start with the Downloads folder. Web browsers save there unless someone changed the setting. Open it in File Explorer and click the Date modified column header until the newest files are at the top.

Your browser's download list is the next stop, since it can open the folder that holds each file. File Explorer's start page (Home or Quick access, depending on your version of Windows) also lists recent files.

If none of that turns it up, you need a search. The search box in File Explorer only looks inside the folder you have open and the folders below it, so you have to guess where to start, and outside your own user folders it can be slow.

Let a search app keep a list of every file

Chatda keeps a list of the files on your drives, so a search doesn't have to walk through folders while you wait.

Download it from the download page and install it. Installing asks for administrator approval because Chatda installs for all users together with its drive indexing service. Chatda isn't code-signed yet, so Windows SmartScreen may say it doesn't recognize the app. The download page lists the file's SHA-256 checksum so you can check it first. If it matches, choose More info, then Run anyway.

You don't have to choose any folders. On Windows, Chatda adds every fixed drive (C:\, D:\ and so on) by itself and reads the names, sizes and dates of the files on it. If you click Yes when Chatda asks for administrator rights, it reads the NTFS file table directly, and a drive with 2 million files takes about 10 to 20 seconds. The fast drive indexing service does the same without asking each time. Without administrator rights it goes through the folders one by one, which takes a few minutes. The status bar at the bottom shows Reading disk list with a percentage and the time left. Chatda saves the list, so the next time it starts the list is back in a second or two.

Show the newest files first

Leave the search box empty. Chatda then lists every file it knows about, with the most recently modified at the top. A file you saved a minute ago is usually in the first few lines, and the Path column tells you which folder it's in.

You don't need to refresh anything for that to work. Chatda notices files being added, changed and deleted while it runs, and new and downloaded files show up in search within seconds, even on large drives.

When the list is busy, set the Date dropdown to Today. A file copied from a USB stick or another computer may keep the date it was last edited there, which can be weeks old. For those, choose Recently created in the Sort dropdown, which puts the newest arrivals on your PC at the top.

Search by any part of the name

If you remember part of the name, type it. Results appear as you type, usually within 0.2 seconds, and you don't need to press Enter. Words can match the middle of a name, so port finds report, and folders show up in the results as well.

Short searches work better than long ones. invoice 2026 finds more than a full file name you're only half sure of. If you know the type of file, add it: *.pdf lists PDF files, and invoice *.pdf narrows that to PDFs that match "invoice". Typing dm:today after your words keeps only files modified today.

Use the file from the results

Once you've found the file, you can work with it from the results. Double-click to open it. Ctrl+Enter shows it in File Explorer. Drag it into an email, a chat or a folder to copy it there. F2 renames it, and Del moves it to the trash after asking you first. If you change your mind, Ctrl+Z brings it back.

Keep it one shortcut away

Closing the Chatda window doesn't quit the app. It stays in the tray and keeps its list up to date. The next time a file goes missing, press Ctrl+Shift+Space in any app and the window pops up with the cursor in the search box. Press it again to hide it. If you turn on Start at login in ⚙ Settings, Chatda starts in the tray when you sign in, without opening a window.

When the file still doesn't show up

Go through these in order:

  1. Was it saved to a USB stick, an external disk or a network drive? Chatda adds fixed drives by itself, but not those. When you connect one, Chatda asks whether to add it to search. You can also add it later from All locations ▾ with + Add folder, or Connect network folder for a NAS. Changes on a NAS can take up to five minutes to show up.
  2. Is a filter still on? Active date, type, folder and search-in filters appear as chips in the status bar. Click a chip to clear it. In All locations ▾, choose All folders so you're not searching just one folder.
  3. Is it inside a developer folder or a dot file? Whole-drive indexing skips folders such as node_modules and .git, and files whose names start with a dot. To include them, turn on Include developer folders … (all files) under ⚙ Settings → Exclude from index.
  4. Was Chatda closed when you saved it? With the fast drive indexing service installed, Chatda catches up on files that changed while it was closed. Without it, choose Re-index from the drive's menu in All locations ▾.
  5. Do you remember what's in it rather than its name? For a whole drive, Chatda keeps only names, sizes and dates. Add the folder where the file probably is with + Add folder, and Chatda also reads the text inside PDF, Word, Excel, PowerPoint, HWPX, TXT, Markdown and CSV files there.

On a Mac, Chatda doesn't add whole drives by itself. Add the folders you work in, such as Downloads and Documents, with + Add folder, and the rest works the same way. The shortcut is ⌘+⇧+Space.
