Find which Word, Excel or PowerPoint file contains a word

You remember a sentence. Maybe it was a client's name, a product code or a phrase from a proposal. You don't remember the file name, and there are forty reports, spreadsheets and slide decks in the folder where it probably lives. So you start opening them one at a time and pressing Ctrl+F in each.

That works, but it's slow, and it gets worse when the folder sits on a NAS or the files have names like final_v3.docx. There is a faster way, and the part people usually miss is that a file's name and its contents are two separate things to search.

Why a normal file search often misses it

Most file searches start from the name. If you type Henderson and the word only appears on page 4 of proposal_draft.docx, a name search has nothing to match. To find it, a program has to open each document ahead of time, pull out its text and keep that text in an index it can look up quickly.

Word, Excel and PowerPoint files saved in the current formats (DOCX, XLSX and PPTX) store their text in a way a search program can read without opening Office. Older files saved as .doc, .xls or .ppt use a different format, and many search tools, including the one below, only match those by name.

A few safe habits before you search

None of this needs special software, but it saves time either way.

Think of the most unusual word you remember. A surname, a part number or an invoice code turns up far fewer results than "report" or "budget".

Search for a short piece rather than the whole sentence. You may remember the phrase slightly differently from how it was typed.

If you have a rough idea of the folder or the year, keep it in mind. Narrowing by folder or date is often what turns 200 results into 3.

If the files are old .doc, .xls or .ppt, opening one in Office and saving it as .docx, .xlsx or .pptx makes its text searchable. Keep the original until you're sure the copy is fine.

How to do it with Chatda

Chatda is a free search program for Windows and macOS. It finds files on your PC, external drives and network folders by name and by the text inside documents. It reads the contents of TXT, MD, CSV, DOCX, XLSX, PPTX, PDF and HWPX files.

1. Add the folder where the documents are

This is the step that decides whether content search works. On Windows, Chatda indexes every fixed drive (C:\, D:\ and so on) by itself, but for a whole drive only file names, sizes and dates are searchable. Your Desktop and Downloads folders are added once automatically, so documents there are searched by content.

For anything else, such as Documents or a project folder, click All locations ▾, then + Add folder, and choose the folder. Indexing starts on its own, and the status bar at the bottom shows progress. For a NAS, use Connect network folder in the same panel and enter the address, username and password.

2. Switch the search to Content only

In the filter bar, open the Search in dropdown and pick Content only. The default, Name + content, also works, but Content only leaves out files that match by name, so you see only documents that have the word inside them.

3. Type the word

Results appear as you type, without pressing Enter. Each line shows the file name, its folder and a Content column with the passage where your word appears, so you can often tell which file it is without opening anything.

If you remember an exact phrase, put it in quotes: "payment statement" finds the words together and in that order. To find files that contain two words anywhere, type both: Henderson 2026.

4. Narrow it down if there are too many

Click All types ▾ and tick only DOCX, XLSX or PPTX. Use the Date dropdown if you know roughly when the file was changed. You can also type filters straight into the search box. For example, quote ext:xlsx dm:thismonth path:clients finds xlsx files under a "clients" folder, changed this month, that contain "quote".

5. Check before you open

Click a result once to open the preview panel on the right. For Word, Excel and PowerPoint files it shows the extracted text with your search words highlighted. Double-click to open the file in its usual app, or press Ctrl+Enter to show it in Explorer or Finder.

If it doesn't find the file

The file is old .doc, .xls or .ppt. Chatda reads contents only from the formats listed above. Other formats are found by name only. Save a copy in the newer format, or search for a word from the file name instead.

The folder was never added. If a file is covered only by a whole-drive entry like C:\, its contents aren't searched. Add its folder with + Add folder. If you've only added whole drives, Chatda shows a notice with an Add folder button above the results.

A filter is still on. Check the All types ▾ and Date dropdowns, and click All locations ▾, then All folders, so you aren't limited to one folder. Active filters appear as chips in the status bar; click one to clear it.

The file is brand new. In a local folder Chatda picks it up in about half a second. On a NAS it can take up to about 5 minutes. If you're in a hurry, choose Re-index from the folder menu (⋯ or right-click the folder).

Your search is too specific. Try a shorter word or a fragment. bottleneck finds more than approval bottleneck.

The document is a scan. If the "text" in a file is really a picture of a page, there is no text for any search to read. That is common with scanned PDFs pasted into Word.

It installs for all users and asks for administrator approval. On a Mac, the first launch may say it can't be opened; the download page explains how to allow it.
