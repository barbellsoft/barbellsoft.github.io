How to recover deleted files from a USB flash drive

You deleted a folder from a USB stick, opened the Recycle Bin to restore it, and it isn't there. That's normal. Windows doesn't send files deleted from a USB flash drive to the Recycle Bin. They are deleted right away, the same as Shift+Delete on any drive.

That doesn't mean the files are gone. In most cases they are still on the drive, and what you do next decides how much of them comes back.

What deleting a file really does

A drive keeps an index, the filesystem, that records which file is stored where and under what name. When you delete a file, the data itself usually stays on the drive. Only the index entry that points to it is removed, which is why recovery is possible at all.

The catch is that the space your file occupies now counts as free. If you save a new file to the drive, Windows may write it right on top of the old data, and once that happens the old data can't be recovered. The more you write to the drive after deleting, the less you get back.

What to do right now

Don't save or copy anything to the drive until your files are somewhere safe. That includes the recovery program and the files you recover. Don't format it either, and if Windows offers to scan and repair the drive, don't click Yes.

Reading from the drive is fine. If you aren't ready to start yet, eject it and leave it unplugged so nothing writes to it in the meantime.

Getting the files back with ReviveUSB

ReviveUSB is a free Windows program that works in a fixed order: it copies the whole drive to an image file first, then recovers files from that copy. Backing up and recovering only read the drive. It runs on Windows 10 or 11 (64-bit), is a single exe with nothing to install, and needs administrator rights because it reads the disk directly.

The image is a full copy, so you need free space on another drive as large as the USB drive. A 128 GB drive needs 128 GB free. The recovered files need room too, on any drive except the USB one.

ReviveUSB isn't code-signed yet, so Windows SmartScreen or your antivirus may warn you. The download page shows the file's SHA-256. Check it in PowerShell with Get-FileHash .\ReviveUSB.exe -Algorithm SHA256, and if the values match, choose More info, then Run anyway. Save the download to your PC, not to the USB drive.

1. Select the drive

Run ReviveUSB.exe and allow administrator rights. The top of the window should say Administrator: ON. If it says OFF, click Restart as administrator. Plug in the USB drive, click Refresh, and click your drive in the list. Only USB disks are listed, so your internal disks stay out of the way.

2. Back up to an image

Click Back up to image and save the image on another drive with enough free space. The suggested name is diskN.img, where N is the disk number. If you pick a place on the USB drive itself, ReviveUSB refuses and asks for a different drive, because saving there could overwrite the files you want back.

You can close the window at any time. To continue later, start the program again, select the same drive, click Back up to image, choose the same file, and answer Yes when Windows asks whether to replace it. The log shows Resuming image and the copy picks up where it stopped.

From here on you work on the image, and the USB drive isn't read again.

3. Recover files (names/paths)

Click Recover files (names/paths). Because a disk is selected in the list, ReviveUSB first asks whether to read that disk directly. Click No and select your .img file; the image is the better choice. Then choose a folder for the results on a healthy drive.

This method reads NTFS, FAT32 and exFAT. It copies every file it can find with its name and folder, including deleted files and files that were inside deleted folders. When it finds both current and deleted files, the deleted ones go into a separate _deleted_files folder, so an old copy never sits next to the current file. That's the first place to look.

The destination folder needs as much free space as the files. If it doesn't have it, the log warns you before anything starts.

On a FAT32 drive, the log may list some files that "may be wrong inside". When Windows deleted them, it erased part of the information about where they start, and for types like .bin there is no signature to tell the right spot. Open those files before you rely on them.

4. If nothing comes back, recover by signature

If names/paths finds nothing, or says it can't detect the filesystem, run Recover files (signature) on the same image. It finds files by their content, so it works even when the filesystem is gone. It looks for JPEG, PNG, GIF, BMP, PDF and ZIP files, plus MP4, MOV, 3GP, M4A and HEIC, which covers phone and dashcam video and iPhone photos.

You lose the names this way. Files come back numbered, like jpg_00001_@.... Office files such as docx, xlsx and pptx are ZIP files inside, so they arrive with a .zip name. Rename them to the right extension.

The drive doesn't need repairing

Deleting files doesn't break a drive. The repair buttons (Check (chkdsk), Format and Full rebuild) are for drives Windows can't open, and Format and Full rebuild erase data. Leave them alone here.

Open the recovered files on your PC and check them. Once you have what you need, copy them back onto the USB drive the usual way and keep using it, but keep a copy on your PC as well. You can then delete the image file and the progress file next to it, for example disk2.img and disk2.img.state.json.

If it doesn't work

If a recovered file won't open, it may have been fragmented, so only its first part came back. Try both recovery buttons on the image.

If the backup is very slow, the cause is usually the drive or the connection, since ReviveUSB already skips bad regions. Plug the drive straight into a USB 3.0 port on the back of the PC instead of a hub, swap the cable, or try another PC. Back up again to the same image file and it continues where it stopped. If you're short on time, close the program partway and run Recover files (signature) on the image you have so far. It recovers files from the part that was copied.

If nothing comes back at all, new data may have been written over the deleted files. Overwritten data can't be recovered by any software, and neither can data on a flash chip that has died. A professional data recovery service is the remaining option then.
