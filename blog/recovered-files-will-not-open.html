Recovered files won't open or look corrupted: what to try

You got your files back from a USB drive or SD card, and some of them won't open. A photo turns grey halfway down, a PDF reader says the file is damaged, a video won't play, or a Word document shows up as a ZIP. This is common after recovery, and the reason behind it decides whether anything can be done. Sometimes renaming the file is enough. Sometimes the data is simply gone.

Why recovered files come back broken

The data was overwritten

When a file is deleted, its data usually stays on the drive and only the index entry pointing to it is removed. The space it occupies now counts as free, though. If anything was saved to the drive afterwards, it may have landed on top of the old file. A recovery tool can still find the old entry, but the contents now belong to some other file. No software can bring that data back.

The file was stored in pieces

A drive doesn't always keep a file in one continuous run. When a file is split into fragments, the filesystem index is what records where each piece went. If a file is found by its content rather than through that index, there is no record of where the rest of it went, and you may get only the first part. It is the first cause the ReviveUSB manual lists when a recovered file won't open.

Part of the drive couldn't be read

A failing stick or card often has regions that return read errors. Whatever was stored there is missing from any copy of the drive, so a file that sat partly in those regions can't come back complete.

The file is fine, but labelled wrong or unfinished

Office files such as docx, xlsx and pptx are ZIP files inside, so a tool that finds files by content saves them as .zip. Videos are different. If a recording was cut off, or the drive lost the part where its end was written, the file has no proper ending, and most players won't play it.

Before you try again

If you still have the original drive, leave it as it is until you're finished. Don't save anything to it or format it, and if Windows offers to scan and repair it, don't click Yes. A second, better attempt depends on the data still being there. Keep the recovered files on a different, healthy drive, and experiment on copies of them rather than the only ones you have.

Trying again with ReviveUSB

ReviveUSB is a free Windows tool for this job. It is a 64-bit exe for Windows 10 or 11 and needs administrator rights, because it reads the disk directly. It isn't code-signed yet, so SmartScreen may warn you. The download page lists the file's SHA-256 so you can check it before you choose More info, then Run anyway.

1. Work from an image and retry the unreadable parts

Click Refresh, select the drive, click Back up to image and save the image on another drive. ReviveUSB only reads the drive, and it skips regions it can't read so the copy doesn't stall. At the end it asks whether to retry them sector by sector. On a badly damaged drive that can take a long time, but it can rescue more of your data, so say yes if you can wait.

Only go back to the drive if nothing has been formatted, rebuilt or saved on it since the image was made. Otherwise skip to step 2 and work with the image you have.

If you already made an image, you don't have to start over. Click Back up to image again, choose the same file, and answer Yes when Windows asks whether to replace it. On a finished image it doesn't read the whole drive again. It only offers to retry the regions it couldn't read. The more of the drive the image holds, the more files can come back whole.

2. Use both recovery buttons

The two buttons find files in different ways, so run both on the image, each into its own folder on a healthy drive.

Recover files (names/paths) reads the NTFS, FAT32 or exFAT index and copies files out with their names and folders. It copies current files as well as deleted ones, and the deleted ones go into a separate _deleted_files folder. It works whenever the filesystem can still be read, even if Windows won't open the drive.

Recover files (signature) finds files by their content: JPEG, PNG, GIF, BMP, PDF, ZIP, MP4, MOV, 3GP, M4A and HEIC. Version 0.2.13 added HWP, older Office files (doc, xls, ppt), MP3, AVI and WAV. It works even when the filesystem is gone, but the names are lost, and files come back numbered like jpg_00001_@....

The manual's advice for files that won't open is to try both buttons. If a file is broken in one result folder, look for it in the other.

3. Read the log for warnings

ReviveUSB warns you about some files it can't vouch for. On FAT32, exFAT and NTFS drives, deleted files whose space was later used by newer files are listed with a warning that their contents are probably wrong. After names/paths recovery from a FAT32 drive that Windows deleted files from, the log may list files that "may be wrong inside", because Windows erased part of where they start. Open those files before you rely on them.

4. Fix the ones that are only mislabelled

In the signature results, rename .zip files that are really Office documents to .docx, .xlsx or .pptx, then open them again. A video without its end is saved as far as it goes, but most players can't play it without the missing end. ReviveUSB doesn't repair damaged files. What it recovers is what was on the drive.

If they still won't open

Some files won't come back whole, and it helps to know that before you spend hours on more scans. If the data was overwritten, or the flash chip itself is dead, software can't help. For files that matter that much, a professional data recovery service is the remaining option.

There is one more case. If the files opened fine on your PC but break after you put them on a repaired drive, the drive is at fault. After a repair, Test drive writes test data and reads it back, and Copy files back compares every copied file with the original by SHA-256 and lists any that don't match. Don't keep your files on a drive that fails either check, and keep the recovered copies on your PC either way.
