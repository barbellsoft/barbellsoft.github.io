Search inside files on your Desktop and Downloads

Most files on a work PC end up in one of two places. You save an attachment and it lands in Downloads. You want something close at hand and drop it on the Desktop. A few weeks later you remember a sentence from it, a client's name or a line from a quote, but not what the file was called.

Searching by name doesn't help then. You need a search that reads the text inside the documents. This post shows how Chatda, a free search app for Windows 10 and 11 (it runs on macOS too), does that for your Desktop and Downloads folders, and what to check when a file still doesn't show up.

What changed in Chatda 9.34.13

On Windows, Chatda adds every fixed drive (C:\, D:\ and so on) by itself. For a whole drive it only keeps file names, sizes and dates. That makes any file findable by name right away, but a word that appears only inside a document wouldn't match.

Until now you had to add the folders whose contents you wanted searched. Many people never did, and searching by content simply returned files whose names matched.

Starting with version 9.34.13, Chatda on Windows adds your Desktop and Downloads folders once, on its own, the first time it runs. The documents in them are then searchable by what's written inside. If you already added those folders, or you removed one on purpose, Chatda leaves them as they are.

Set it up

Download Chatda from the download page and install it. Installing asks for administrator approval, because Chatda installs for all users together with its drive indexing service.

Chatda isn't code-signed yet, so Windows SmartScreen may say it doesn't recognize the app. The download page lists the file's SHA-256 checksum and shows how to compare it in PowerShell. If the value matches, choose More info, then Run anyway.

When Chatda starts, it indexes your drives and then the Desktop and Downloads folders. The status bar at the bottom shows the progress. If Chatda is already installed, update it to 9.34.13 or later.

Search by a word inside a document

Type a word you remember into the search box. The default mode, Name + content, finds files that have the word in the name and files that have it inside.

Look at the Content column in the results. It shows where your search words appear in the document. If it's empty, the file matched by name only.

To see only the files that contain the word somewhere inside, pick Content only from the Search in dropdown in the filter bar. That leaves out files that match only by name, which helps when the word is common in file names.

Which files are read

Chatda reads the contents of TXT, MD, CSV, DOCX, XLSX, PPTX, PDF and HWPX files. Other formats, including older HWP files, images and code, match by name only.

A PDF has to contain real text. Some PDFs are photos of paper pages, saved by a scanner or a phone app, and there are no letters in them to search. Open the file and try to select a sentence with your mouse. If nothing highlights, or the whole page highlights as one block, you'll only find that file by its name.

Search other folders too

Your Desktop and Downloads aren't the only places documents live. For a project folder, a shared work folder or Documents, add it yourself:

  1. Click All locations ▾ at the top.
  2. Choose + Add folder and pick the folder.
  3. Indexing starts on its own, and the status bar shows how far along it is.

If you have only whole drives added and no folder whose contents are read, Chatda shows a notice above the results with an Add folder button, so you don't have to guess why a word inside a document isn't found.

If a file still doesn't show up

Check where the file is. A document on another drive, or in a folder you haven't added, is searched by name only. Add its folder and search again.

Check the file type against the list above. A Word file saved in an older format or a scanned PDF will match by name only.

Check the All types ▾ filter at the top. If a type filter is on, files of other types are left out of the results.

Try a shorter word or part of one. If you remember a phrase exactly, put it in quotes, for example "payment statement".

The help page explains the search modes and the search syntax in more detail, and the FAQ covers installation questions.
