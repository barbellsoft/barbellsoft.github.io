Search inside HWPX files together with PDF and Office files

If you work with Korean documents, your folders are probably a mix. Reports written as HWPX, PDFs that someone emailed you, Word files, a few Excel sheets. You remember a phrase from one of them, maybe a project name or a line from a notice, but not which format it was in or what the file was called.

Searching by file name doesn't help when the name is the part you forgot. You need a search that reads the text inside all of those formats at once and puts the results in one list. This post shows how to do that with Chatda, a free search app for Windows 10 and 11 that also runs on macOS, and what to check when a Korean document still won't turn up.

HWPX and HWP are different files

Hangul documents come in two formats. HWPX is the newer one. HWP is the older one, and many folders still hold plenty of them.

Chatda reads the text inside HWPX files. It does not read the text inside HWP files, so those can only be found by name. The full list of formats it reads inside is TXT, MD, CSV, DOCX, XLSX, PPTX, PDF and HWPX. Anything else, including images and ZIP files, matches by name only.

So before you start, look at the extensions in the folders you care about. If an important document is still an .hwp file and you want to find it by what it says, open it in your word processor and save a copy as HWPX. Keep the original until you've checked that the copy opens properly.

PDFs need a similar check. A PDF scanned from paper is a picture of text, and there are no letters in it for any search tool to read. Open it and try to select a sentence with the mouse. If nothing highlights, or the whole page highlights as one block, you'll only find that file by its name.

Set up Chatda once

Download Chatda from the download page and install it. Installing asks for administrator approval, because Chatda installs for all users together with its drive indexing service.

Chatda isn't code-signed yet, so Windows SmartScreen may say it doesn't recognize the app. The download page lists the file's SHA-256 and shows how to compare it in PowerShell. If the value matches, choose More info, then Run anyway. On a Mac, the first launch may say Chatda can't be opened: click Done, open System Settings > Privacy & Security, click Open Anyway, then open Chatda again.

If you'd rather use a Korean interface, go to ⚙ Settings → Language and pick 한국어.

On Windows, Chatda adds every fixed drive (C:\, D:\ and so on) by itself. For a whole drive it keeps only file names, sizes and dates, which means you can find any file by name straight away, but not by its contents. To search inside your documents, add the folders they live in:

  1. Click All locations ▾ at the top.
  2. Choose + Add folder and pick a folder, for example Documents or a project folder.
  3. Indexing starts on its own. The status bar at the bottom shows the progress and the time left.

If the documents sit on a NAS, choose Connect network folder in the same panel and enter the NAS address, your username and your password.

Search in Korean

Type a word or two into the search box. You don't need to press Enter, because results appear as you type, usually within 0.2 seconds. While you're still composing a Korean character, Chatda waits until the character is complete before it searches.

You can mix Korean and English in one search, like Ctrl 단축키. Spacing doesn't matter much either: 회의록, 회의 록 and 회의 록 2024 behave about the same. If you're not sure of the exact wording, start short. 3분기 결산 will find more than a long title you half remember.

HWPX files, PDFs and Office files come back in the same table. The Content column shows where your words appear in each document, and an empty cell means the file matched by name only. Click a result once to open the preview panel on the right. For Word, Excel, PowerPoint and HWPX files it shows the extracted text (up to 300 MB), and for PDFs it shows the document text (up to 30 MB). Double-click to open the file in its usual app.

Narrow it down

When a common word turns up in dozens of files, these help:

  • In the Search in dropdown, switch to Content only. Files that only have the word in their name drop out.
  • Add an extension to the search. 예산 *.hwpx finds HWPX files that contain 예산 (budget). *.{hwpx,pdf} covers both formats, and so does ext:hwpx;pdf.
  • Put words in quotes, like "지급 명세서", to find them together and in that order.
  • Leave out drafts with a minus: 계약 -초안 hides results that contain 초안 (draft).
  • Use the Date dropdown to limit results to the past week, month or year.

If you need a list of what you found, for a report or to send to a colleague, use Export ▾ → CSV (Excel). It saves every result that matches the current search, not just the ones on screen, and the file opens in Excel without garbled Korean.

When a document still doesn't show up

Work through these in order:

  1. Is it .hwp rather than .hwpx? Old HWP files match by name only. Save a copy as HWPX if you need to search its contents.
  2. Is the folder added by itself? A file covered only by a whole-drive entry like C:\ is searched by name. Add its folder with + Add folder.
  3. Is the PDF a scan? If you can't select its text, there is nothing inside it to search.
  4. Is Chatda up to date? Version 9.33.0 fixed some Korean PDFs, such as PDFs made from Hangul documents, whose text couldn't be searched. Version 9.34.5 fixed file names where Korean is joined to digits or letters, like 1차 or 회의록v2, not matching in the middle of the name. When a new version is out, a banner appears at the top when Chatda starts; click Install.
  5. Did you just save it? In a local folder Chatda picks up new and changed files within about half a second. On a NAS it can take up to five minutes. In a hurry, choose Re-index from the folder's menu.
  6. Did indexing finish? A ⚠ mark in front of a folder name means it didn't. Choose Re-index.
  7. Is the word too specific? Try Content only with a shorter, more general word. 병목 finds more than 결재 병목.
