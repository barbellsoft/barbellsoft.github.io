USB drive shows 0 bytes or No Media: what you can recover

You plug in a USB stick and nothing opens. Disk Management lists the disk, but as "No Media", or with a size of 0 bytes. Windows may even offer to format it. Choose Cancel.

If the drive really reports no storage, no software can read it, ReviveUSB included. A few things are still worth trying, though, and there is a similar-looking case with much better odds.

Two problems that look alike

Start with the size Windows shows.

If it says 0 bytes or No Media, the small chip that runs the stick, its controller, could not load its own firmware, or the drive reports no storage at all. Until that changes, there is nothing for any program to read.

If the drive shows its real capacity but has no drive letter, or nothing appears in File Explorer, the drive is answering, and the damage is usually in the partition or the filesystem. The ReviveUSB manual has an example from an external drive: 3.6 TB, status Healthy/Online, and only a 200 MB RAW piece without a drive letter. Healthy/Online means the hardware is working and only the partition structure is broken, which software can usually handle.

What ReviveUSB shows for a 0-byte drive

ReviveUSB is a free Windows tool for failing USB drives. It runs on Windows 10 or 11 (64-bit), is one exe with nothing to install, and needs administrator rights because it reads disks directly. It isn't code-signed yet, so SmartScreen may warn you. The download page lists the file's SHA-256 so you can check it with Get-FileHash .\ReviveUSB.exe -Algorithm SHA256 in PowerShell before choosing More info, then Run anyway.

Click Refresh and look at the disk list. A stick in this state shows as "Firmware failure (ROM mode)" or "No storage (size 0)". Select it and a Diagnosis box opens below the list with the device ID, the likely controller and what to do next. Copy diagnosis copies that text if you want to ask someone for help.

Backup, recovery and repair are all turned off for this drive, because there is nothing to read or write.

If the list shows "Empty (0)" in gray instead, that is often an empty card reader slot. Insert a card. If a USB stick shows it, unplug it and plug it back in.

What you can still try

Unplug the drive and plug it back in. The Diagnosis box checks again every 5 seconds by itself, or you can click Check again.

If the drive comes back with its normal name, don't write anything to it, and don't run a repair. Back it up straight away:

  1. Click Back up to image and save the image on a different drive with as much free space as the stick's capacity. ReviveUSB only reads the drive and skips regions it can't read instead of stalling. If you have to stop, close the window; backing up again to the same file later picks up where it left off.
  2. Click Recover files (names/paths), pick the image, and choose a folder on a healthy drive. Your files come back with their names and folders if the filesystem can be read. If it finds nothing, use Recover files (signature) on the same image, which finds photos, videos, PDFs and ZIP files by their content but without their names.

Only after your files are safe should you think about using the stick again. Repair and Copy files back stay off for a drive that came back from this state until it passes Test drive on the whole free space. A quick 1 GB test doesn't turn them on. A large write can make a drive like this stop again, which is why the full test comes first.

When a recovery lab is the only option

If the drive does not come back, ReviveUSB can't revive it, and its files can't be read by software. If the files matter, a data recovery lab may be able to read the memory chip directly. If they don't, replace the drive.

You may find advice to run factory tools (mass production tools) on the stick. ReviveUSB doesn't recommend them: they did not work on the drive we tested, and they are not officially distributed.

The same limit applies more widely. If the data has been overwritten, or the flash chip itself is dead, software cannot help, and a professional recovery service is what's left.

If the size is right but there's no drive letter

Here you have more options. Start with plain Windows: open Disk Management and look at the volume. If it shows a normal filesystem and only lacks a letter, you can right-click it, choose Change Drive Letter and Paths, and add one. That doesn't touch your files. If Windows asks you to format at any point, choose Cancel.

If the volume shows as RAW, or a large drive shows only a small RAW piece with the rest unallocated, the partition or filesystem is damaged. Then use the same order as above: Back up to image, then Recover files (names/paths) on the image. ReviveUSB reads NTFS, FAT32 and exFAT itself and can often read a filesystem that Windows refuses to mount. It copies all the files it finds, not only deleted ones, and anything that had been deleted goes into a separate _deleted_files folder. If that finds nothing, try Recover files (signature).

Once your files are on your PC, you can repair the drive. For a RAW drive with damaged partitions, Full rebuild is the usual fix. It wipes the whole disk, so it asks you to type ERASE DISK and the disk number first. Check (chkdsk) and Format need a drive letter, and chkdsk can't repair a RAW drive anyway. Before any repair writes to the drive, ReviveUSB reads it to look for signs that the controller is failing, such as the drive not responding or reporting a size of 0. If it finds them, it won't repair and says why in the log.

If it still doesn't work

If recovered files won't open, they may have been fragmented, so only the first part came back, or they sat in regions that couldn't be read. Try both recovery buttons.

If the drive keeps appearing and disappearing, or turns RAW again soon after a rebuild, the hardware is probably failing. Replace it, and keep a second copy of anything that matters. The manual explains every button, and the FAQ covers the common questions.
