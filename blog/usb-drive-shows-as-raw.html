USB drive or SD card shows as RAW: recover files first

You open Disk Management because a USB stick or SD card stopped opening, and the File System column says RAW. Don't format it yet. RAW means Windows can't read the index of files on the drive. The files themselves are usually still there.

What RAW means

Every drive carries a filesystem, an index that says which file lives where and under what name. When Windows can't mount that index, it labels the volume RAW. That happens even when only one value in the index is wrong.

Disk Management shows two versions of this. In the first, the volume is still there, maybe even with a drive letter, and File System says RAW. Often the boot sector at the start of the volume is damaged, a common reason Windows asks you to format a drive.

In the second, the partition itself is damaged. A large drive shows up as a small RAW piece, or with no drive letter, and the rest is unallocated. The ReviveUSB manual has an example from an external drive: 3.6 TB, status Healthy/Online, and only a 200 MB RAW piece without a letter. Healthy/Online means the hardware works and only the partition structure is broken, which software can usually repair.

Why chkdsk and formatting don't help

chkdsk refuses to run on a RAW drive, and rightly so: it repairs a filesystem that exists, and a RAW drive has none it can read.

Formatting writes a fresh, empty index over the drive. Your old files' data stays on the flash until something overwrites it, but the names and folders are gone. After a quick format, ReviveUSB's names-and-folders recovery finds nothing and points you to signature recovery, which brought back photos, documents and videos in testing, but without their names.

So until your files are somewhere safe:

  • Don't format, in Disk Management, File Explorer or any repair tool.
  • Don't click Yes when Windows offers to scan and repair the drive.
  • Don't save or copy anything onto it.

Reading is fine. If it's an SD card, move it from the camera or phone to a card reader, so nothing else writes to it.

Getting the files out with ReviveUSB

ReviveUSB is a free Windows tool built around one rule: copy the drive first, recover from the copy, and repair the drive last. It runs on Windows 10 or 11 (64-bit), is a single exe with nothing to install, and needs administrator rights because it reads the disk directly. You also need free space on another drive equal to the broken one. A 128 GB drive needs 128 GB free.

It isn't code-signed yet, so SmartScreen may say it doesn't recognize the app. The download page lists the file's SHA-256. Check it in PowerShell with Get-FileHash .\ReviveUSB.exe -Algorithm SHA256, and if it matches, choose More info, then Run anyway.

1. Select the drive

Run ReviveUSB.exe, allow administrator rights, and check that the top of the window says Administrator: ON. Click Refresh and click your drive in the list. The Filesystem column will say RAW. Only USB disks are listed, and an SD card in a USB reader counts as one. If your card is in a laptop's built-in reader and doesn't appear, tick Show internal disks (caution) and take care to pick the card, not your system disk.

2. Back up to an image

Click Back up to image and save the file on a different drive. ReviveUSB only reads the drive, skips regions it can't read, and asks at the end whether to retry them sector by sector. You can close the window and continue later: click Back up to image again, choose the same file, answer Yes when Windows asks whether to replace it, and the log says Resuming image. From here on, every step works on the image, so a failing card is read only once.

3. Recover files with their names

Click Recover files (names/paths), pick the image, and choose a folder on a healthy drive. Do this even though Windows says RAW. ReviveUSB reads NTFS, FAT32 and exFAT itself and can often read an index that Windows won't mount. If the boot sector at the start of the volume is damaged, it reads the backup copy that Windows keeps. If the partition table at the start of a GPT drive is damaged, it reads the backup copy at the end of the drive.

When it works, your files come back with their names and folders. It copies all the files it can find, not only deleted files, and anything that had been deleted goes into a separate _deleted_files folder.

4. If that finds nothing, recover by signature

If ReviveUSB says it couldn't detect the filesystem, or finds nothing, click Recover files (signature) on the same image. It finds files by their content: JPEG, PNG, GIF, BMP, PDF and ZIP, plus MP4, MOV, 3GP, M4A and HEIC, which covers phone and dashcam video and iPhone photos.

Names are lost this way. Files come back numbered, like jpg_00001_@.... Office documents are ZIP files inside, so they arrive as .zip; rename them. A video whose end was never written is saved as far as it goes, but most players won't play it.

Repairing the drive, only now

Once the recovered folder is on your PC, repair the drive. For a RAW drive or one with no letter, select it and click Full rebuild. It wipes the disk, creates a new partition and quick-formats it as NTFS, after you type ERASE DISK and the disk number to confirm. If the drive still has a letter and only the volume is broken, Format is enough. If the card goes back into a camera or another device, reformat it there afterwards.

Before writing anything, ReviveUSB reads the drive to check whether its controller is failing, and if it sees signs of that, it won't repair the drive and says why in the log. A drive that is RAW only because its filesystem can't be recognized is not blocked. After the rebuild, click Refresh, select the drive and run Test drive; the full test is slow but catches drives that fake their capacity. If it passes, Copy files back returns the recovered folder to the drive and checks every file against the original. Keep the copy on your PC anyway.

If it doesn't work

If the list shows "Firmware failure (ROM mode)" or "No storage (size 0)", there is nothing to read. Unplug it and plug it back in. If it comes back with its normal name, back it up at once. If it doesn't, a data recovery lab may be able to read the memory chip directly.

If recovered files won't open, they may have been fragmented, so only the first part came back, or they sat in regions that couldn't be read. Try both recovery buttons.

If the drive turns RAW again soon after a rebuild, or keeps disconnecting, replace it. And if the data was overwritten, or the flash chip itself is dead, no software can help.
