"You need to format the disk" on USB: save your files first

You plug in a USB stick that worked yesterday and Windows says "You need to format the disk in drive E: before you can use it", with a Format disk button and a Cancel button. Click Cancel.

The message sounds final, but it usually means the filesystem on the drive is damaged, not that the drive is dead. Windows can't read the index that lists your files, so it offers to format the drive. Your files are usually still there. Formatting is what puts them at risk.

What is going on

Every drive keeps an index, the filesystem, that says which file lives where. When Windows can't mount that filesystem, it shows the drive as RAW. That happens even when only one value in the index is wrong. If a large drive shows up as a small RAW piece, or has no drive letter at all, the partition itself is damaged.

This is also why the usual first aid doesn't help. chkdsk repairs a filesystem that exists, and a RAW drive has none it can read, so there is nothing for it to fix.

What not to do yet

Until your files are somewhere safe, leave the drive alone:

  • Don't format it, in Windows or anywhere else.
  • Don't click Yes if Windows offers to scan and fix the drive.
  • Don't save or copy anything new onto it.

When the index is damaged, the data itself normally stays where it was. Write something new and Windows may put it right on top of your old files, and then nothing can bring them back. Reading from the drive is fine.

Getting your files back with ReviveUSB

ReviveUSB is a free Windows tool built around that order: copy the drive, recover from the copy, and only then repair the drive. It runs on Windows 10 or 11 (64-bit) and needs administrator rights because it reads the disk directly.

You'll need free space on another drive as large as the broken one. A 128 GB stick needs 128 GB free.

ReviveUSB isn't code-signed yet, so SmartScreen may say it doesn't recognize the app. The download page lists the file's SHA-256. Check it in PowerShell with Get-FileHash .\ReviveUSB.exe -Algorithm SHA256, and if it matches, choose More info, then Run anyway.

1. Pick the drive

Run ReviveUSB.exe and allow administrator rights. The top of the window should say Administrator: ON. Click Refresh, then click your USB drive in the list. The Filesystem column will probably say RAW.

2. Copy the drive to an image

Click Back up to image and save the file, named something like disk2.img, on a different drive. ReviveUSB only reads the USB stick here. It skips regions it can't read so the copy doesn't stall, and at the end it asks whether to retry those regions sector by sector.

You can close the window and continue later: click Back up to image again, choose the same file and answer Yes to replace it. The log says Resuming image and the copy picks up where it stopped.

From here on you work on the image. Reading a failing stick over and over is riskier than reading a copy of it.

3. Recover files with their names

Click Recover files (names/paths), pick your image file and choose a folder on a healthy drive. ReviveUSB refuses a folder on the drive you're recovering.

Try this even though Windows says the drive is RAW. It reads NTFS, FAT32 and exFAT, and it can often still read a filesystem that Windows won't mount. When it works, your files come back with their names and folders. It copies all the files it finds, not just deleted files, and anything that was deleted goes into a separate _deleted_files folder.

4. If that finds nothing, use the signature method

If ReviveUSB says it could not detect the filesystem, or finds nothing, click Recover files (signature) and use the same image. This method ignores the filesystem and looks for files by their content. It finds JPEG, PNG, GIF, BMP, PDF and ZIP files, plus MP4, MOV, 3GP, M4A and HEIC (phone and dashcam videos, and phone photos).

The trade-off is that names are lost. Files come back numbered, like jpg_00001_@.... Documents such as .docx, .xlsx and .pptx are ZIP files inside, so they come back as .zip. Rename them to the right extension.

Fixing the USB stick afterwards

Once your files are safe on your PC, you can make the stick usable again. For a RAW drive or one without a drive letter, select it and click Full rebuild. It wipes the disk, creates a new partition and formats it as NTFS. You confirm by typing ERASE DISK and the disk number, for example ERASE DISK 2. If the drive still has a letter and you only want to wipe it, Format does that.

Before writing anything, ReviveUSB reads the drive to check whether its controller is failing, for example if parts of it couldn't be read. If it sees those signs, it won't repair the drive and says why in the log. A large write can kill a failing drive halfway through, so in that case keep your recovered files and replace the stick.

After the rebuild, click Refresh, select the drive and click Test drive. Yes tests all free space, No runs a quick 1 GB test. Only the full test catches drives that fake their capacity. If it passes, Copy files back puts your recovered folder back on the stick and then reads every file back to compare it with the original. Keep the copy on your PC anyway.

If it doesn't work

The list shows "Firmware failure (ROM mode)" or "No storage (size 0)"

The stick's controller isn't loading, and Windows may show it as "No Media" or 0 bytes and still ask you to format. Click Cancel. Unplug it and plug it back in. If it comes back with its normal name, back it up right away. If it doesn't come back, software can't read it. A data recovery lab may be able to read the memory chip directly.

The backup is extremely slow

Plug the drive straight into a USB 3.0 port on the back of the PC, without a hub or extension cable. If that doesn't help, try another cable or PC. Backing up to the same image file continues the copy.

Recovered files won't open

The file may have been fragmented, so only the first part came back. Try both recovery buttons. Parts of the drive that couldn't be read are missing from the image.

The repair fails

Unplug the drive, plug it back in and try again, and close anything that might be using it, such as antivirus or Explorer previews. If the status stays Unhealthy or the drive keeps disconnecting, the hardware is probably failing. Software can't fix that, so replace the drive.

When nothing can help

Some files can't be recovered. If the data has already been overwritten, or the flash chip itself is dead, no software can help, and a professional recovery service is the remaining option. The ReviveUSB manual explains every button.
