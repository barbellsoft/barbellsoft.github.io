Windows search can't find your document? Search inside it

You remember writing "deposit due by the 15th" in some document last month. You don't remember the file name, or whether it was a Word file, a PDF or a spreadsheet. You type the phrase into the search box on the taskbar, and nothing useful comes back.

This is a common gap. Most searching on a PC starts from the file name, and the name is exactly what you've forgotten. This post explains why a search can miss a document that is sitting right there, compares three kinds of search, and shows how to find a file by the words inside it with Chatda, a free search app for Windows 10 and 11 that also runs on macOS.

Why the search comes back empty

A search can only find what it has looked at beforehand. To answer instantly, every search tool keeps an index: a list it built earlier of file names, and sometimes of the text inside files. If the words you remember were never put into that index, no search box will find them.

Three things decide whether a document's words are in an index:

  • Where the file is. An index covers certain folders or drives. A file on another drive, in a folder outside that list, or on a network folder may only be known by its name, or not at all.
  • What kind of file it is. To read the text inside, a program has to understand the format. If it doesn't, the file can still be found by name, but not by its contents.
  • Whether the index is up to date. A file saved a minute ago may not be in the index yet.

Name-only tools are a good choice when you know part of the name. Built-in search works well for files in the places it indexes. When all you have is a phrase from inside the document, you need something that has read the documents, and that's the case Chatda is built for.

Find a document by its words with Chatda

1. Install and open Chatda. Get it from the download page. On Windows, Chatda adds every fixed drive right away, so you can search file names on C:\ and D:\ from the start. For whole drives it indexes names, sizes and dates, not the text inside.

2. Add the folders whose contents you want searched. Click All locations ▾, then + Add folder, and pick the folder where your documents live, such as Documents or Desktop. Indexing starts by itself, and the status bar at the bottom shows its progress.

3. Add a network folder if your files are on a NAS. In All locations ▾, choose Connect network folder, then enter the NAS address and your username and password.

4. Type the words you remember. Results appear as you type; there's no need to press Enter. The Content column shows where your words appear in each document, with the search words highlighted.

5. Narrow it down. If the word is in many file names too, set Search in to Content only, so you see only files that contain the word but don't have it in their name. You can also pick a file type, limit the date to the past week or month, or type a wildcard such as *.pdf together with your words.

6. Open it. Double-click a result to open it in its default app, or press Ctrl+Enter to show it in Explorer. Ctrl+Shift+Space brings up Chatda from anywhere, so next time you can start searching without hunting for the window.

How fast is it?

On one test PC (Windows 10 Pro, AMD Ryzen 5 8500G, 31 GB RAM, NVMe SSD), Chatda indexed the names on the whole C: drive, about 11.8 million files, in 16 to 17 seconds, against 47 to 48 seconds for another file search program (Program A) indexing the same files. A one-letter search took 87 to 92 ms. Results on your PC will differ; the conditions are on the Chatda page.

What it can't do

Chatda reads the contents of TXT, MD, CSV, DOCX, XLSX, PPTX, PDF and HWPX files. Other formats, such as images or ZIP files, are found by name only. Whole drives added automatically are searched by name; add the folder itself to search inside its documents.

Chatda isn't code-signed yet, so Windows SmartScreen may show a warning the first time, and macOS may refuse to open it at first. On Windows it installs for all users and asks for administrator approval.

If the document still doesn't show up

  • It was saved a moment ago. In a local folder Chatda picks up changes quickly; on a NAS it can take up to about 5 minutes. In a hurry, open the folder menu (⋯ next to the folder) and choose Re-index.
  • No excerpt appears. The file's format may not support content search, or the file is only covered by a whole-drive entry. Add its folder with + Add folder.
  • A NAS folder looks empty. Check that you can open the NAS address in Explorer, and if you're working from outside the office, that your VPN is connected.
