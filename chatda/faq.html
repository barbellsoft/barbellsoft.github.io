Chatda FAQ

The same file shows up several times.

Often the same file really does exist in several folders, for example on a NAS. Set grouping to By folder or By version to tidy the list.

I don't see an excerpt from the document.

The file's format may not support content search (images or ZIP files, for example). Contents are read from TXT, MD, CSV, DOCX, XLSX, PPTX, PDF and HWPX. Files covered only by a whole-drive entry such as C:\ are searched by name; add their folder separately to search their contents.

I just created a file and it doesn't show up.

In a local folder, Chatda picks it up within about half a second. On a NAS it can take up to five minutes. In a hurry, choose Re-index from the folder menu.

Search is slow.

Switch the search mode to Name only, which is the fastest. You can also narrow the search with the file type filter or search a single folder with the folder filter.

How do I get updates?

When a new version is out, a banner appears at the top when Chatda starts. Click Install and the rest is automatic.

Do favorites and recent searches sync between PCs?

No. Each computer keeps its own.

I changed my NAS password. What now?

Reconnect with the new password from Connect network folder in the sidebar.
