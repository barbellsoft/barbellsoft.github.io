Gelöschte Dateien vom USB-Stick wiederherstellen

Sie haben einen Ordner von einem USB-Stick gelöscht, den Papierkorb geöffnet, um ihn wiederherzustellen, und er ist nicht da. Das ist normal. Windows verschiebt Dateien, die von einem USB-Stick gelöscht werden, nicht in den Papierkorb. Sie werden sofort gelöscht, genau wie mit Umschalt+Entf auf jedem Laufwerk.

Das heißt nicht, dass die Dateien weg sind. Meist sind sie noch auf dem Laufwerk, und was Sie als Nächstes tun, entscheidet, wie viel davon zurückkommt.

Was beim Löschen wirklich passiert

Ein Laufwerk führt einen Index, das Dateisystem, der festhält, welche Datei wo und unter welchem Namen gespeichert ist. Wenn Sie eine Datei löschen, bleiben die Daten selbst meist auf dem Laufwerk. Entfernt wird nur der Indexeintrag, der auf sie zeigt. Deshalb ist eine Wiederherstellung überhaupt möglich.

Der Haken: Der Platz, den Ihre Datei belegt, gilt jetzt als frei. Speichern Sie eine neue Datei auf das Laufwerk, schreibt Windows sie womöglich direkt über die alten Daten, und dann lassen sich die alten Daten nicht mehr wiederherstellen. Je mehr Sie nach dem Löschen auf das Laufwerk schreiben, desto weniger bekommen Sie zurück.

Was Sie jetzt tun sollten

Speichern oder kopieren Sie nichts auf das Laufwerk, bis Ihre Dateien in Sicherheit sind. Das gilt auch für das Wiederherstellungsprogramm und die geretteten Dateien. Formatieren Sie es auch nicht, und wenn Windows anbietet, das Laufwerk zu prüfen und zu reparieren, klicken Sie nicht auf Ja.

Lesen vom Laufwerk ist unbedenklich. Wenn Sie noch nicht anfangen können, werfen Sie es aus und lassen Sie es abgezogen, damit in der Zwischenzeit nichts darauf schreibt.

Die Dateien mit ReviveUSB zurückholen

ReviveUSB ist ein kostenloses Windows-Programm, das in fester Reihenfolge arbeitet: Zuerst kopiert es das ganze Laufwerk in eine Image-Datei, dann stellt es die Dateien aus dieser Kopie wieder her. Sichern und Wiederherstellen lesen das Laufwerk nur. Es läuft unter Windows 10 oder 11 (64-Bit), ist eine einzelne exe-Datei ohne Installation und braucht Administratorrechte, weil es direkt vom Datenträger liest.

Das Image ist eine vollständige Kopie, daher brauchen Sie auf einem anderen Laufwerk so viel freien Speicher, wie der USB-Stick groß ist. Ein 128-GB-Laufwerk braucht 128 GB freien Speicher. Auch die geretteten Dateien brauchen Platz, auf einem beliebigen Laufwerk außer dem USB-Stick.

ReviveUSB ist noch nicht codesigniert, daher warnt Sie möglicherweise Windows SmartScreen oder Ihr Virenschutz. Auf der Download-Seite steht der SHA-256 der Datei. Prüfen Sie ihn in PowerShell mit Get-FileHash .\ReviveUSB.exe -Algorithm SHA256. Stimmen die Werte überein, wählen Sie Weitere Informationen und dann Trotzdem ausführen. Speichern Sie den Download auf Ihrem PC, nicht auf dem USB-Stick.

1. Laufwerk auswählen

Starten Sie ReviveUSB.exe und erlauben Sie Administratorrechte. Oben im Fenster sollte Administrator: EIN stehen. Steht dort AUS, klicken Sie auf Als Administrator neu starten. Schließen Sie den USB-Stick an, klicken Sie auf Aktualisieren und dann in der Liste auf Ihr Laufwerk. Aufgelistet werden nur USB-Datenträger, Ihre internen Datenträger bleiben also außen vor.

2. Als Image sichern

Klicken Sie auf Als Image sichern und speichern Sie das Image auf einem anderen Laufwerk mit genug freiem Speicher. Vorgeschlagen wird der Name diskN.img, wobei N die Datenträgernummer ist. Wählen Sie einen Ort auf dem USB-Stick selbst, lehnt ReviveUSB ab und verlangt ein anderes Laufwerk, denn dort zu speichern könnte genau die Dateien überschreiben, die Sie zurückhaben wollen.

Sie können das Fenster jederzeit schließen. Um später weiterzumachen, starten Sie das Programm erneut, wählen dasselbe Laufwerk, klicken auf Als Image sichern, wählen dieselbe Datei und antworten mit Ja, wenn Windows fragt, ob sie ersetzt werden soll. Das Protokoll zeigt Image wird fortgesetzt, und die Kopie macht dort weiter, wo sie aufgehört hat.

Ab hier arbeiten Sie mit dem Image, und der USB-Stick wird nicht mehr gelesen.

3. Dateien retten (Namen/Pfade)

Klicken Sie auf Dateien retten (Namen/Pfade). Da in der Liste ein Datenträger ausgewählt ist, fragt ReviveUSB zuerst, ob es diesen Datenträger direkt lesen soll. Klicken Sie auf Nein und wählen Sie Ihre .img-Datei; das Image ist die bessere Wahl. Wählen Sie dann einen Ordner für die Ergebnisse auf einem intakten Laufwerk.

Diese Methode liest NTFS, FAT32 und exFAT. Sie kopiert jede Datei, die sie finden kann, mit ihrem Namen und Ordner, auch gelöschte Dateien und Dateien aus gelöschten Ordnern. Findet sie sowohl aktuelle als auch gelöschte Dateien, kommen die gelöschten in einen eigenen Ordner _deleted_files, sodass nie eine alte Kopie neben der aktuellen Datei liegt. Dort sollten Sie zuerst nachsehen.

Der Zielordner braucht so viel freien Speicher, wie die Dateien belegen. Fehlt der Platz, warnt Sie das Protokoll, bevor etwas beginnt.

Bei einem FAT32-Laufwerk kann das Protokoll einige Dateien auflisten, die „falschen Inhalt haben können“. Als Windows sie gelöscht hat, hat es einen Teil der Information darüber gelöscht, wo sie beginnen, und bei Typen wie .bin gibt es keine Signatur, an der sich die richtige Stelle erkennen ließe. Öffnen Sie diese Dateien, bevor Sie sich auf sie verlassen.

4. Kommt nichts zurück, per Signatur retten

Findet Namen/Pfade nichts oder meldet, dass es das Dateisystem nicht erkennen kann, führen Sie Dateien retten (Signatur) mit demselben Image aus. Es findet Dateien anhand ihres Inhalts und funktioniert daher auch, wenn das Dateisystem weg ist. Es sucht nach JPEG-, PNG-, GIF-, BMP-, PDF- und ZIP-Dateien sowie MP4, MOV, 3GP, M4A und HEIC. Damit sind Videos von Handys und Dashcams und iPhone-Fotos abgedeckt.

Die Namen gehen dabei verloren. Die Dateien kommen nummeriert zurück, etwa als jpg_00001_@.... Office-Dateien wie docx, xlsx und pptx sind im Inneren ZIP-Dateien und kommen deshalb mit der Endung .zip an. Benennen Sie sie mit der richtigen Endung um.

Das Laufwerk muss nicht repariert werden

Das Löschen von Dateien beschädigt kein Laufwerk. Die Reparatur-Schaltflächen (Prüfen (chkdsk), Formatieren und Neu aufbauen) sind für Laufwerke gedacht, die Windows nicht öffnen kann, und Formatieren und Neu aufbauen löschen Daten. Lassen Sie sie hier in Ruhe.

Öffnen Sie die geretteten Dateien auf Ihrem PC und prüfen Sie sie. Haben Sie, was Sie brauchen, kopieren Sie die Dateien wie gewohnt zurück auf den USB-Stick und benutzen ihn weiter, behalten aber auch eine Kopie auf Ihrem PC. Danach können Sie die Image-Datei und die Fortschrittsdatei daneben löschen, zum Beispiel disk2.img und disk2.img.state.json.

Wenn es nicht klappt

Lässt sich eine gerettete Datei nicht öffnen, war sie womöglich fragmentiert, sodass nur ihr erster Teil zurückkam. Probieren Sie beide Schaltflächen zum Retten mit dem Image aus.

Ist die Sicherung sehr langsam, liegt das meist am Laufwerk oder an der Verbindung, denn ReviveUSB überspringt schlechte Bereiche bereits. Stecken Sie das Laufwerk direkt in einen USB-3.0-Anschluss auf der Rückseite des PCs statt in einen Hub, tauschen Sie das Kabel oder versuchen Sie es an einem anderen PC. Sichern Sie erneut in dieselbe Image-Datei, dann geht es dort weiter, wo es aufgehört hat. Wenn die Zeit knapp ist, schließen Sie das Programm zwischendurch und führen Dateien retten (Signatur) mit dem bisherigen Image aus. Es stellt Dateien aus dem Teil wieder her, der schon kopiert wurde.

Kommt überhaupt nichts zurück, wurden die gelöschten Dateien möglicherweise mit neuen Daten überschrieben. Überschriebene Daten kann keine Software wiederherstellen, ebenso wenig Daten auf einem Flash-Chip, der ausgefallen ist. Dann bleibt nur ein professioneller Datenrettungsdienst.
