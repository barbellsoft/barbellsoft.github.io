Chatda FAQ

Dieselbe Datei erscheint mehrmals.

Oft liegt dieselbe Datei tatsächlich in mehreren Ordnern, etwa auf einem NAS. Stellen Sie die Gruppierung auf „Nach Ordner“ oder „Nach Version“, um die Liste übersichtlicher zu machen.

Ich sehe keinen Auszug aus dem Dokument.

Möglicherweise unterstützt das Dateiformat keine Inhaltssuche (zum Beispiel Bilder oder ZIP-Dateien). Inhalte werden aus TXT, MD, CSV, DOCX, XLSX, PPTX, PDF und HWPX gelesen. Dateien, die nur über einen Eintrag für ein ganzes Laufwerk wie C:\ erfasst sind, werden nach Namen durchsucht; um auch ihren Inhalt zu durchsuchen, fügen Sie ihren Ordner separat hinzu.

Ich habe gerade eine Datei erstellt, aber sie erscheint nicht.

In einem lokalen Ordner erkennt Chatda sie innerhalb von etwa einer halben Sekunde. Auf einem NAS kann es bis zu fünf Minuten dauern. Wenn es eilt, wählen Sie im Ordnermenü „Neu indexieren“.

Die Suche ist langsam.

Stellen Sie den Suchmodus auf „Nur Name“, das ist am schnellsten. Sie können die Suche auch mit dem Dateitypfilter eingrenzen oder mit dem Ordnerfilter nur einen Ordner durchsuchen.

Wie bekomme ich Updates?

Wenn eine neue Version erscheint, wird beim Start von Chatda oben ein Banner angezeigt. Klicken Sie auf „Installieren“, der Rest läuft automatisch.

Werden Favoriten und letzte Suchen zwischen PCs synchronisiert?

Nein. Jeder Computer speichert seine eigenen.

Ich habe mein NAS-Passwort geändert. Was nun?

Verbinden Sie sich über „Netzwerkordner verbinden“ in der Seitenleiste mit dem neuen Passwort neu.
