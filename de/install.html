Wenn Download oder Installation blockiert wird

Unsere Programme sind neu und noch nicht codesigniert, deshalb kennen Windows und Edge sie nicht. Wählen Sie das Fenster, das so aussieht wie Ihres.

  • Edge behält die Datei nicht„wird nicht häufig heruntergeladen“
  • Ein blaues Fenster erscheint„Der Computer wurde durch Windows geschützt“
  • Die intelligente App-Steuerung hat blockiert„möglicherweise unsicher“
  • Heruntergeladene Datei nicht gefundenOrdner Downloads öffnen

Zuerst die Datei prüfen

Bevor Sie eine Warnung übergehen, prüfen Sie, ob die Datei von uns stammt. Jede Downloadseite nennt ihren SHA-256-Wert. Führen Sie in PowerShell den folgenden Befehl aus und vergleichen Sie.

Get-FileHash .\<file> -Algorithm SHA256

Die intelligente App-Steuerung hat eine möglicherweise unsichere App blockiert.

OK

Dieses Fenster hat keine Schaltfläche, um das Programm trotzdem zu starten. Die intelligente App-Steuerung lässt nur bekannte oder signierte Programme zu, und unsere sind noch nicht signiert.

  1. Öffnen Sie Windows-Sicherheit, dann App- & Browsersteuerung, dann Einstellungen der intelligenten App-Steuerung.
  2. Mit Aus lässt sich das Programm starten. Je nach Windows-Version können Sie die Funktion danach eventuell erst nach dem Zurücksetzen von Windows wieder einschalten. Entscheiden Sie also mit Bedacht.
  3. Wenn Sie sie eingeschaltet lassen möchten, nutzen Sie das Programm auf einem anderen PC oder warten Sie auf signierte Versionen.

Die heruntergeladene Datei ist nicht auffindbar

  1. Drücken Sie Windows-Taste + E, um den Datei-Explorer zu öffnen.
  2. Klicken Sie links auf Downloads. Nach Änderungsdatum sortiert, stehen neue Dateien oben.
  3. In Edge oder Chrome können Sie auch Strg + J drücken und Datei öffnen oder Im Ordner anzeigen wählen.
