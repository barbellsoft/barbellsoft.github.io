Hilfe zu Barbell Launcher

Verwendung

  • Drücken Sie Alt+Space an beliebiger Stelle. Das Suchfeld wird oben auf dem Bildschirm geöffnet.
  • Geben Sie einige Buchstaben ein und drücken Sie Enter. Die erste Zeile ist bereits ausgewählt.
  • Mit ↑ und ↓ wählen Sie eine andere Zeile, mit Esc schließen Sie das Fenster.

Mögliche Eingaben

  • Ein App-Name oder ein Teil davon: ‘excel’, ‘vsc’ für Visual Studio Code. Koreanische Anfangskonsonanten (ㅋㅋㅇ) und Text, der im falschen Eingabemodus (Koreanisch/Englisch) getippt wurde, funktionieren ebenfalls.
  • Eine Rechnung: ‘123+5’, ‘1,500,0003.3%’. Enter kopiert das Ergebnis.
  • Koreanische Büroberechnungen: ‘부가세 110000’, ‘3.3% 1000000’, ‘30평’, ‘1234500’ (Betrag in koreanischen Worten).
  • Datumsangaben: ‘today+30’, ‘+10bd’ (Arbeitstage ohne koreanische Feiertage), ‘12/31’ (D-Day, Monat/Tag), ‘11/1~12/31’.
  • Web: ‘g Suchbegriff’ sucht bei Google, ‘n Suchbegriff’ sucht bei Naver, ‘example.com’ öffnet die Website.
  • Befehle: Sperren, Energie sparen, Einstellungen, Herunterfahren, Neu starten, Abmelden. Herunterfahren, Neu starten und Abmelden erfordern zweimal Enter.

Verknüpfungen und Textbausteine

  • Öffnen Sie „Verknüpfungen verwalten“ über das Symbol im Infobereich. Weisen Sie einer Adresse, einem Ordner oder einem Text ein Schlüsselwort zu und geben Sie dann das Schlüsselwort ein.
  • Fügen Sie {검색어} in eine Adresse ein, um mit den Wörtern nach dem Schlüsselwort zu suchen.
  • Enter auf einem Textbaustein fügt ihn dort ein, wo Sie gerade geschrieben haben.
  • Exportieren Sie eine Datei, um Verknüpfungen mit Ihrem Team zu teilen. Textbausteine sind nur enthalten, wenn Sie sie auswählen.
  • Textbausteine werden unverschlüsselt auf diesem PC gespeichert. Speichern Sie keine Kennwörter.

Ihre Daten bleiben auf diesem PC

  • Was Sie in das Suchfeld eingeben, wird nicht gespeichert.
  • Barbell Launcher speichert nur, wie oft Sie jede App starten, Ihre Einstellungen und Ihre Verknüpfungen.
  • Das Programm stellt von sich aus keine Internetverbindung her. Nur eine Websuchzeile öffnet Ihren Browser.

Wenn es nicht funktioniert

  • Wenn das Tastenkürzel das Suchfeld nicht öffnet, wird es möglicherweise von einem anderen Programm verwendet. Wählen Sie in den Einstellungen ein anderes.
  • Ein Textbaustein kann nicht in ein Fenster eingefügt werden, das als Administrator ausgeführt wird. Er befindet sich in der Zwischenablage. Drücken Sie Ctrl+V.
