Hilfe zu PasteFit

So funktioniert es

  • Kopieren Sie Text oder eine Tabelle (Strg+C).
  • Klicken Sie dorthin, wo Sie einfügen möchten, und drücken Sie die Tastenkombination (Win+Alt+V, wenn Sie sie nicht geändert haben).
  • Ein kleines Fenster zeigt, wie der Text aussehen wird. Drücken Sie die Eingabetaste zum Einfügen oder Esc zum Abbrechen.

Bereinigungsarten

  • Nur den Text übernehmen: entfernt Schriftarten, Farben und Links und bereinigt überzählige Leerzeichen.
  • Zeilenumbrüche reparieren: verbindet Zeilen, die mitten im Satz umbrechen, wie bei aus einem PDF kopiertem Text. Leerzeilen und Listenpunkte bleiben erhalten.
  • In eine Zeile: setzt alles in eine einzige Zeile, für ein Suchfeld, ein Eingabefeld oder eine Zelle.
  • Als Tabelle einfügen: fügt eine Tabelle aus einer Webseite oder aus Excel in Word, Outlook oder einem Browser als saubere Tabelle und in Excel als Zellen ein.

Ihre Zwischenablage bleibt privat

  • Die Zwischenablage wird nur gelesen, wenn Sie die Tastenkombination drücken. Sie wird nicht überwacht.
  • Was Sie kopieren, wird nicht gespeichert, und es gibt keinen Verlauf.
  • Es wird nichts über das Internet gesendet.
  • Wenn ein Passwort-Manager den kopierten Inhalt kennzeichnet, wird er in der Vorschau ausgeblendet.

Wenn nicht automatisch eingefügt wird

  • In ein Fenster, das als Administrator läuft, oder in ein Remotedesktopfenster kann nicht automatisch eingefügt werden. Der bereinigte Text ist in der Zwischenablage, drücken Sie also Strg+V.
  • Nach dem Einfügen bleibt der bereinigte Text in der Zwischenablage. Zum Rückgängigmachen drücken Sie Strg+Z in dem Programm, in das Sie eingefügt haben.
