ReviveUSB Benutzerhandbuch

ReviveUSB rettet Dateien von einem defekten USB-Laufwerk oder einer externen Festplatte und repariert das Laufwerk auf Wunsch, damit Sie es wieder verwenden können. Alles geschieht in einem Fenster: Datenträger auswählen, dann eine Schaltfläche anklicken. Folgen Sie diesem Handbuch von oben nach unten.

0. Schnellstart

  1. Starten Sie ReviveUSB.exe und erlauben Sie Administratorrechte, wenn Windows danach fragt.
  2. Klicken Sie auf Aktualisieren und dann in der Datenträgerliste auf Ihr USB-Laufwerk.
  3. Klicken Sie auf Als Image sichern und speichern Sie das Image auf einem anderen Laufwerk mit genug freiem Speicher.
  4. Klicken Sie auf Dateien retten (Namen/Pfade), wählen Sie das Image und einen Ordner auf einem intakten Laufwerk. Kommt nichts zurück, gehen Sie mit Dateien retten (Signatur) genauso vor.
  5. Erst wenn Sie alle Dateien haben, machen Sie das Laufwerk mit einer der Reparatur-Schaltflächen wieder nutzbar.

Die eine Regel, die zählt: Wenn Sie Ihre Daten zurückwollen, speichern Sie nichts Neues auf das defekte Laufwerk. Erstellen Sie zuerst das Image und stellen Sie aus dem Image wieder her.

Wenn Sie die Daten nicht brauchen und nur das Laufwerk wieder funktionieren soll, überspringen Sie Schritt 3 und 4. Kapitel 7 beschreibt das.

1. Was das Programm tut

Verwenden Sie es, wenn ein Laufwerk in einem dieser Zustände ist:

  • Sie haben versehentlich Dateien gelöscht.
  • Windows meldet beim Anschließen „Sie müssen den Datenträger formatieren, bevor Sie ihn verwenden können“. Das ist ein beschädigtes Dateisystem, angezeigt als RAW.
  • Ein großes Laufwerk erscheint als kleines RAW-Stück oder hat keinen Laufwerksbuchstaben, weil seine Partition beschädigt ist.
  • Das Laufwerk wird erkannt, aber Ihre Dateien sind nicht sichtbar.

Es gibt zwei Ziele, und ein Tool erledigt beide.

Ziel Bedeutung Schaltflächen
Daten zurückholen Gelöschte oder unsichtbare Dateien wiederherstellen Als Image sichern, dann eine der Dateien retten-Schaltflächen
Laufwerk zurückholen Laufwerk neu formatieren, damit es wieder nutzbar ist Prüfen (chkdsk), Formatieren, Neu aufbauen

Die Reihenfolge steht fest: zuerst die Daten retten, dann das Laufwerk reparieren. Wer zuerst repariert, vernichtet die Daten endgültig.

2. Sicherheitsregeln vor dem Start

Was die Wiederherstellung ruiniert, ist das Schreiben auf das defekte Laufwerk. Dieses Programm auszuführen ist unbedenklich, weil Sicherung und Wiederherstellung nur vom Laufwerk lesen.

Der Grund: Wenn Sie eine Datei löschen, bleiben die Daten selbst meist auf dem Laufwerk. Nur der Indexeintrag, der auf sie zeigt, wird entfernt, und genau deshalb ist eine Wiederherstellung überhaupt möglich. Speichern Sie danach eine neue Datei auf das Laufwerk, sieht das System freien Platz dort, wo Ihre alten Daten liegen, und schreibt die neue Datei womöglich direkt darüber. Dann lassen sich die alten Daten nicht mehr retten.

Tun Sie vor der Wiederherstellung nichts davon:

  • Neue Dateien auf dem Laufwerk speichern oder dorthin kopieren.
  • Das Laufwerk formatieren, weder in Windows noch mit den Reparatur-Schaltflächen.
  • Auf Ja klicken, wenn Windows anbietet, das Laufwerk zu prüfen und zu reparieren.

Diese Schaltflächen sind sicher, weil sie nur lesen: Aktualisieren, Zustandsprüfung, Als Image sichern und beide Dateien retten-Schaltflächen.

defektes USB-Laufwerk --(nur lesen)--> disk2.img (Sicherungskopie) --> recovered\ (Ihre Dateien)
   Original unberührt                   mit dieser Kopie arbeiten        Ergebnis

4. Programm starten

4.1 Herunterladen und Datei prüfen

Laden Sie ReviveUSB.exe von der Download-Seite herunter. Die Datei ist noch nicht codesigniert, daher warnen Windows SmartScreen oder Ihr Virenscanner möglicherweise. Prüfen Sie vor dem Start, ob die Datei zum SHA-256 auf der Download-Seite passt. In PowerShell:

Get-FileHash .\ReviveUSB.exe -Algorithm SHA256

Wenn die Hashwerte übereinstimmen und SmartScreen erscheint, wählen Sie Weitere Informationen und dann Trotzdem ausführen.

4.2 Administratorrechte

Das Programm fragt beim Start nach Administratorrechten, weil das direkte Lesen eines Datenträgers sie erfordert. Erlauben Sie es. Oben im Fenster steht dann Administrator: EIN. Steht dort AUS, klicken Sie auf Als Administrator neu starten.

Während ein Vorgang läuft, sind die Aktions-Schaltflächen ausgegraut, und Fortschrittsbalken und Protokoll werden laufend aktualisiert. Eine Stopp-Schaltfläche gibt es nicht. Um eine Sicherung anzuhalten, schließen Sie das Fenster; Kapitel 5 erklärt, wie Sie später fortsetzen.

5. Ein Laufwerk in fünf Schritten retten

Schritt 1. Laufwerk auswählen

Schließen Sie das Laufwerk an und klicken Sie auf Aktualisieren. Klicken Sie in der Liste auf Ihr Laufwerk. Das Protokoll bestätigt, welchen Datenträger Sie gewählt haben, zum Beispiel Datenträger 2 ausgewählt: SanDisk Ultra.

Achten Sie auf die Spalte Dateisystem. RAW bedeutet, dass das Dateisystem beschädigt ist.

Sie können jetzt auf Zustandsprüfung klicken. Sie zeigt den Status des Laufwerks und, sofern das Laufwerk sie ausgibt, SMART-Zähler wie Verschleiß und nicht korrigierbare Lesefehler. Viele USB-Laufwerke reichen keine SMART-Daten durch; das Protokoll sagt es dann.

Schritt 2. Als Image sichern

Klicken Sie auf Als Image sichern. Wählen Sie den Speicherort für das Image auf einem anderen Laufwerk mit genug freiem Speicher. Der vorgeschlagene Name ist diskN.img, wobei N die Datenträgernummer ist.

Das Original-Laufwerk wird nur gelesen. Defekte Bereiche werden schnell übersprungen, sodass die Kopie weiterläuft, statt hängen zu bleiben. Der Fortschrittsbalken zeigt den Prozentsatz und wie viel schon kopiert ist.

Konnten manche Bereiche nicht gelesen werden, fragt das Programm, ob es sie sektorweise erneut versuchen soll. Das kann mehr von Ihren Daten retten, bei einem stark beschädigten Laufwerk aber lange dauern. Schließen Sie das Fenster während des erneuten Versuchs, sichern Sie später erneut in dieselbe Datei, dann wird der Versuch fortgesetzt. Eine erneute Sicherung in ein fertiges Image liest nie wieder das ganze Laufwerk: Sie bietet nur an, die unlesbaren Bereiche erneut zu versuchen. Um neu zu beginnen, wählen Sie einen neuen Dateinamen.

Wählen Sie einen Ort auf dem Laufwerk, das Sie retten, lehnt das Programm ab und verlangt ein anderes Laufwerk. Speichern dort könnte die Dateien überschreiben, die Sie zurückwollen.

Sie können jederzeit durch Schließen des Fensters anhalten. Der Fortschritt wird alle zwei Sekunden gespeichert. Zum Fortsetzen starten Sie das Programm erneut, wählen dasselbe Laufwerk, klicken auf Als Image sichern und wählen dieselbe Datei. Fragt Windows, ob sie ersetzt werden soll, antworten Sie mit Ja: Das Protokoll zeigt Image wird fortgesetzt, und die Kopie macht dort weiter, wo sie aufgehört hat. Das Programm prüft, ob es dasselbe Laufwerk ist. Gehört die Datei zu einem anderen Laufwerk oder meldet das Laufwerk jetzt eine andere Größe, bricht es ab, statt die frühere Kopie zu vermischen oder zu überschreiben; wählen Sie in diesem Fall einen neuen Dateinamen.

Schritt 3. Dateien aus dem Image retten

Es gibt zwei Schaltflächen. Versuchen Sie zuerst Dateien retten (Namen/Pfade) und verwenden Sie Dateien retten (Signatur), wenn dabei nichts gefunden wird.

  1. Klicken Sie auf die Schaltfläche.
  2. Wählen Sie Ihre Imagedatei (.img).
  3. Wählen Sie einen Ordner für die geretteten Dateien auf einem intakten Laufwerk. Ein Ordner auf dem Laufwerk, das Sie retten, wird abgelehnt. Hat das Laufwerk mehrere Partitionen, landen die Dateien jeder Partition in einem eigenen Unterordner wie volume2_exfat.

Die Namen/Pfade-Methode kopiert alle Dateien, die sie findet, nicht nur gelöschte. Genau das brauchen Sie, wenn Windows meldet, dass auf das Laufwerk „nicht zugegriffen werden kann“, oder verlangt, es zu formatieren: Die Dateien sind meist noch da und kommen mit ihren Namen zurück. Findet sie sowohl aktuelle als auch gelöschte Dateien, landen die gelöschten in einem eigenen Ordner _deleted_files, damit eine alte Kopie nie neben der aktuellen Datei liegt. Der Zielordner braucht so viel freien Speicher, wie die Dateien belegen; reicht er nicht, warnt das Protokoll vor dem Start. Auf einem FAT32-Laufwerk, auf dem Windows Dateien gelöscht hat, kann das Protokoll Dateien auflisten, die „falschen Inhalt haben können“: Windows hat einen Teil ihrer Startposition gelöscht, und bei Typen wie .bin gibt es keine Signatur, um die richtige Stelle zu erkennen. Öffnen Sie diese Dateien, bevor Sie sich darauf verlassen.

Dateien retten (Namen/Pfade) Dateien retten (Signatur)
Ergebnis Dateinamen, Ordnerpfade und Inhalte Nur Inhalte, benannt nach laufender Nummer wie jpg_00001_@...
Funktioniert mit NTFS, FAT32 und exFAT Jedem Laufwerk, auch ohne Dateisystem
Am besten, wenn Das Dateisystem noch lesbar ist, auch wenn Windows das Laufwerk nicht öffnet Das Dateisystem selbst zerstört ist
Reihenfolge Zuerst versuchen Verwenden, wenn die erste nichts findet

Versuchen Sie zuerst die Namen/Pfade-Methode, auch wenn das Laufwerk als RAW angezeigt wird. Windows zeigt RAW immer dann, wenn es das Dateisystem nicht einbinden kann, auch wenn darin nur ein einziger Wert falsch ist, und das Programm kann es oft trotzdem lesen und die Dateien mit ihren Namen zurückholen. Meldet die Methode, dass sie das Dateisystem nicht erkennt, oder findet sie nichts, verwenden Sie die Signatur-Methode.

Die Signatur-Methode findet JPEG-, PNG-, GIF-, BMP-, PDF- und ZIP-Dateien sowie MP4-, MOV-, 3GP-, M4A- und HEIC-Dateien (Videos von Handys und Dashcams, iPhone-Fotos). Office-Dateien wie docx, xlsx und pptx sind intern ZIP-Dateien und kommen daher mit der Endung .zip zurück; benennen Sie sie mit der richtigen Endung um. Ein Video, dessen Ende nie geschrieben wurde (eine abgebrochene Aufnahme oder ein Laufwerk, das Daten verloren hat), wird so weit gespeichert, wie es reicht, aber die meisten Player können es ohne das fehlende Ende nicht abspielen.

Ist in der Liste ein Datenträger ausgewählt, fragt das Programm zuerst, ob es direkt von diesem Datenträger lesen soll. Klicken Sie auf Nein, um Ihre Image-Datei auszuwählen, oder auf Ja, um den Datenträger selbst zu lesen. Das direkte Lesen braucht Administratorrechte und ist für ein defektes Laufwerk riskanter, daher ist ein Image die bessere Wahl.

Schritt 4. Laufwerk reparieren (erst nach der Wiederherstellung)

Wählen Sie das Laufwerk und verwenden Sie eine der Reparatur-Schaltflächen. Kapitel 7 erklärt, welche Sie nehmen. Formatieren und Neu aufbauen löschen Daten, daher verlangt das Programm, dass Sie ein Bestätigungswort exakt eintippen, zum Beispiel FORMAT E. Vergewissern Sie sich, dass Sie alles gerettet haben, bevor Sie sie verwenden.

Bevor Prüfen (chkdsk), Formatieren oder Neu aufbauen etwas schreibt, prüft das Programm das Laufwerk nur lesend. Zeigt das Laufwerk Anzeichen, dass sein Controller ausfällt, repariert es nicht und nennt den Grund im Protokoll. Die Anzeichen sind: Das Laufwerk reagiert nicht auf Lesezugriffe oder meldet eine Größe von 0, oder ein Teil des Laufwerks konnte nicht gelesen werden. Bei FAT32-Laufwerken prüft es außerdem, ob das Dateisystem das Laufwerk größer angibt, als es wirklich ist, ob die beiden Kopien der Dateitabelle (FAT) an vielen Stellen voneinander abweichen und ob die Hälfte oder mehr der Stellen, an denen Dateien liegen sollten, leer gelesen werden. Die Reparatur lässt sich dann nicht erzwingen. Eine Reparatur schreibt viel, und ein ausfallendes Laufwerk kann mitten in einem großen Schreibvorgang ganz aufhören zu arbeiten. Holen Sie Ihre Dateien mit Schritt 2 und 3 zurück und ersetzen Sie das Laufwerk. Ein Laufwerk, das nur als RAW erscheint, weil sein Dateisystem nicht erkannt wird, wird nicht blockiert. Dieselbe Prüfung läuft, wenn Sie ohne Datenrettung reparieren (Kapitel 7).

Schritt 5. Dateien zurückbringen (nach der Reparatur)

Die ganze Reihenfolge lautet: Daten retten, die geretteten Dateien auf dem PC aufbewahren, das Laufwerk reparieren und dann die Dateien auf das reparierte Laufwerk zurückbringen. Dieser Schritt ist der letzte Teil. Er prüft außerdem, ob das Laufwerk Daten wirklich speichert, bevor Sie ihm wieder vertrauen.

Wenn Formatieren oder Neu aufbauen fertig ist, steht im Protokoll: auf Aktualisieren klicken, dann Laufwerk testen, dann Dateien zurückkopieren. Beide Schaltflächen stehen in der Zeile Nach der Reparatur: und arbeiten mit dem Laufwerksbuchstaben des gewählten Datenträgers. Sie brauchen keine Administratorrechte.

  1. Klicken Sie auf Aktualisieren und wählen Sie das reparierte Laufwerk. Es kann einen neuen Laufwerksbuchstaben haben.
  2. Klicken Sie auf Laufwerk testen. Wählen Sie Ja, um den ganzen freien Speicher zu testen, oder Nein für einen schnellen Test mit 1 GB (Abbrechen tut nichts). Der volle Test ist langsam, findet aber Laufwerke, die eine falsche Kapazität vortäuschen. Das Programm schreibt Testdaten in einen Ordner _revive_test auf dem Laufwerk, liest sie am Windows-Cache vorbei zurück, vergleicht sie und löscht den Ordner dann. Ein Ordner, den ein früher abgebrochener Test hinterlassen hat, wird ebenfalls gelöscht. Wird das Laufwerk voll, hört das Schreiben dort auf, und die bis dahin geschriebenen Daten werden geprüft.
  3. Lesen Sie das Ergebnis im Protokoll. Bei Erfolg steht dort, wie viel ohne Fehler geschrieben und zurückgelesen wurde. Bei einem Fehlschlag steht dort, wie viel nicht korrekt zurückgelesen wurde; ersetzen Sie das Laufwerk. Kamen später geschriebene Daten an der Stelle früherer Daten zurück, meldet das Protokoll, dass das Laufwerk vermutlich nur etwa eine bestimmte Menge fasst, weniger als angegeben. Das ist ein Laufwerk mit gefälschter Kapazität. Legen Sie Ihre Dateien nicht darauf. Hört das Laufwerk während des Tests auf zu reagieren, nennt das Protokoll, nach wie vielen Daten es stehen blieb, und dass das Laufwerk Daten nicht zuverlässig speichern kann. Legen Sie Ihre Dateien nicht darauf, sondern ersetzen Sie es.
  4. Klicken Sie auf Dateien zurückkopieren und wählen Sie den Ordner auf Ihrem PC mit den geretteten Dateien. Ein Ordner auf demselben Laufwerk wird abgelehnt. Hat das Laufwerk nicht genug freien Speicher, meldet das Programm das, bevor es etwas schreibt. Es kopiert alles mit derselben Ordnerstruktur, außer den Ordnern System Volume Information und $RECYCLE.BIN auf oberster Ebene, die Windows selbst neu anlegt.
  5. Nach dem Kopieren liest das Programm jede Datei vom Laufwerk zurück, wieder am Cache vorbei, und vergleicht ihre SHA-256-Prüfsumme mit dem Original. Stimmt alles überein, sagt das Protokoll das. Wurden einige Dateien nicht gleich zurückgelesen, listet das Protokoll sie auf und meldet, dass das Laufwerk Daten nicht zuverlässig speichert. Bewahren Sie keine wichtigen Dateien auf diesem Laufwerk auf.

Behalten Sie die geretteten Dateien auch nach erfolgreichem Kopieren auf Ihrem PC, damit Sie weiterhin eine zweite Kopie haben.

7. Ein Laufwerk reparieren, wenn Sie die Daten nicht brauchen

Brauchen Sie die Dateien nicht und soll ein defektes USB-Laufwerk oder eine externe Festplatte nur wieder einsatzbereit werden, überspringen Sie Sicherung und Wiederherstellung und reparieren Sie direkt.

7.1 Zuerst diagnostizieren

Klicken Sie auf Aktualisieren, wählen Sie das Laufwerk und sehen Sie sich Liste und Protokoll an. Ein echtes Beispiel von einer externen WD-Festplatte: Die Liste zeigte 3,6 TB, Status Healthy/Online und nur ein 200-MB-RAW-Stück ohne Laufwerksbuchstaben.

So lesen Sie das: Der Status Healthy/Online bedeutet, dass die Hardware funktioniert und nur die Partitionsstruktur defekt ist. Das kann Software meist reparieren. Zeigt ein großes Laufwerk nur ein kleines RAW-Stück oder keinen Laufwerksbuchstaben, ist seine Hauptpartition verloren.

7.2 Reparatur wählen, von sanft bis stark

Symptom Schaltfläche Funktion
Laufwerksbuchstabe vorhanden, Dateien beschädigt oder Lesefehler Prüfen (chkdsk) Behebt Dateisystemfehler und behält die Daten
Laufwerksbuchstabe vorhanden, Sie wollen es leeren Formatieren Formatiert nur das Volume neu
RAW, kein Laufwerksbuchstabe, beschädigte Partitionen Neu aufbauen Löscht den ganzen Datenträger und legt ihn neu an. Das ist die übliche Lösung

Prüfen (chkdsk) und Formatieren brauchen einen Laufwerksbuchstaben. Hat das Laufwerk keinen, verweist das Programm auf Neu aufbauen. chkdsk kann auch kein RAW-Laufwerk reparieren, weil kein Dateisystem mehr da ist.

7.3 Ein RAW-Laufwerk wiederbeleben

Das ist der häufigste Fall. Wählen Sie das Laufwerk, klicken Sie auf Neu aufbauen und tippen Sie auf Nachfrage ERASE DISK 2 (mit Ihrer Datenträgernummer). Das dauert meist einige Sekunden bis eine Minute. Danach erhält das Laufwerk einen neuen Laufwerksbuchstaben. Bevor Sie ihm wieder Dateien anvertrauen, klicken Sie auf Aktualisieren, wählen das Laufwerk und führen Laufwerk testen aus. Schritt 5 in Kapitel 5 erklärt das Ergebnis und wie Sie Ihre Dateien zurückbringen.

Das neue Dateisystem ist NTFS, das Windows lesen und schreiben kann. Brauchen Sie das Laufwerk an einem Mac oder einem anderen Gerät, formatieren Sie es danach mit diesem Gerät oder mit dem Formatierungsdialog von Windows neu.

7.4 Aufräumen

Haben Sie früher ein Image erstellt und brauchen es nicht mehr, löschen Sie die Imagedatei und die Fortschrittsdatei daneben, zum Beispiel disk2.img und disk2.img.state.json.

7.5 Wenn die Reparatur scheitert

  1. Trennen Sie das Laufwerk, schließen Sie es wieder an, klicken Sie auf Aktualisieren und versuchen Sie es erneut. Windows hält den Datenträger womöglich gesperrt.
  2. Schließen Sie alles, was das Laufwerk noch verwenden könnte, etwa Virenscanner oder Explorer-Vorschauen.
  3. Scheitert es weiterhin, bleibt der Status Unhealthy oder taucht das Laufwerk immer wieder auf und verschwindet, ist wahrscheinlich die Hardware defekt. Das kann Software nicht beheben; erwägen Sie einen Austausch des Laufwerks.

7.6 Das Risiko eines erneuten Ausfalls senken

Keine Software kann garantieren, dass ein Laufwerk nicht wieder ausfällt. Die Zustandsprüfung liest die Zähler, die das Laufwerk über sich selbst führt: umgeleitete Sektoren, Lesefehler und Verschleiß. Nicht korrigierbare Lese- oder Schreibfehler oder hoher Verschleiß bedeuten ein hohes Risiko eines erneuten Ausfalls; ein Austausch wird empfohlen.

Viele USB-Gehäuse reichen wegen Einschränkungen des Bridge-Chips keine SMART-Daten durch. Die Zustandsprüfung meldet dann, dass das Laufwerk keine SMART-Daten ausgibt. Ein Spezialtool wie CrystalDiskInfo kann sie unter Umständen trotzdem lesen.

Einige Grundsätze:

  • Software umgeht Zellen, die bereits defekt sind. Die physische Lebensdauer des Laufwerks kann sie nicht verlängern.
  • Bewahren Sie die einzige Kopie wichtiger Daten nie auf einem Laufwerk auf, das schon einmal ausgefallen ist. Halten Sie immer eine zweite Sicherung.
  • Wird das Laufwerk kurz nach einem Neuaufbau wieder RAW oder trennt es sich ständig, tauschen Sie es aus.

8. Fehlerbehebung

Die Datenträgerliste ist leer

Das Protokoll meldet Keine Datenträger gefunden. Prüfen Sie, ob das Laufwerk angeschlossen ist und in der Windows-Datenträgerverwaltung erscheint, und klicken Sie dann erneut auf Aktualisieren. Ist es kein USB-Laufwerk, kreuzen Sie Interne Datenträger anzeigen (Vorsicht) an.

Die Liste zeigt "Firmware-Fehler (ROM-Modus)" oder "Kein Speicher (0)"

Der Controller des USB-Sticks konnte seine Firmware nicht laden, oder das Laufwerk meldet keinen Speicher. Windows zeigt ein solches Laufwerk meist als "Kein Medium" oder als Datenträger mit 0 Byte an und fragt vielleicht, ob es formatiert werden soll; wählen Sie dann Abbrechen. Wenn Sie das Laufwerk auswählen, öffnet sich unter der Datenträgerliste ein Feld Diagnose. Es zeigt die Geräte-ID, den vermutlichen Controller und die nächsten Schritte. Solange das Laufwerk in diesem Zustand ist, sind Sicherung, Wiederherstellung und Reparatur ausgeschaltet, denn es gibt nichts zu lesen oder zu schreiben.

  1. Ziehen Sie das Laufwerk ab und stecken Sie es wieder an. Das Feld prüft alle 5 Sekunden von selbst erneut (Sie können auch auf Erneut prüfen klicken). Kommt das Laufwerk mit seinem normalen Namen zurück, schreiben Sie nichts darauf, sondern sichern Sie es zuerst. Das Feld bleibt offen, meldet die Rückkehr und zeigt die Schaltflächen Als Image sichern und Laufwerk testen (ganzer freier Platz). Reparatur und Dateien zurückkopieren bleiben für dieses Laufwerk ausgeschaltet, bis es Laufwerk testen über den ganzen freien Speicher besteht, auch wenn Sie das Feld schließen, weil ein großer Schreibvorgang es wieder stoppen kann.
  2. Kommt es nicht zurück, kann ReviveUSB es nicht wiederbeleben, und seine Dateien lassen sich nicht lesen. Sind die Dateien wichtig, kann ein Datenrettungslabor den Speicherchip eventuell direkt auslesen; andernfalls ersetzen Sie das Laufwerk. ReviveUSB empfiehlt keine Fertigungswerkzeuge (Mass-Production-Tools): Bei dem Laufwerk, das wir getestet haben, haben sie nicht funktioniert, und sie werden nicht offiziell verteilt.
  3. Ist es in Schritt 1 zurückgekommen und möchten Sie es weiter benutzen, sichern Sie es zuerst und führen dann Laufwerk testen über den ganzen freien Speicher aus. Besteht der Test ohne Fehler, werden Reparatur und Dateien zurückkopieren für dieses Laufwerk eingeschaltet, und das Feld schließt sich von selbst. Ein schneller 1-GB-Test schaltet sie nicht ein.

Diagnose kopieren kopiert den Text des Felds, damit Sie ihn einfügen können, wenn Sie um Hilfe bitten. Schließen Sie das Feld mit ×.

Manche Geräte erscheinen grau als "Leer (0)". Dann meldet ein Gerät, das das Programm nicht kennt, keinen Speicher, und ein leerer Steckplatz eines Kartenlesers sieht meist genau so aus. Das ist kein Defekt: Stecken Sie eine Karte ein. Zeigt ein USB-Stick das an, ziehen Sie ihn ab und stecken Sie ihn wieder ein. Sicherung, Wiederherstellung und Reparatur bleiben so lange aus, weil es nichts zu lesen gibt.

Die Sicherung ist sehr langsam (zum Beispiel eine Schätzung von 100 Stunden oder mehr)

Das Programm überspringt defekte Bereiche bereits, daher liegt eine Verlangsamung meist am Laufwerk oder an der Verbindung. Ist die Geschwindigkeit von Anfang bis Ende niedrig (einige hundert KB/s), versuchen Sie Folgendes der Reihe nach:

  1. Schließen Sie das Laufwerk direkt an einen USB-3.0-Anschluss (blau) auf der Rückseite des PCs an. Vermeiden Sie Hubs und Verlängerungskabel.
  2. Tauschen Sie das Kabel.
  3. Versuchen Sie einen anderen PC.

Um den Anschluss zu wechseln, schließen Sie ReviveUSB, stecken das Laufwerk um und sichern erneut in dieselbe Imagedatei. Es geht dort weiter, wo es aufgehört hat.

Das Laufwerk wird als RAW angezeigt

Windows kann das Dateisystem nicht lesen, das Programm aber oft schon. Sichern Sie das Laufwerk als Image und versuchen Sie zuerst Dateien retten (Namen/Pfade); findet das nichts, verwenden Sie Dateien retten (Signatur). Machen Sie das Laufwerk nach der Wiederherstellung mit Neu aufbauen wieder nutzbar.

„Dateisystem nicht erkannt“

Die Namen/Pfade-Methode versteht nur NTFS, FAT32 und exFAT, und der Dateisystemindex muss lesbar sein. Verwenden Sie stattdessen Dateien retten (Signatur). (Die Meldung kann Befehlszeilennamen wie carve oder --fs verwenden; im Fenster ist die Signatur-Schaltfläche dasselbe.)

„Dieser Vorgang erfordert Administratorrechte“

Klicken Sie auf Ja, um das Programm als Administrator neu zu starten, oder schließen Sie es und starten Sie es erneut, wobei Sie die Windows-Abfrage erlauben.

Wiederhergestellte Dateien lassen sich nicht öffnen

Die Datei war womöglich fragmentiert, sodass nur ihr erster Teil gerettet wurde. Versuchen Sie beide Wiederherstellungs-Schaltflächen. Unlesbare Teile des Laufwerks fehlen im Image, und Dateien, die dort lagen, kommen nicht vollständig zurück.

9. FAQ

F. Ich will das USB-Laufwerk retten. Was bedeutet also „nicht darauf schreiben“? A. Es bedeutet, keine neuen Daten auf dem Laufwerk zu speichern. Dieses Programm auszuführen ist unbedenklich, weil Sicherung und Wiederherstellung nur lesen. Siehe Kapitel 2.

F. Kann das das Original-Laufwerk beschädigen? A. Sicherung und Wiederherstellung lesen nur. Nur die Reparatur-Schaltflächen ändern das Original, und sie verlangen vorher eine Bestätigung.

F. Lassen sich Dateinamen wiederherstellen? A. Dateien retten (Namen/Pfade) stellt Namen und Ordner wieder her. Dateien retten (Signatur) stellt nur Inhalte wieder her und benennt die Dateien nach laufender Nummer.

F. Mein Laufwerk hat 114 GB. Muss ich alles als Image sichern? A. Eine vollständige Sicherung ist die sichere Wahl. Fehlt Ihnen die Zeit, können Sie das Programm zwischendurch schließen und Dateien retten (Signatur) auf das bisherige Image anwenden; es rettet Dateien aus dem bereits kopierten Teil.

F. Gibt es Fälle, in denen eine Wiederherstellung unmöglich ist? A. Ja. Wenn die Daten überschrieben wurden oder der Flash-Chip selbst defekt ist, kann Software nicht helfen. Dann ist ein professioneller Datenrettungsdienst die Lösung.

10. Glossar

Begriff Bedeutung
Image (.img) Eine byte-genaue Kopie des Laufwerks in einer Datei. Sie arbeiten mit dieser Kopie statt mit dem Original
RAW Der Dateisystemindex ist defekt, daher kann Windows das Laufwerk nicht lesen
Signatursuche (Carving) Eine Datei anhand ihres inhaltlichen Fingerabdrucks (Magic Bytes) wiederherstellen
Namen/Pfade-Wiederherstellung (Undelete) Den Dateisystemindex lesen, um Dateien mit Namen und Pfaden wiederherzustellen
Defekter Sektor Ein Speicherbereich, der sich nicht lesen lässt. Die Sicherung überspringt und protokolliert ihn
Sektor und Cluster Die kleinste Speichereinheit (meist 512 Byte) und eine Gruppe von Sektoren
Administratorrechte Die Windows-Berechtigung für den direkten Zugriff auf einen Datenträger
