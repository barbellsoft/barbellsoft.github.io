YAML-in-JSON-Konverter (und JSON in YAML)

Fügen Sie YAML oder JSON ein und wählen Sie die Richtung.

Gut zu wissen

  • YAML wird mit dem YAML-1.2-Core-Schema gelesen. Datumsangaben und Wörter wie yes oder on bleiben Text, Merge-Schlüssel (<<) werden angewendet.
  • Benutzerdefinierte Tags (!name) und mehrere durch --- getrennte Dokumente werden nicht unterstützt und ergeben einen Fehler.
  • Kommentare bleiben nicht erhalten. Ganze Zahlen über 9007199254740991 in JSON können an Genauigkeit verlieren.

Dieses Tool überträgt die eingegebenen Texte und Dateien nicht.
