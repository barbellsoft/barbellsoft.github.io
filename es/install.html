Cuando la descarga o la instalación se bloquea

Nuestros programas son nuevos y aún no tienen firma de código, así que Windows y Edge no los reconocen. Elija la ventana que se parezca a la que ve.

Compruebe el archivo primero

Antes de saltarse una advertencia, asegúrese de que el archivo es el que publicamos. Cada página de descarga muestra su SHA-256. En PowerShell, ejecute el comando de abajo y compare.

Get-FileHash .\<file> -Algorithm SHA256

Control inteligente de aplicaciones bloqueó el programa

Se ha bloqueado parte de esta aplicación

Control inteligente de aplicaciones bloqueó una aplicación que puede no ser segura.

OK

Esta ventana no tiene un botón para ejecutar el programa de todas formas. Control inteligente de aplicaciones solo permite programas conocidos o firmados, y los nuestros aún no lo están.

  1. Abra Seguridad de Windows, luego Control de aplicaciones y navegador, luego Configuración de Control inteligente de aplicaciones.
  2. Si elige Desactivado, el programa se puede ejecutar. Según la versión de Windows, es posible que no pueda volver a activarlo sin restablecer Windows, así que decida con cuidado.
  3. Si prefiere mantenerlo activado, use el programa en otro PC o espere a que nuestros programas estén firmados.

No encuentra el archivo descargado

  1. Pulse la tecla Windows + E para abrir el Explorador de archivos.
  2. Pulse Descargas en el panel izquierdo. Ordenados por Fecha de modificación, los nuevos están arriba.
  3. En Edge o Chrome también puede pulsar Ctrl + J y luego Abrir archivo o Mostrar en carpeta.
