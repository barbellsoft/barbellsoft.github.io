Conversor de YAML a JSON (y de JSON a YAML)

Pega YAML o JSON y elige la dirección.

Conviene saber

  • El YAML se lee con el esquema core de YAML 1.2. Las fechas y palabras como yes u on se quedan como texto, y las claves de fusión (<<) se aplican.
  • No se admiten etiquetas personalizadas (!nombre) ni varios documentos separados por ---; muestran un error.
  • Los comentarios no se conservan. Los enteros mayores que 9007199254740991 en JSON pueden perder precisión.

Esta herramienta no envía el texto ni los archivos que introduces.
