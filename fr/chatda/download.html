Le plus simple sur Mac, sans avertissement de sécurité :

  1. Appuyez sur Commande (⌘) + Espace pour ouvrir Spotlight, tapez Terminal et appuyez sur Retour.
  2. Cliquez sur Copier ci-dessous, cliquez dans la fenêtre du Terminal, appuyez sur Commande (⌘) + V pour coller, puis sur Retour.
  3. Patientez environ une minute. Chatda s'installe dans Applications et s'ouvre tout seul.
curl -fsSL https://github.com/barbellsoft/chatda-releases/releases/latest/download/install.sh | bash

Si Windows affiche un avertissement

Chatda n'est pas encore signé numériquement, donc Windows SmartScreen peut indiquer qu'il ne reconnaît pas l'application. Vérifiez que le fichier est bien celui publié ici en comparant son SHA-256 dans PowerShell :

Get-FileHash .\Chatda_x64-setup.exe -Algorithm SHA256

Si la valeur correspond, choisissez Informations complémentaires, puis Exécuter quand même. Chatda s'installe pour tous les utilisateurs avec son service d'indexation des lecteurs, c'est pourquoi l'installation et les mises à jour demandent l'accord d'un administrateur. Sur Mac, si Chatda ne peut pas être ouvert, cliquez sur Terminé, ouvrez Réglages Système > Confidentialité et sécurité, faites défiler vers le bas, cliquez sur Ouvrir quand même, puis rouvrez Chatda.
