FAQ de Chatda

Le même fichier apparaît plusieurs fois.

Souvent, le même fichier existe réellement dans plusieurs dossiers, par exemple sur un NAS. Réglez le regroupement sur « Par dossier » ou « Par version » pour mettre de l'ordre dans la liste.

Je ne vois pas d'extrait du document.

Le format du fichier ne prend peut-être pas en charge la recherche dans le contenu (images ou fichiers ZIP, par exemple). Le contenu est lu dans les fichiers TXT, MD, CSV, DOCX, XLSX, PPTX, PDF et HWPX. Les fichiers couverts uniquement par une entrée de disque entier comme C:\ sont recherchés par leur nom ; pour rechercher dans leur contenu, ajoutez leur dossier séparément.

Je viens de créer un fichier et il n'apparaît pas.

Dans un dossier local, Chatda le détecte en une demi-seconde environ. Sur un NAS, cela peut prendre jusqu'à cinq minutes. Si vous êtes pressé, choisissez « Réindexer » dans le menu du dossier.

La recherche est lente.

Passez le mode de recherche sur « Nom uniquement », le plus rapide. Vous pouvez aussi affiner la recherche avec le filtre de type de fichier ou chercher dans un seul dossier avec le filtre de dossier.

Comment obtenir les mises à jour ?

Quand une nouvelle version sort, une bannière apparaît en haut au démarrage de Chatda. Cliquez sur « Installer » et le reste se fait automatiquement.

Les favoris et les recherches récentes sont-ils synchronisés entre PC ?

Non. Chaque ordinateur conserve les siens.

J'ai changé le mot de passe de mon NAS. Que faire ?

Reconnectez-vous avec le nouveau mot de passe via « Connecter un dossier réseau » dans la barre latérale.
