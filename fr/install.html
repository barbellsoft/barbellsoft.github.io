Quand le téléchargement ou l’installation est bloqué

Nos programmes sont récents et pas encore signés, donc Windows et Edge ne les reconnaissent pas. Choisissez la fenêtre qui ressemble à la vôtre.

Vérifiez d’abord le fichier

Avant de passer outre un avertissement, vérifiez que le fichier est bien celui que nous publions. Chaque page de téléchargement indique son SHA-256. Dans PowerShell, exécutez la commande ci-dessous et comparez.

Get-FileHash .\<file> -Algorithm SHA256

Supprimer

  1. Dans le volet des téléchargements en haut à droite, pointez le fichier et cliquez sur ··· (trois points).
  2. Cliquez sur Conserver.
  3. Dans la fenêtre qui s’ouvre, ne cliquez pas sur Supprimer. Cliquez sur Afficher plus.
  4. Cliquez sur Conserver quand même. Le fichier est enregistré et vous pouvez l’ouvrir.

Le contrôle intelligent des applications a bloqué le programme

Une partie de cette application a été bloquée

Le contrôle intelligent des applications a bloqué une application potentiellement dangereuse.

OK

Cette fenêtre n’a pas de bouton pour lancer le programme quand même. Le contrôle intelligent des applications n’autorise que les programmes connus ou signés, et les nôtres ne le sont pas encore.

  1. Ouvrez Sécurité Windows, puis Contrôle des applications et du navigateur, puis Paramètres du contrôle intelligent des applications.
  2. Si vous choisissez Désactivé, le programme peut se lancer. Selon la version de Windows, vous ne pourrez peut-être pas le réactiver sans réinitialiser Windows : décidez avec prudence.
  3. Si vous préférez le garder activé, utilisez le programme sur un autre PC ou attendez nos versions signées.

Vous ne trouvez pas le fichier téléchargé

  1. Appuyez sur Windows + E pour ouvrir l’Explorateur de fichiers.
  2. Cliquez sur Téléchargements à gauche. Triés par Date de modification, les nouveaux fichiers sont en haut.
  3. Dans Edge ou Chrome, vous pouvez aussi appuyer sur Ctrl + J puis cliquer sur Ouvrir le fichier ou Afficher dans le dossier.
