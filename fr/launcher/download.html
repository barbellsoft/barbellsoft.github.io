Si Windows affiche un avertissement

Barbell Launcher n’est pas encore signé, Windows SmartScreen peut donc indiquer qu’il ne reconnaît pas l’application. Vérifiez que le fichier est bien celui publié ici en comparant son SHA-256 dans PowerShell :

Get-FileHash .\BarbellLauncher.exe -Algorithm SHA256

Si la valeur correspond, choisissez « Informations complémentaires », puis « Exécuter quand même ». Barbell Launcher n’a pas besoin de droits administrateur.
