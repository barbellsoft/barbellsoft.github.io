Aide de Barbell Launcher

Utilisation

  • Appuyez sur Alt+Space n’importe où. La zone de recherche s’ouvre en haut de l’écran.
  • Saisissez quelques lettres et appuyez sur Enter. La première ligne est déjà sélectionnée.
  • Utilisez ↑ et ↓ pour choisir une autre ligne, et Esc pour fermer.

Ce que vous pouvez saisir

  • Le nom d’une application, en entier ou en partie : ‘excel’, ‘vsc’ pour Visual Studio Code. Les consonnes initiales coréennes (ㅋㅋㅇ) et le texte saisi dans le mauvais mode coréen/anglais fonctionnent aussi.
  • Un calcul : ‘123+5’, ‘1,500,0003.3%’. Enter copie le résultat.
  • Calculs de bureau coréens : ‘부가세 110000’, ‘3.3% 1000000’, ‘30평’, ‘1234500’ (montant en toutes lettres en coréen).
  • Dates : ‘today+30’, ‘+10bd’ (jours ouvrés, hors jours fériés coréens), ‘12/31’ (jours restants, mois/jour), ‘11/1~12/31’.
  • Web : ‘g mots’ recherche sur Google, ‘n mots’ recherche sur Naver, ‘example.com’ ouvre le site.
  • Commandes : verrouiller, mettre en veille, paramètres, arrêter, redémarrer, se déconnecter. Arrêter, redémarrer et se déconnecter nécessitent d’appuyer deux fois sur Enter.

Raccourcis et extraits

  • Ouvrez ‘Gérer les raccourcis’ depuis l’icône de la zone de notification. Associez un mot-clé à une adresse, un dossier ou un texte, puis saisissez ce mot-clé.
  • Insérez {검색어} dans une adresse pour rechercher les mots saisis après le mot-clé.
  • Enter sur un extrait le colle là où vous étiez en train de saisir.
  • Exportez un fichier pour partager les raccourcis avec votre équipe. Les extraits ne sont inclus que si vous les choisissez.
  • Les extraits sont enregistrés sur ce PC sans chiffrement. N’enregistrez pas de mots de passe.

Vos données restent sur ce PC

  • Ce que vous saisissez dans la zone de recherche n’est pas enregistré.
  • Barbell Launcher enregistre uniquement le nombre de lancements de chaque application, vos paramètres et vos raccourcis.
  • Il ne se connecte pas à Internet de lui-même. Seule une ligne de recherche web ouvre votre navigateur.

En cas de problème

  • Si le raccourci clavier n’ouvre pas la zone de recherche, un autre programme l’utilise peut-être. Choisissez-en un autre dans Paramètres.
  • Impossible de coller un extrait dans une fenêtre exécutée en tant qu’administrateur. Il se trouve dans le Presse-papiers : appuyez sur Ctrl+V.
