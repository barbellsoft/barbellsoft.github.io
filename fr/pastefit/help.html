Aide de PasteFit

Mode d’emploi

  • Copiez du texte ou un tableau (Ctrl+C).
  • Cliquez là où vous voulez coller et appuyez sur le raccourci (Win+Alt+V si vous ne l’avez pas modifié).
  • Une petite fenêtre montre le résultat. Appuyez sur Entrée pour coller ou sur Échap pour annuler.

Façons de nettoyer

  • Conserver uniquement le texte : supprime les polices, les couleurs et les liens, et nettoie les espaces en trop.
  • Corriger les retours à la ligne : réunit les lignes coupées au milieu d’une phrase, comme dans un texte copié depuis un PDF. Les lignes vides et les éléments de liste restent.
  • Mettre sur une ligne : met tout sur une seule ligne, pour une zone de recherche, un champ de saisie ou une cellule.
  • Coller en tableau : colle un tableau d’une page web ou d’Excel sous forme de tableau propre dans Word, Outlook ou un navigateur, et sous forme de cellules dans Excel.

Votre Presse-papiers reste privé

  • Il lit le Presse-papiers uniquement quand vous appuyez sur le raccourci. Il ne surveille pas le Presse-papiers.
  • Il n’enregistre pas ce que vous copiez et ne garde aucun historique.
  • Il n’envoie rien sur Internet.
  • Si un gestionnaire de mots de passe marque ce que vous avez copié, l’aperçu le masque.

Quand il ne colle pas tout seul

  • Il ne peut pas coller tout seul dans une fenêtre exécutée en tant qu’administrateur ni dans une fenêtre Bureau à distance. Le texte nettoyé est dans le Presse-papiers : appuyez sur Ctrl+V.
  • Après le collage, le texte nettoyé reste dans le Presse-papiers. Pour annuler, appuyez sur Ctrl+Z dans le programme où vous avez collé.
