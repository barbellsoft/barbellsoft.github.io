Si Windows affiche un avertissement

ReviveFix n'est pas encore signé numériquement, donc Windows SmartScreen peut indiquer qu'il ne reconnaît pas l'application. Vérifiez que le fichier est bien celui publié ici en comparant son SHA-256 dans PowerShell :

Get-FileHash .\ReviveFix.exe -Algorithm SHA256

Si la valeur correspond, choisissez Informations complémentaires, puis Exécuter quand même. ReviveFix démarre sans droits d'administrateur. Windows ne les demande que lorsqu'une réparation en a besoin, par exemple pour démarrer le spouleur d'impression.
