Our programs are new and not code-signed yet, so Windows and Edge don't recognize them. Pick the window that looks like what you see.

Check the file first

Before you click past a warning, make sure the file is the one we published. Each download page lists its SHA-256. In PowerShell, run the command below and compare.

Get-FileHash .\<file> -Algorithm SHA256

Smart App Control blocked the program

Part of this app has been blocked

Smart App Control blocked an app that may be unsafe.

OK

This window has no button to run the program anyway. Smart App Control allows only programs it already knows or that are signed, and ours are not signed yet.

  1. Open Windows Security, then App & browser control, then Smart App control settings.
  2. If you choose Off, the program can run. Depending on your Windows version, you may not be able to turn Smart App Control back on without resetting Windows, so decide carefully.
  3. If you'd rather keep it on, use the program on another PC, or wait until our programs are signed.

You can't find the downloaded file

  1. Press Windows key + E to open File Explorer.
  2. Click Downloads in the left pane. New files are at the top when sorted by Date modified.
  3. In Edge or Chrome you can also press Ctrl + J and click Open file or Show in folder.
