USBメモリが0バイト・メディアなしと表示されたら、復元できるもの

USB メモリを挿しても何も開かない。ディスクの管理にディスクは表示されているものの、「メディアなし」になっているか、サイズが 0 バイトになっている。Windows がフォーマットを求めてくることもあります。「キャンセル」を選んでください。

ドライブが本当に容量がないと報告しているなら、ReviveUSB も含め、どんなソフトウェアでも読み取れません。それでも試す価値のあることはいくつかありますし、見た目は似ていても、ずっと望みのあるケースもあります。

似て見える 2 つの問題

まず、Windows が表示しているサイズを確認します。

0 バイトまたはメディアなしと表示される場合は、USB メモリを動かしている小さなチップ、つまりコントローラーが自分のファームウェアを読み込めなかったか、ドライブが容量をまったく報告していません。この状態が変わらない限り、どんなプログラムにも読み取れるものはありません。

ドライブが本来の容量を表示しているのにドライブ文字がない、またはエクスプローラーに何も表示されない場合は、ドライブは応答しており、損傷はたいていパーティションかファイルシステムにあります。ReviveUSB のマニュアルには外付けドライブの例が載っています。3.6 TB、状態は Healthy/Online で、ドライブ文字のない 200 MB の RAW 領域が 1 つだけ、というものです。Healthy/Online は、ハードウェアは動いていて壊れているのはパーティション構造だけ、という意味で、これはたいていソフトウェアで対処できます。

0 バイトのドライブで ReviveUSB に表示されるもの

ReviveUSB は、故障しかけた USB ドライブのための無料の Windows ツールです。Windows 10 または 11 (64 ビット) で動き、インストール不要の exe ファイル 1 つで、ディスクを直接読み取るため管理者権限が必要です。まだコード署名されていないため、SmartScreen が警告することがあります。ダウンロードページにファイルの SHA-256 が載っているので、詳細情報、続けて 実行 を選ぶ前に、PowerShell で Get-FileHash .\ReviveUSB.exe -Algorithm SHA256 を実行して確認できます。

更新 をクリックしてディスクの一覧を確認します。この状態の USB メモリは「ファームウェア故障(ROM モード)」または「容量なし(0)」と表示されます。選択すると一覧の下に 診断 ボックスが開き、デバイス ID、推定されるコントローラー、次にすることが表示されます。誰かに助けを求めたい場合は、診断をコピー でその内容をコピーできます。

このドライブでは、バックアップ、復元、修復はすべてオフになります。読み書きできるものがないからです。

一覧に灰色で「空(0)」と表示される場合は、多くの場合カードリーダーの空きスロットです。カードを挿してください。USB メモリでこう表示される場合は、抜いてもう一度挿してください。

まだ試せること

ドライブを抜いて、もう一度挿します。診断 ボックスは 5 秒ごとに自動で再確認しますが、再確認 をクリックしてもかまいません。

ドライブが元の名前で戻ってきたら、何も書き込まず、修復も実行しないでください。すぐにバックアップします。

  1. イメージにバックアップ をクリックし、USB メモリの容量と同じだけの空きがある別のドライブにイメージを保存します。ReviveUSB はドライブを読み取るだけで、読み取れない領域は止まらずに飛ばします。途中でやめる必要があればウィンドウを閉じてください。後で同じファイルにもう一度バックアップすると、止まったところから続きます。
  2. ファイル復元(名前・パス) をクリックし、イメージを選んで、正常なドライブ上のフォルダーを指定します。ファイルシステムが読み取れれば、ファイルは名前とフォルダーごと戻ります。何も見つからない場合は、同じイメージで ファイル復元(シグネチャ) を使います。写真、動画、PDF、ZIP ファイルを中身から探しますが、名前は戻りません。

USB メモリをまた使うことを考えるのは、ファイルを安全な場所に移してからにしてください。この状態から戻ったドライブでは、空き領域全体で ドライブテスト に合格するまで、修復と ファイルを書き戻す はオフのままです。1 GB のクイックテストではオンになりません。このようなドライブは大量に書き込むとまた止まることがあるため、全体のテストを先に行います。

データ復旧業者しか手がないとき

ドライブが戻らない場合、ReviveUSB では復活させられず、ファイルもソフトウェアでは読み取れません。大事なファイルなら、データ復旧業者がメモリチップを直接読み取れることがあります。そうでなければ、ドライブを交換してください。

USB メモリに工場用のツール(量産ツール)を使うよう勧める情報を見かけることがあるかもしれません。ReviveUSB はおすすめしません。テストしたドライブでは効果がなく、公式に配布されているものでもないからです。

同じ限界は、もっと広い範囲にも当てはまります。データが上書きされている場合や、フラッシュチップそのものが壊れている場合はソフトウェアでは手の打ちようがなく、残る手段はデータ復旧の専門業者です。

サイズは正しいのにドライブ文字がない場合

この場合は打てる手が増えます。まずは Windows の標準機能から始めましょう。ディスクの管理を開いてボリュームを確認します。通常のファイルシステムが表示されていて、ドライブ文字がないだけなら、右クリックして「ドライブ文字とパスの変更」を選び、文字を追加できます。これはファイルに影響しません。途中で Windows がフォーマットを求めてきたら、「キャンセル」を選んでください。

ボリュームが RAW と表示される場合や、大容量のドライブが小さな RAW 領域だけを表示して残りが未割り当てになっている場合は、パーティションかファイルシステムが損傷しています。その場合は上と同じ順番で進めます。イメージにバックアップ をしてから、そのイメージで ファイル復元(名前・パス) を実行します。ReviveUSB は NTFS、FAT32、exFAT を自分で読み取り、Windows がマウントを拒むファイルシステムでも読めることがよくあります。削除されたファイルだけでなく、見つけたファイルをすべてコピーし、削除されていたものは別の _deleted_files フォルダーに入ります。それで何も見つからなければ、ファイル復元(シグネチャ) を試してください。

ファイルが PC に入ったら、ドライブを修復できます。パーティションが損傷した RAW ドライブには、通常は 完全再構築 を使います。ディスク全体を消去するので、先に ERASE DISK とディスク番号を入力するよう求められます。検査(chkdsk) と フォーマット にはドライブ文字が必要で、そもそも chkdsk は RAW ドライブを修復できません。修復でドライブに書き込む前に、ReviveUSB はドライブを読み取り、応答しない、サイズが 0 と報告されるといった、コントローラーが壊れかけている兆候がないか調べます。兆候が見つかれば修復はせず、理由をログに表示します。

それでもうまくいかないとき

復元したファイルが開けない場合は、断片化していて先頭部分しか戻らなかったか、読み取れなかった領域にあった可能性があります。両方の復元ボタンを試してください。

ドライブが表示されたり消えたりを繰り返す場合や、再構築してすぐにまた RAW になる場合は、ハードウェアが故障しかけている可能性が高いです。ドライブを交換し、大事なものはもう 1 つ別にコピーを持っておいてください。各ボタンの説明はマニュアルに、よくある疑問はよくある質問にあります。
