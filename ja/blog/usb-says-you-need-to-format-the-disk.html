USBメモリに「フォーマットする必要があります」と出たら、先にデータを救出

動画で見たい方は 1 分の解説動画を YouTube で見る。

昨日まで使えていた USB メモリを挿したら、Windows に「ドライブ E: を使うにはフォーマットする必要があります。フォーマットしますか?」と表示され、ディスクのフォーマット と キャンセル のボタンが出た。そんなときは キャンセル をクリックしてください。

もう手遅れのように聞こえるメッセージですが、たいていはドライブそのものが壊れたのではなく、ドライブ上のファイルシステムが傷んでいるという意味です。Windows はファイルの一覧を記録した索引を読めないので、フォーマットを勧めてくるのです。ファイルはたいていまだ残っています。ファイルを危険にさらすのは、むしろフォーマットのほうです。

何が起きているのか

どのドライブにも、どのファイルがどこにあるかを記録した索引があります。これがファイルシステムです。Windows はこのファイルシステムをマウントできないと、ドライブを RAW と表示します。索引の中の値が 1 つ違うだけでもそうなります。大容量のドライブが小さな RAW 領域として表示される、またはドライブ文字がまったくない場合は、パーティション自体が損傷しています。

いつもの応急処置が効かないのもこのためです。chkdsk は存在するファイルシステムを修復するものですが、RAW ドライブには chkdsk が読めるファイルシステムがないので、直す対象がありません。

まだしてはいけないこと

ファイルを安全な場所に移すまでは、ドライブに手を加えないでください。

  • Windows でもほかの場所でも、フォーマットしない。
  • Windows に「スキャンして修復しますか?」と聞かれても、「スキャンおよび修復」をクリックしない。
  • 新しいものを保存したりコピーしたりしない。

索引が損傷しても、データそのものは普通は元の場所に残っています。そこに何か新しいものを書き込むと、Windows が古いファイルのちょうど上に置いてしまうことがあり、そうなるともう何をしても戻りません。ドライブから読み取るだけなら問題ありません。

ReviveUSB でファイルを取り戻す

ReviveUSB は、ドライブをコピーし、そのコピーから復元し、ドライブの修復はそのあと、という順番を前提に作られた無料の Windows ツールです。Windows 10 または 11 (64 ビット) で動き、ディスクを直接読み取るため管理者権限が必要です。

壊れたドライブと同じだけの空き容量が、別のドライブに必要です。128 GB の USB メモリなら 128 GB の空きが要ります。

ReviveUSB はまだコード署名されていないため、SmartScreen が「認識されないアプリ」として警告することがあります。ダウンロードページにファイルの SHA-256 が載っています。PowerShell で Get-FileHash .\ReviveUSB.exe -Algorithm SHA256 を実行して確認し、一致したら 詳細情報、続けて 実行 を選んでください。

1. ドライブを選ぶ

ReviveUSB.exe を実行し、管理者権限を許可します。ウィンドウの上部に 管理者権限: オン と表示されるはずです。更新 をクリックし、一覧で USB メモリをクリックします。ファイルシステム の列はおそらく RAW になっています。

2. ドライブをイメージにコピーする

イメージにバックアップ をクリックし、disk2.img のような名前で別のドライブに保存します。ここで ReviveUSB は USB メモリを読み取るだけです。読み取れない領域は飛ばすのでコピーが止まらず、最後にその領域をセクター単位で再試行するか尋ねます。

ウィンドウを閉じて、後で続きをすることもできます。もう一度 イメージにバックアップ をクリックし、同じファイルを選んで、置き換えるか聞かれたら「はい」と答えます。ログに イメージ作成を再開 と表示され、止まったところからコピーが続きます。

ここから先はイメージを使って作業します。壊れかけた USB メモリを何度も読むより、そのコピーを読むほうが安全です。

3. 名前付きでファイルを復元する

ファイル復元(名前・パス) をクリックし、イメージファイルを選んで、正常なドライブ上のフォルダーを指定します。復元中のドライブ上のフォルダーは ReviveUSB が受け付けません。

Windows が RAW と表示していても、これを試してください。ReviveUSB は NTFS、FAT32、exFAT を読み取れ、Windows がマウントしないファイルシステムでも読めることがよくあります。うまくいけば、ファイルは名前とフォルダーごと戻ります。削除したファイルだけでなく見つかったファイルをすべてコピーし、削除されていたものは別の _deleted_files フォルダーに入ります。

4. 何も見つからなければシグネチャ方式を使う

ReviveUSB がファイルシステムを認識できなかったと表示する、または何も見つからない場合は、ファイル復元(シグネチャ) をクリックし、同じイメージを使います。この方法はファイルシステムを無視し、中身からファイルを探します。見つけられるのは JPEG、PNG、GIF、BMP、PDF、ZIP ファイルと、MP4、MOV、3GP、M4A、HEIC (スマートフォンやドライブレコーダーの動画、スマートフォンの写真) です。

その代わり、名前は失われます。ファイルは jpg_00001_@... のような通し番号付きで戻ります。.docx、.xlsx、.pptx などの文書は中身が ZIP ファイルなので、.zip として戻ります。正しい拡張子に名前を変えてください。

そのあとで USB メモリを直す

ファイルが PC に無事に保存できたら、USB メモリを使える状態に戻せます。RAW のドライブやドライブ文字のないドライブは、選択して 完全再構築 をクリックします。ディスクを消去して新しいパーティションを作り、NTFS でフォーマットします。確認のため ERASE DISK とディスク番号を入力します (例: ERASE DISK 2)。ドライブ文字が残っていて、中身を消すだけでよい場合は フォーマット で足ります。

ReviveUSB は書き込む前にドライブを読み取り、コントローラーが壊れかけていないか確認します。一部が読み取れなかった場合などがそうです。その兆候があれば修復はせず、理由をログに表示します。壊れかけたドライブは大きな書き込みの途中で完全に止まることがあるので、その場合は復元したファイルを手元に残し、USB メモリは交換してください。

再構築が終わったら、更新 をクリックしてドライブを選び、ドライブテスト をクリックします。はい なら空き領域全体を、いいえ なら 1 GB の簡易テストを行います。容量を偽装したドライブを見つけられるのは全体のテストだけです。合格したら、ファイルを書き戻す で復元したフォルダーを USB メモリに戻し、すべてのファイルを読み戻して元のファイルと比べます。それでも PC 上のコピーは残しておいてください。

うまくいかないとき

一覧に「ファームウェア故障(ROM モード)」または「容量なし(0)」と表示される

USB メモリのコントローラーが起動していません。Windows では「メディアなし」や 0 バイトと表示され、それでもフォーマットを求められることがあります。「キャンセル」をクリックしてください。抜いて差し直します。元の名前で戻ってきたら、すぐにバックアップしてください。戻らない場合、ソフトウェアでは読み取れません。データ復旧業者ならメモリチップを直接読み取れることがあります。

バックアップがとても遅い

ハブや延長ケーブルを使わず、PC 背面の USB 3.0 ポートに直接差してください。それでも改善しなければ、別のケーブルや別の PC で試します。同じイメージファイルにもう一度バックアップすれば、コピーの続きから再開します。

復元したファイルが開けない

ファイルが断片化していて、先頭部分しか戻らなかった可能性があります。両方の復元ボタンを試してください。ドライブの読み取れなかった部分はイメージに含まれていません。

修復に失敗する

ドライブを抜いて差し直してからもう一度試し、ウイルス対策ソフトやエクスプローラーのプレビューなど、ドライブを使っていそうなものを閉じてください。状態が Unhealthy のまま、またはドライブの接続が何度も切れる場合は、ハードウェアが故障しかけている可能性が高いです。ソフトウェアでは直せないので、ドライブを交換してください。

どうにもならないとき

復元できないファイルもあります。データがすでに上書きされている場合や、フラッシュチップそのものが壊れている場合は、どんなソフトウェアでも手の打ちようがなく、残る手段はデータ復旧の専門業者です。各ボタンの説明は ReviveUSB のマニュアルにあります。
