ダウンロードやインストールがブロックされたとき

私たちのプログラムは新しく、まだコード署名がないため、Windows と Edge が見慣れないファイルとして扱います。いま表示されている画面に近いものを選んでください。

  • Edge で保存できない「一般的にダウンロードされていません」
  • 青い画面が出た「Windows によって PC が保護されました」
  • スマート アプリ コントロールにブロックされた「安全でない可能性のあるアプリ」
  • ダウンロードしたファイルが見つからないダウンロード フォルダーを開く

まずファイルを確認

警告を進める前に、私たちが公開したファイルか確認してください。各ダウンロード ページに SHA-256 があります。PowerShell で次のコマンドを実行して比べてください。

Get-FileHash .\<file> -Algorithm SHA256

スマート アプリ コントロールにブロックされた

このアプリの一部がブロックされました

スマート アプリ コントロールが、安全でない可能性のあるアプリをブロックしました。

OK

この画面には、それでも実行するボタンがありません。スマート アプリ コントロールは既知のプログラムか署名されたプログラムだけを許可し、私たちのプログラムにはまだ署名がありません。

  1. Windows セキュリティ → アプリとブラウザー コントロール → スマート アプリ コントロールの設定 を開きます。
  2. オフにするとプログラムを実行できます。Windows のバージョンによっては、一度オフにすると Windows をリセットするまで再びオンにできないことがあるので、慎重に決めてください。
  3. オンのままにしたい場合は、別の PC で使うか、署名版が出るまでお待ちください。

ダウンロードしたファイルが見つからない

  1. Windows キー + E でエクスプローラーを開きます。
  2. 左側のダウンロードを押します。更新日時の順に並べると、新しいファイルが一番上にあります。
  3. Edge や Chrome では Ctrl + J を押し、ファイルを開く、またはフォルダーに表示を押しても構いません。
