Barbell Launcher ヘルプ

使い方

  • どこでも Alt+Space を押すと、画面の上部に検索ボックスが開きます。
  • 数文字入力して Enter を押します。最初の行はあらかじめ選択されています。
  • ↑ と ↓ で別の行を選び、Esc で閉じます。

入力できるもの

  • アプリ名またはその一部: 「excel」、Visual Studio Code なら「vsc」。ハングルの初声（ㅋㅋㅇ）や、韓/英の入力モードを切り替えずに入力した文字でも検索できます。
  • 計算: 「123+5」、「1,500,0003.3%」。Enter で結果をコピーします。
  • 韓国の事務計算: 「부가세 110000」（付加価値税）、「3.3% 1000000」（源泉徴収）、「30평」（坪）、「1234500」（金額のハングル表記）。
  • 日付: 「today+30」、「+10bd」（営業日、韓国の祝日を除く）、「12/31」（残り日数、月/日）、「11/1~12/31」。
  • Web: 「g 検索語」は Google、「n 検索語」は Naver で検索し、「example.com」はそのサイトを開きます。
  • コマンド: lock（ロック）、sleep（スリープ）、settings（設定）、shutdown（シャットダウン）、restart（再起動）、sign out（サインアウト）。シャットダウン、再起動、サインアウトは Enter を 2 回押す必要があります。

ショートカットと定型文

  • トレイ アイコンから「ショートカットの管理」を開きます。アドレス、フォルダー、文章にキーワードを付け、そのキーワードを入力します。
  • アドレスに {검색어} を入れると、キーワードの後に入力した語句で検索します。
  • 定型文で Enter を押すと、入力していた場所に貼り付けます。
  • ファイルにエクスポートしてチームとショートカットを共有できます。定型文は選んだ場合のみ含まれます。
  • 定型文はこの PC に暗号化せずに保存されます。パスワードは保存しないでください。

データはこの PC にのみ保存されます

  • 検索ボックスに入力した内容は保存されません。
  • Barbell Launcher が保存するのは、アプリごとの起動回数、設定、ショートカットだけです。
  • 自動でインターネットに接続することはありません。ブラウザーを開くのは Web 検索の行だけです。

動作しないとき

  • ショートカット キーを押しても検索ボックスが開かない場合は、別のプログラムが使用している可能性があります。設定で別のキーを選んでください。
  • 管理者として実行されているウィンドウには定型文を貼り付けられません。クリップボードにあるので Ctrl+V を押してください。
