動作環境
Windows 10 または 11 (64 ビット)。一部の修正だけ管理者権限が必要で、そのとき Windows が確認します。

ダウンロード

Windows 10 / 11 用 64 ビット exe 7.9 MB

ダウンロード ReviveFix.exe

SHA-256 deb6f1b56beee24647ddd7b69dc6a94a516f8d377f9bf4da408ac94fd3d47cea

ダウンロードが始まります。使ってみて役に立ったら、コーヒー 1 杯で開発を支えてください。寄付は、Windows の警告をずっと少なくするコード署名証明書に使います。 寄付で応援する

Windows が警告を表示した場合

ReviveFix はまだコード署名されていないため、Windows SmartScreen が「認識されないアプリ」と表示することがあります。PowerShell で SHA-256 を比べて、ここで公開しているファイルと同じか確認してください:

Get-FileHash .\ReviveFix.exe -Algorithm SHA256

値が一致したら、「詳細情報」を選んでから「実行」を選びます。ReviveFix は管理者権限なしで起動し、印刷スプーラーの起動など管理者権限が必要な修正のときだけ Windows が確認します。

コード署名証明書（年間約 200 米ドル）があれば、この警告はずっと少なくなります。 寄付で応援する
