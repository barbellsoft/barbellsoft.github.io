ブラウザーで使える無料ツール

どのツールもブラウザーの中で動作します。ツールは、入力した内容やファイルを送信しません。

  • 文字数カウント
    スペース込み・なしの文字数、単語数、行数、バイト数を数えます。余分な空白や空行を削除し、PDF からコピーして途中で切れた行をつなぎます。
  • 販売利益計算ツール
    販売価格、仕入原価、モールの手数料、送料を入力すると、入金額・利益・利益率がわかります。目標利益率を入れると、必要な販売価格も計算します。
  • 時給・年収換算ツール
    時給を週給・月給・年収に、年収を時給に換算します。週の労働時間と年間の週数で計算し、税金は差し引きません。
  • 画像圧縮
    写真を WebP や JPG で保存し直して、ファイルサイズを小さくします。画質とサイズを選べます。ツールはブラウザーの中で動作し、写真を送信しません。
  • 画像を指定サイズに圧縮
    応募フォームなどの容量制限（20KB、50KB、100KB など）に合わせて写真を圧縮します。制限内でいちばん高い画質を探します。ツールは写真を送信しません。
  • PDF 結合・ページ抽出
    複数の PDF を 1 つにまとめたり、必要なページだけを新しい PDF として保存したりできます。ツールはブラウザーの中で動作し、ファイルを送信しません。
  • QR コード作成
    リンクやテキストを QR コードにして、PNG または SVG で保存します。ツールはブラウザーの中で動作し、入力した内容を送信しません。
  • YAML ↔ JSON 変換
    YAML を JSON に、JSON を YAML にブラウザーで変換し、結果をコピーできます。YAML のエラーは行番号を表示します。ツールは入力した内容を送信しません。
  • USB エラーガイド
    USB メモリや SD カードで「フォーマットする必要があります」、RAW、書き込み禁止、0 バイト、ドライブが認識されない、といった状態が何を意味するのか、まず何を試すべきか、復元ソフトで助かる場合と助からない場合を説明します。
  • USB 容量計算ツール
    パッケージに書かれた容量を入力すると、Windows で表示される容量がわかります。1000 と 1024 の違い、ファイルシステムが使う領域、容量を偽ったドライブの確かめ方も説明します。
