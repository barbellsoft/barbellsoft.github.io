USB メモリと SD カードのエラーメッセージ：意味と対処法

表示されているメッセージや症状を下から探してください。それぞれに、よくある原因、対処法、そして Windows 用の無料復元ツール ReviveUSB で助かる場合と助からない場合を載せています。

どのメッセージでも、必要なファイルがドライブに入っているなら、フォーマットしない、chkdsk を実行しない、新しいものを何も保存しない、を守ってください。まずドライブ全体をコピーし、そのコピーから復元し、修復は最後に行います。

このページのメッセージ

  • 「ドライブを使うにはフォーマットする必要があります」
  • ドライブが RAW と表示される
  • 0 バイト、または「メディアなし」
  • ドライブが認識されない、ドライブ文字がない
  • 「ディスクは書き込み禁止になっています」
  • 復元したファイルが開かない
  • 新しく買った安いドライブでファイルが消える・壊れる

「ドライブを使うにはフォーマットする必要があります」

よくある原因
Windows がドライブのファイルシステムを読み取れない状態です。取り外し操作をせずに抜いた、書き込み中に電源が切れた、ドライブが故障しかけている、といったことの後によく起こります。ファイルはまだ残っていることが多いです。
対処法
キャンセルを押してください。フォーマットすると、取り戻したいファイルが上書きされることがあります。まずドライブ全体をイメージファイルにコピーし、そのイメージから別のドライブにファイルを復元し、フォーマットはその後に行います。
ReviveUSB でできること
ReviveUSB は「イメージにバックアップ」でドライブをイメージに保存し (ドライブは読み取るだけです)、NTFS、FAT32、exFAT から、現在のファイルと削除されたファイルを名前とフォルダーごと復元します。名前が読み取れない場合は、写真、動画、PDF、ZIP ファイルを中身から見つけます。後で使う「フォーマット」と「完全再構築」も同じウィンドウにあります。
できないこと
データが上書きされている場合や、フラッシュメモリのチップ自体が壊れている場合は、どんなソフトでも取り戻せません。そのときはデータ復旧の専門業者に頼るしかありません。

手順を詳しく説明したガイド： USBメモリに「フォーマットする必要があります」と出たら、先にデータを救出

ドライブが RAW と表示される

よくある原因
エクスプローラーやディスクの管理でファイルシステムが RAW と表示される状態です。Windows がパーティションやファイルシステムを認識できていません。chkdsk を実行すると、RAW ドライブには使用できないと表示されます。
対処法
chkdsk は読み取れるファイルシステムのないドライブを修復できないので、何度も試さないでください。先にファイルを復元し、その後でパーティションとファイルシステムを作り直します。
ReviveUSB でできること
ReviveUSB は NTFS、FAT32、exFAT を自分で読み取るので、Windows がマウントしないファイルシステムでも読めることがよくあります。まずイメージに対して「ファイル復元(名前・パス)」を試してください。その後、「完全再構築」でパーティションとファイルシステムを作り直せます。
できないこと
ReviveUSB でもファイルシステムを検出できない場合、「ファイル復元(シグネチャ)」で写真、動画、PDF、ZIP ファイルは見つかりますが、名前とフォルダーは戻りません。

手順を詳しく説明したガイド： USBメモリ・SDカードがRAWになったら、修復の前にデータを復元

0 バイト、または「メディアなし」

よくある原因
ディスクの管理にディスクは表示されるものの、サイズが 0 バイトか「メディアなし」になっている状態です。ドライブを動かす小さなチップであるコントローラーがファームウェアを読み込めなかったか、ドライブが記憶領域をまったく提供していません。
対処法
フォーマットを求められたらキャンセルしてください。ドライブを抜いて差し直し、別のポートや PC でも試します。本来のサイズで戻ってきたら、何も書き込まず、すぐにバックアップしてください。
ReviveUSB でできること
このようなドライブには、ReviveUSB が「診断」ボックスを表示し、デバイス ID、推定コントローラー、次にすることを示して、5 秒ごとに確認し直します。ドライブが戻ってきたらバックアップし、そのイメージから復元します。
できないこと
ドライブが記憶領域を提供していない間は読み取るものがないので、バックアップ、復元、修復は使えません。最後まで戻らない場合は、データ復旧の専門業者がチップの読み取りを試みるしかありません。

手順を詳しく説明したガイド： USBメモリが0バイト・メディアなしと表示されたら、復元できるもの

ドライブが認識されない、ドライブ文字がない

よくある原因
エクスプローラーに何も表示されない、または Windows が USB デバイスを認識できないと表示する状態です。原因は、ポート、ケーブル、ドライブ文字の割り当て漏れ、パーティションの損傷、ドライブの故障などが考えられます。
対処法
ドライブを別のポート (できれば PC 背面のポート) に直接差し、別のケーブルや PC でも試してください。ディスクの管理を開き、ディスクが本来の容量で表示されているのにドライブ文字がなければ、ドライブは応答しており、損傷はたいていパーティションかファイルシステムにあります。まったく表示されない場合は、接続かハードウェアの問題です。
ReviveUSB でできること
ディスクが本来の容量で表示されていれば、ReviveUSB はドライブ文字ではなくディスクそのものを扱うので、ドライブ文字がなくてもバックアップし、そのイメージから復元できます。
できないこと
どのポートや PC でもディスクの管理にディスクが表示されない場合は、どんなプログラムもアクセスできません。

手順を詳しく説明したガイド： USBメモリが0バイト・メディアなしと表示されたら、復元できるもの

「ディスクは書き込み禁止になっています」

よくある原因
SD カードや一部のアダプターには、側面に小さなロックスイッチがあります。ディスクの読み取り専用属性や Windows のポリシーが書き込みを止めていることもあります。フラッシュメモリの中には、故障し始めると自分で読み取り専用モードに切り替わるものもあります。
対処法
まずロックスイッチを確認してください。それでも書き込めない場合は、読み取れるうちにファイルをコピーし、ドライブを交換します。勝手に読み取り専用に戻ってしまうドライブに、新しいファイルを預けてはいけません。
ReviveUSB でできること
バックアップと復元はドライブを読み取るだけなので、書き込み禁止のドライブでもイメージにコピーし、そこからファイルを復元できます。
できないこと
ReviveUSB には書き込み禁止を解除する機能はなく、修復機能はドライブへの書き込みが必要です。

復元したファイルが開かない

よくある原因
ファイルは戻ったものの、壊れている状態です。写真が途中から灰色になる、動画が再生できない、などです。データが上書きされていた、ファイルが断片化して保存されていた、ドライブの一部が読み取れなかった、といった原因が考えられます。
対処法
同じイメージから、もう一方の方法で復元し直してください。結果は、復元しているドライブとは別のドライブに保存します。
ReviveUSB でできること
ReviveUSB には 2 つの復元方法があります。「ファイル復元(名前・パス)」はファイルシステムを読み取り、名前とフォルダーを保ちます。「ファイル復元(シグネチャ)」はファイルを中身から見つけます。イメージは読み取るだけなので、同じイメージで両方を試しても失うものはありません。
できないこと
上書きされたデータは戻りません。また、ドライブの読み取れなかった部分はイメージにも含まれていません。

手順を詳しく説明したガイド： 復元したファイルが開けない・壊れているときに試すこと

新しく買った安いドライブでファイルが消える・壊れる

よくある原因
実際より大きな容量を報告するドライブがあります。本当の容量を超えてコピーしたファイルは失われるか、前のファイルを上書きします。エラーメッセージが出ないことも多いです。
対処法
まず容量計算ツールで、表示されている容量なら Windows にどれだけ表示されるはずかを確認してください。そのうえで、書き込みと読み取りで検証するツールでドライブ全体をテストしてから使います。
ReviveUSB でできること
修復の後、ReviveUSB の「ドライブテスト」は空き領域全体にテストデータを書き込み、Windows のキャッシュを通さずに読み戻して比較します。容量を偽るドライブを見つけられるのは、空き領域全体のテストです。
できないこと
容量を偽ったドライブを本物にできるプログラムはありません。ファイルを入れないでください。
