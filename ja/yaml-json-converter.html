YAML JSON 変換：YAML を JSON に、JSON を YAML に

YAML か JSON を貼り付けて、変換の向きを選んでください。

知っておくこと

  • YAML は YAML 1.2 のコアスキーマで読み込みます。日付や yes・on などの値は文字列のまま残し、マージキー（<<）は展開します。
  • 独自タグ（!名前）と --- で区切った複数のドキュメントには対応しておらず、エラーになります。
  • コメントは残りません。JSON で 9007199254740991 より大きい整数は精度が落ちることがあります。
