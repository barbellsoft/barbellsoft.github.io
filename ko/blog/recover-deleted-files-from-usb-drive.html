USB 메모리에서 지운 파일 복구하는 방법

USB 메모리에서 폴더를 지운 뒤 되살리려고 휴지통을 열었는데 보이지 않습니다. 정상입니다. Windows는 USB 메모리에서 지운 파일을 휴지통으로 보내지 않습니다. 어느 드라이브에서든 Shift+Delete를 누른 것처럼 바로 지워집니다.

그렇다고 파일이 사라진 것은 아닙니다. 대부분은 아직 드라이브에 남아 있고, 지금부터 무엇을 하느냐에 따라 얼마나 되찾을지가 갈립니다.

파일을 지우면 실제로 일어나는 일

드라이브에는 어떤 파일이 어디에 어떤 이름으로 저장되어 있는지 적어 둔 색인, 곧 파일시스템이 있습니다. 파일을 지워도 데이터 자체는 대개 드라이브에 남습니다. 그 데이터를 가리키던 색인 항목만 지워지며, 복구가 가능한 이유도 바로 이것입니다.

문제는 그 파일이 차지하던 공간이 이제 빈 공간으로 취급된다는 점입니다. 드라이브에 새 파일을 저장하면 Windows가 옛 데이터 바로 위에 쓸 수 있고, 그렇게 되면 옛 데이터는 되살릴 수 없습니다. 지운 뒤 드라이브에 많이 쓸수록 되찾는 것은 줄어듭니다.

지금 바로 할 일

파일을 안전한 곳에 옮기기 전까지는 드라이브에 아무것도 저장하거나 복사해 넣지 마세요. 복구 프로그램과 복구한 파일도 마찬가지입니다. 포맷도 하지 말고, Windows가 드라이브를 검사하고 복구하겠다고 하면 예를 누르지 마세요.

드라이브를 읽는 것은 괜찮습니다. 아직 시작할 준비가 안 됐다면 드라이브를 꺼내 뽑아 두세요. 그래야 그사이 아무것도 드라이브에 쓰이지 않습니다.

ReviveUSB로 파일 되찾기

ReviveUSB는 정해진 순서대로 일하는 무료 Windows 프로그램입니다. 먼저 드라이브 전체를 이미지 파일로 복사하고, 그다음 그 사본에서 파일을 복구합니다. 백업과 복구는 드라이브를 읽기만 합니다. Windows 10 또는 11(64비트)에서 실행되고, 설치할 필요 없는 exe 파일 하나이며, 디스크를 직접 읽기 때문에 관리자 권한이 필요합니다.

이미지는 드라이브를 통째로 복사한 것이라, USB 드라이브 용량만큼의 빈 공간이 다른 드라이브에 있어야 합니다. 128 GB 드라이브라면 128 GB가 비어 있어야 합니다. 복구한 파일을 둘 공간도 필요하며, USB 드라이브만 아니면 어느 드라이브든 됩니다.

ReviveUSB는 아직 코드 서명이 되어 있지 않아서 Windows SmartScreen이나 백신 프로그램이 경고할 수 있습니다. 다운로드 페이지에 파일의 SHA-256 값이 나와 있습니다. PowerShell에서 Get-FileHash .\ReviveUSB.exe -Algorithm SHA256 을 실행해 확인하고, 값이 같으면 추가 정보를 누른 다음 실행을 누르세요. 내려받은 파일은 USB 드라이브가 아니라 PC에 저장하세요.

1. 드라이브 고르기

ReviveUSB.exe 를 실행하고 관리자 권한을 허용합니다. 창 위쪽에 관리자 권한: 켜짐이 나와야 합니다. 꺼짐으로 나오면 관리자 권한으로 다시 실행을 누르세요. USB 드라이브를 꽂고 새로고침을 누른 뒤 목록에서 드라이브를 클릭합니다. 목록에는 USB 디스크만 나오므로 내장 디스크를 잘못 고를 일은 없습니다.

2. 이미지로 백업하기

이미지 백업을 누르고, 빈 공간이 충분한 다른 드라이브에 이미지를 저장합니다. 기본 이름은 diskN.img 이며 N은 디스크 번호입니다. USB 드라이브 안을 저장 위치로 고르면 ReviveUSB가 거부하고 다른 드라이브를 고르라고 합니다. 거기에 저장하면 되찾으려는 파일을 덮어쓸 수 있기 때문입니다.

창은 언제든 닫아도 됩니다. 나중에 이어서 하려면 프로그램을 다시 실행해 같은 드라이브를 고르고, 이미지 백업을 누른 뒤 같은 파일을 고르고, Windows가 바꿀지 물으면 예를 누르세요. 로그에 이미지 이어받기 가 나오고 멈췄던 곳부터 복사가 이어집니다.

여기서부터는 이미지로 작업하며, USB 드라이브는 다시 읽지 않습니다.

3. 파일 복구(이름·경로)

파일 복구(이름·경로)를 누릅니다. 목록에서 디스크가 선택되어 있으므로 ReviveUSB는 먼저 그 디스크를 직접 읽을지 묻습니다. 아니요를 누르고 .img 파일을 고르세요. 이미지 쪽이 더 낫습니다. 그다음 멀쩡한 드라이브에서 결과를 저장할 폴더를 고릅니다.

이 방법은 NTFS, FAT32, exFAT를 읽습니다. 찾을 수 있는 파일을 모두 이름과 폴더 그대로 복사하며, 지운 파일과 지운 폴더 안에 있던 파일도 포함합니다. 지금 있는 파일과 지운 파일을 함께 찾으면 지운 파일은 _deleted_files 폴더에 따로 넣으므로, 옛 사본이 지금 파일 옆에 섞이는 일은 없습니다. 가장 먼저 열어 볼 곳이 이 폴더입니다.

결과를 저장할 폴더에는 파일 크기만큼의 빈 공간이 있어야 합니다. 공간이 모자라면 시작하기 전에 로그가 경고합니다.

FAT32 드라이브라면 로그에 '내용이 틀릴 수 있는' 파일 목록이 나올 수 있습니다. Windows가 그 파일을 지울 때 시작 위치에 관한 정보 일부를 지웠고, .bin 같은 형식은 올바른 위치를 알려 줄 시그니처가 없습니다. 이런 파일은 믿고 쓰기 전에 열어 보세요.

4. 아무것도 안 나오면 시그니처로 복구하기

이름·경로 복구가 아무것도 찾지 못하거나 파일시스템을 인식하지 못한다고 하면, 같은 이미지로 파일 복구(시그니처)를 실행하세요. 파일 내용을 보고 파일을 찾으므로 파일시스템이 없어도 됩니다. JPEG, PNG, GIF, BMP, PDF, ZIP 파일과 MP4, MOV, 3GP, M4A, HEIC를 찾으므로 휴대폰·블랙박스 동영상과 iPhone 사진까지 다룹니다.

이 방식으로는 이름을 잃습니다. 파일은 jpg_00001_@... 처럼 번호가 붙어 돌아옵니다. docx, xlsx, pptx 같은 Office 파일은 속이 ZIP 파일이라 .zip 이름으로 돌아옵니다. 맞는 확장자로 이름을 바꿔 주세요.

드라이브는 고칠 필요가 없습니다

파일을 지운다고 드라이브가 망가지지는 않습니다. 수리 버튼(검사(chkdsk), 포맷, 완전 복구(rebuild))은 Windows가 열지 못하는 드라이브에 쓰는 것이고, 포맷과 완전 복구(rebuild)는 데이터를 지웁니다. 이번에는 건드리지 마세요.

복구한 파일을 PC에서 열어 확인하세요. 필요한 파일을 다 찾았다면 평소처럼 USB 드라이브에 다시 복사해 계속 쓰면 됩니다. 다만 PC에도 사본을 남겨 두세요. 그다음에는 이미지 파일과 그 옆의 진행 상황 파일, 예를 들어 disk2.img 와 disk2.img.state.json 을 지워도 됩니다.

그래도 안 될 때

복구한 파일이 열리지 않는다면 파일이 조각나 저장되어 앞부분만 돌아왔을 수 있습니다. 이미지로 복구 버튼 두 개를 모두 써 보세요.

백업이 아주 느리다면 원인은 대개 드라이브나 연결입니다. ReviveUSB는 이미 불량 구간을 건너뛰기 때문입니다. 허브 대신 PC 뒤쪽의 USB 3.0 포트에 드라이브를 바로 꽂거나, 케이블을 바꾸거나, 다른 PC에서 해 보세요. 같은 이미지 파일로 다시 백업하면 멈췄던 곳부터 이어집니다. 시간이 없다면 중간에 프로그램을 닫고 그때까지 만든 이미지로 파일 복구(시그니처)를 실행하세요. 복사된 부분에서 파일을 복구합니다.

아무것도 돌아오지 않는다면 지운 파일 위에 새 데이터가 써졌을 수 있습니다. 덮어써진 데이터는 어떤 소프트웨어로도 되살릴 수 없고, 죽은 플래시 칩에 있는 데이터도 마찬가지입니다. 그때 남은 방법은 전문 데이터 복구 업체입니다.

버튼마다 하는 일은 설명서에, 복구에 관해 자주 묻는 질문은 FAQ에 있습니다.
