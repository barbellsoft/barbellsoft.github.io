USB 포맷하라고 뜰 때: 포맷하기 전에 파일부터 살리세요

영상으로 보고 싶다면 유튜브에서 1분짜리 따라 하기 영상을 보세요.

어제까지 잘 쓰던 USB 메모리를 꽂았는데 Windows가 "E: 드라이브의 디스크를 사용하기 전에 포맷해야 합니다"라며 디스크 포맷 버튼과 취소 버튼을 띄웁니다. 취소를 누르세요.

메시지만 보면 끝난 것 같지만, 대개는 드라이브가 죽은 것이 아니라 드라이브의 파일시스템이 망가진 것입니다. Windows가 파일 목록을 적어 둔 색인을 읽지 못하니 포맷하자고 하는 것입니다. 파일은 대개 그대로 남아 있습니다. 오히려 포맷이 파일을 위험하게 만듭니다.

무슨 일이 일어난 걸까

모든 드라이브에는 어떤 파일이 어디에 있는지 적어 둔 색인, 곧 파일시스템이 있습니다. Windows는 이 파일시스템을 마운트하지 못하면 드라이브를 RAW로 표시합니다. 색인 안의 값이 하나만 틀려도 그렇습니다. 용량이 큰 드라이브가 작은 RAW 조각으로 보이거나 드라이브 문자가 아예 없다면 파티션 자체가 망가진 것입니다.

흔히 하는 응급처치가 듣지 않는 이유도 여기 있습니다. chkdsk는 있는 파일시스템을 고치는 도구인데, RAW 드라이브에는 읽을 수 있는 파일시스템이 없으니 고칠 대상이 없습니다.

아직 하지 말아야 할 일

파일을 안전한 곳에 옮기기 전까지는 드라이브를 그대로 두세요.

  • Windows에서든 다른 어디서든 포맷하지 마세요.
  • Windows가 드라이브를 검사하고 복구하겠다고 해도 진행하지 마세요.
  • 새 파일을 저장하거나 복사해 넣지 마세요.

색인이 망가져도 데이터 자체는 보통 원래 자리에 그대로 있습니다. 그런데 새로 무언가를 쓰면 Windows가 그 데이터를 예전 파일 바로 위에 쓸 수 있고, 그러면 무엇으로도 되살릴 수 없습니다. 드라이브를 읽기만 하는 것은 괜찮습니다.

ReviveUSB로 파일 되찾기

ReviveUSB는 이 순서에 맞춰 만든 무료 Windows 프로그램입니다. 드라이브를 먼저 복사하고, 그 사본에서 파일을 복구한 다음, 드라이브는 맨 나중에 고칩니다. Windows 10 또는 11(64비트)에서 실행되고, 디스크를 직접 읽기 때문에 관리자 권한이 필요합니다.

고장 난 드라이브만큼의 빈 공간이 다른 드라이브에 있어야 합니다. 128 GB USB 메모리라면 128 GB가 비어 있어야 합니다.

ReviveUSB는 아직 코드 서명이 되어 있지 않아서 SmartScreen이 인식할 수 없는 앱이라고 경고할 수 있습니다. 다운로드 페이지에 파일의 SHA-256 값이 적혀 있습니다. PowerShell에서 Get-FileHash .\ReviveUSB.exe -Algorithm SHA256 을 실행해 확인하고, 값이 같으면 추가 정보를 누른 다음 실행을 누르세요.

1. 드라이브 고르기

ReviveUSB.exe 를 실행하고 관리자 권한을 허용합니다. 창 위쪽에 관리자 권한: 켜짐이 나와야 합니다. 새로고침을 누르고 목록에서 USB 드라이브를 클릭합니다. 파일시스템 열에는 아마 RAW라고 나올 것입니다.

2. 드라이브를 이미지로 복사하기

이미지 백업을 누르고, disk2.img 같은 이름으로 다른 드라이브에 파일을 저장합니다. 이 단계에서 ReviveUSB는 USB 메모리를 읽기만 합니다. 읽지 못하는 구간은 건너뛰어 복사가 멈추지 않게 하고, 끝에 가서 그 구간을 섹터 단위로 다시 읽을지 묻습니다.

창을 닫았다가 나중에 이어서 해도 됩니다. 이미지 백업을 다시 누르고 같은 파일을 고른 뒤, 바꿀지 물으면 예를 누르세요. 로그에 이미지 이어받기 가 나오고 멈춘 곳부터 복사를 이어 갑니다.

여기서부터는 이미지로 작업합니다. 고장 나 가는 USB 메모리를 몇 번이고 읽는 것보다 그 사본을 읽는 편이 안전합니다.

3. 이름 그대로 파일 복구하기

파일 복구(이름·경로)를 누르고 이미지 파일을 고른 뒤, 멀쩡한 드라이브에서 폴더를 고릅니다. 복구하려는 드라이브 안의 폴더는 ReviveUSB가 받지 않습니다.

Windows가 RAW라고 해도 이 방법을 먼저 해 보세요. ReviveUSB는 NTFS, FAT32, exFAT를 읽으며, Windows가 마운트하지 못하는 파일시스템도 읽어 내는 경우가 많습니다. 성공하면 파일이 이름과 폴더 그대로 돌아옵니다. 지운 파일만이 아니라 찾은 파일을 모두 복사하고, 지워졌던 파일은 _deleted_files 폴더에 따로 넣습니다.

4. 아무것도 못 찾으면 시그니처 방식으로

ReviveUSB가 파일시스템을 인식하지 못했다고 하거나 아무것도 찾지 못하면, 같은 이미지로 파일 복구(시그니처)를 누르세요. 이 방식은 파일시스템을 보지 않고 파일 내용으로 파일을 찾습니다. JPEG, PNG, GIF, BMP, PDF, ZIP 파일과 MP4, MOV, 3GP, M4A, HEIC 파일(휴대폰·블랙박스 동영상과 휴대폰 사진)을 찾습니다.

대신 이름은 잃습니다. 파일은 jpg_00001_@... 처럼 번호가 붙어 돌아옵니다. .docx, .xlsx, .pptx 같은 문서는 속이 ZIP 파일이라서 .zip 으로 돌아옵니다. 알맞은 확장자로 이름을 바꿔 주세요.

그다음 USB 메모리 고치기

파일을 PC에 안전하게 옮겼다면 USB 메모리를 다시 쓸 수 있게 만들어도 됩니다. RAW 드라이브나 드라이브 문자가 없는 드라이브라면 목록에서 고르고 완전 복구(rebuild)를 누르세요. 디스크를 지우고 새 파티션을 만든 뒤 NTFS로 포맷합니다. 확인하려면 ERASE DISK 와 디스크 번호를 입력합니다. 예를 들면 ERASE DISK 2 입니다. 드라이브 문자가 아직 있고 지우기만 하면 된다면 포맷으로 됩니다.

ReviveUSB는 무언가를 쓰기 전에 드라이브를 읽어서 컨트롤러가 고장 나 가는지 확인합니다. 드라이브 일부를 읽지 못한 경우가 그런 예입니다. 그런 징후가 보이면 드라이브를 고치지 않고 그 이유를 로그에 적습니다. 고장 나 가는 드라이브는 큰 쓰기를 하다가 중간에 아예 멈출 수 있으니, 이럴 때는 복구한 파일을 잘 보관하고 USB 메모리를 바꾸세요.

다시 만든 뒤에는 새로고침을 누르고 드라이브를 골라 드라이브 시험을 누릅니다. 예는 빈 공간 전체를 시험하고, 아니요는 1 GB만 빠르게 시험합니다. 용량을 속이는 드라이브는 전체 시험에서만 드러납니다. 통과하면 파일 되돌려 넣기로 복구한 폴더를 USB 메모리에 다시 넣습니다. 이때 파일을 하나하나 다시 읽어 원본과 비교합니다. 그래도 PC에 있는 사본은 지우지 말고 두세요.

그래도 안 될 때

목록에 '펌웨어 고장(ROM 모드)'이나 '저장 공간 없음(0)'이 나올 때

USB 메모리의 컨트롤러가 제대로 올라오지 않는 상태입니다. Windows에서는 '미디어 없음'이나 0바이트로 보이면서도 포맷하라고 할 수 있습니다. 취소를 누르세요. 뽑았다가 다시 꽂아 보세요. 원래 이름으로 돌아오면 바로 백업하세요. 돌아오지 않으면 소프트웨어로는 읽을 수 없습니다. 데이터 복구 업체라면 메모리 칩을 직접 읽어 낼 수도 있습니다.

백업이 아주 느릴 때

허브나 연장 케이블 없이 PC 뒷면의 USB 3.0 포트에 드라이브를 바로 꽂으세요. 그래도 그대로라면 케이블이나 PC를 바꿔 보세요. 같은 이미지 파일로 다시 백업하면 복사가 이어집니다.

복구한 파일이 열리지 않을 때

파일이 조각나 저장되어 있어서 앞부분만 돌아왔을 수 있습니다. 복구 버튼 두 개를 모두 써 보세요. 드라이브에서 읽지 못한 부분은 이미지에도 빠져 있습니다.

수리가 실패할 때

드라이브를 뽑았다가 다시 꽂고 다시 해 보세요. 백신이나 탐색기 미리 보기처럼 드라이브를 쓰고 있을 만한 프로그램도 닫으세요. 상태가 계속 Unhealthy 로 나오거나 연결이 자꾸 끊긴다면 하드웨어가 고장 나는 중일 가능성이 큽니다. 소프트웨어로는 고칠 수 없으니 드라이브를 바꾸세요.

어떤 방법도 통하지 않을 때

되살릴 수 없는 파일도 있습니다. 데이터가 이미 덮어써졌거나 플래시 칩 자체가 죽었다면 어떤 소프트웨어로도 안 되고, 남은 방법은 전문 복구 업체뿐입니다. 버튼마다 하는 일은 ReviveUSB 설명서에 나와 있습니다.
