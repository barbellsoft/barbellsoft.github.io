필요 환경
Windows 10 또는 11(64비트), 또는 macOS(Apple 칩·인텔).

다운로드

컴퓨터용 프로그램이라 휴대폰에는 설치할 수 없습니다. 이 페이지 링크를 내게 보내 두었다가 컴퓨터에서 다운로드하세요.

Windows 설치 파일(64비트) 6.0 MB

다운로드 Chatda_x64-setup.exe

SHA-256 512ff1f7072ec08c64a10ffcf0683098846b781682ccd4ce746b8b56353e290c

macOS 디스크 이미지(Apple 칩·인텔 공용) 14.0 MB

다운로드 Chatda_universal.dmg

SHA-256 3a7c9f16c314d2ad69566e566f23a7bc739c8ba7a4781e335bd795db9ecce1d0

맥에서 보안 경고 없이 가장 쉽게 설치하는 방법:

  1. Command(⌘) + 스페이스 바를 눌러 검색창(Spotlight)을 열고 «터미널»을 입력한 뒤 Return 키를 누릅니다.
  2. 아래 «복사» 버튼을 누르고, 열린 터미널 창을 한 번 클릭한 뒤 Command(⌘) + V로 붙여 넣고 Return 키를 누릅니다.
  3. 1분쯤 기다리면 Chatda가 응용 프로그램 폴더에 설치되고 저절로 열립니다.
curl -fsSL https://github.com/barbellsoft/chatda-releases/releases/latest/download/install.sh | bash

다운로드가 시작됩니다. 사용해 보시고 도움이 되면 커피 한 잔으로 후원해 주세요. 후원금은 Windows 경고를 훨씬 줄여 주는 코드 서명 인증서에 씁니다. 후원으로 돕기

Windows 경고가 뜨면

Chatda는 아직 코드 서명이 없어서, Windows SmartScreen이 '알 수 없는 앱'이라고 경고할 수 있습니다. 받은 파일이 여기 올린 것과 같은지 PowerShell에서 SHA-256을 비교해 확인하세요.

Get-FileHash .\Chatda_x64-setup.exe -Algorithm SHA256

값이 같으면 '추가 정보'를 누르고 '실행'을 고르면 됩니다. 모든 사용자용으로 드라이브 색인 서비스와 함께 설치하기 때문에 설치하고 업데이트할 때 관리자 승인을 받습니다. 맥에서 'Chatda'을(를) 열지 않음이 뜨면 '완료'를 누르고, 시스템 설정 > 개인정보 보호 및 보안에서 아래로 내려 '그래도 열기'를 누른 뒤 다시 여세요.

코드 서명 인증서(1년에 약 200달러)를 갖추면 이 경고가 훨씬 줄어듭니다. 후원으로 돕기

새 기능

9.34.5 · 2026-10-23

  • «1차»·«회의록v2» 처럼 한글과 숫자·영문이 붙은 낱말이 파일 이름 중간에서 검색되지 않던 문제 수정
  • 검색어에 OR 와 확장자 묶음(*.{pdf,docx}·doc: 등)을 같이 쓰면 OR 가 AND 처럼 동작하던 문제 수정, 확장자 빼기(-*.pdf)는 정확한 확장자로
  • 파일이 바뀌어 다시 찾을 때 아래로 내려 본 결과 목록이 처음 300개로 줄던 문제, 색인 중 결과가 늘지 않던 문제 수정
  • build·env 같은 이름의 파일이 감시에서 빠지던 문제 수정
  • 서버 주소에 «아이디:비밀번호@» 를 넣으면 비밀번호가 앱에 저장되던 문제 수정
  • 링크로 열 때 막는 실행 형식을 늘림(.settingcontent-ms, 디스크 이미지 등)
  • Windows: 많은 파일을 한꺼번에 휴지통으로 보낼 때 오래 걸리던 문제, 드라이브 재색인 중 생긴 변경이 빠지던 문제 수정
  • NAS 서버 검색에서 와일드카드(*)와 다른 낱말을 섞으면 결과가 0건이던 문제 수정 (Chatda 서버 0.1.15 필요)

9.34.4 · 2026-10-23

  • 네트워크(NAS) 폴더 안의 하위 폴더를 따로 추가하면 바깥 폴더에 새로 생긴 파일이 검색되지 않던 문제 수정
  • Windows 서비스: 응답을 받지 않는 연결 하나 때문에 모든 사용자 계정의 드라이브 변경 반영이 멈추던 문제 수정 (서비스 교체 안내가 표시되면 교체하세요)

9.34.3 · 2026-10-22

  • 필터와 빼기(-낱말)만 남은 검색이 결과 0건이던 문제 고침
  • 짧은 검색어의 결과가 500·1000개에서 잘리던 문제 고침
  • «오늘»·«1주일» 날짜 칩의 기준 시각이 앱을 켠 순간에 멈춰 있던 문제 고침
  • 복사할 곳이 원본의 상위 폴더면 복사가 거절되던 문제 고침
  • Windows 에서 폴더를 한 번 못 열면 그 아래 파일이 모두 검색에서 빠지던 문제 고침
  • 큰 텍스트 파일이 많은 폴더를 색인할 때 메모리가 크게 늘어 앱이 꺼지던 문제 고침
  • 색인 중 잠깐 못 읽은 문서가 계속 본문 없이 남던 문제 고침
  • 폴더를 빼거나 파일을 많이 지운 뒤에도 색인 파일과 메모리가 줄지 않던 문제 고침

9.34.2 · 2026-10-22

  • 심볼릭 링크의 이름을 그 링크가 가리키는 파일 이름으로 바꾸면 원본 파일이 지워지던 문제 고침
  • 폴더와 그 안의 파일을 함께 휴지통에 보낸 뒤 되돌리면(Ctrl+Z) 폴더가 돌아오지 않던 문제 고침
  • 네트워크 폴더 주소를 «아이디:비밀번호@서버» 형식으로 넣으면 연결·공유 찾아보기 때 비밀번호가 다른 프로그램에 보이던 문제 고침
  • 링크로 받아 열 때 막는 실행 형식을 늘림(.tool, .chm, 앱 설치 꾸러미 등)
