기본 검색

1) 검색창에 단어 입력

검색창: 보고서

→ 0.2초 안에 결과 목록이 나타남.

매 글자 입력마다 자동으로 검색됨. Enter 안 눌러도 됨. 한글 조합 중일 때는 잠시 기다림 (한글 한 글자 완성되면 검색).

2) 검색 결과 보기

결과는 한 줄에 파일 하나씩 표로 나옵니다:

이름                         경로                  내용                          크기     수정한 날짜
📊 2024_3분기_업무결산.xlsx   …\docs\분기보고      …3분기 업무결산보고 작성…      84 KB   2024-10-15 09:12
  • 이름: 파일 형식 아이콘(📊 엑셀, 📄 워드 등)과 파일 이름. 검색어 부분이 노란색으로 강조됩니다
  • 경로: 파일이 들어 있는 폴더
  • 내용: 문서 본문에서 검색어가 나온 부분. 비어 있으면 이름으로만 찾은 파일입니다
  • 크기 · 수정한 날짜
  • 머리글을 누르면 그 칸으로 정렬하고, 다시 누르면 반대로 정렬합니다. «내용»을 누르면 관련도순입니다
  • 머리글 경계를 끌면 칸 너비가 바뀌고, 다음에 켤 때도 그대로입니다

검색 모드

필터 막대의 찾을 곳 드롭다운에서 고릅니다. 기본은 "이름+내용".

모드 무엇을 검색하나 언제 쓰나
이름+내용 파일명 + 본문 모두 일반적인 검색 (기본)
이름만 파일명/경로만 가장 빠름. 파일명을 정확히 알 때
내용만 본문 내용만 (파일명 매치 제외) 내용으로 찾을 때. 파일명에는 단어 없는데 내용에 있는 파일 찾기

예시

업무 검색 시: - 이름+내용: 업무결산보고.xlsx (파일명) + 프로젝트_노트.md (본문에 "업무" 단어) 모두 - 이름만: 업무결산보고.xlsx 만 - 내용만: 프로젝트_노트.md 만 (파일명에 "업무" 없는 것들)

💡 본문에 있는데 파일명엔 없는 것 을 찾고 싶으면 내용만 모드. 본문 인덱싱은 TXT · MD · CSV · DOCX · XLSX · PPTX · PDF · HWPX 만 됩니다 (다른 형식은 파일명만). 드라이브 전체(C:\ 등)로 추가한 곳은 파일명만 검색됩니다.

필터

검색어를 입력하면 검색창 아래에 필터 막대가 나타납니다. 항목마다 드롭다운이고, 기본값이 아닌 걸 고르면 강조 표시됩니다.

종류 필터 (모든 종류 ▾)

모든 종류 ▾ 를 누르면 확장자 체크 목록이 펼쳐짐:

☐ PDF   ☐ DOCX   ☐ XLSX   ☐ HWP   ☐ TXT   ...

원하는 확장자에 체크 → 해당 형식만. 여러 개 동시 선택 가능. 고르면 버튼이 종류 2개 처럼 바뀌고, 목록 맨 위 전부 해제 로 한 번에 풀 수 있음.

기간 필터

기간 ▾   전체 기간 / 오늘 / 1주일 / 1개월 / 1년

선택한 기간 안에 수정된 파일만. 1년 은 오늘부터 거슬러 365일입니다 (올해 1월 1일부터가 아님).

폴더 필터

모든 위치 ▾ 를 눌러 폴더 클릭 → 해당 폴더 안에서만 검색. 같은 창 맨 위의 전체 클릭 → 전체로 복귀.

묶어 보기

묶어 보기 ▾   묶지 않음 / 폴더별 / 종류별 / 버전별
  • 묶지 않음: 평면 목록 (기본)
  • 폴더별: 폴더 단위로 묶어서 표시
  • 종류별: 확장자 단위로 묶기
  • 버전별: 같은 파일의 버전들 (예: 보고서_v1.docx, 보고서_v2.docx) 묶기

정렬

정렬 ▾   관련도순 / 최근 수정순 / 오래된 수정순 / 최근 생성순 / 오래된 생성순 / 이름순 / 이름 역순
  • 관련도순 (기본): 검색어 매치 점수 순. 본문에 여러 번 나오는 게 위로.
  • 최근 수정순 · 최근 생성순: 최근에 고치거나 만든 파일부터
  • 이름순: 가나다 순

반대 방향(오래된 것부터, 이름 역순)은 목록에서 따로 고르면 됩니다.

와일드카드

연산자

쓰는 법 뜻
계약 2026 띄어 쓴 낱말은 모두 들어 있어야 함
사과 OR 배 둘 중 하나라도 (아래 참고)
계약 !초안 · 계약 -초안 그 낱말이 든 것은 뺌
"지급 명세서" 따옴표 안은 붙어 있는 그대로
report_final.pdf 확장자까지 쓰면 그 이름만

OR 대신 세로 막대도 됩니다: 사과 | 배

* · ? — 와일드카드

검색창: 씨애*계약

→ "씨애" 로 시작하고 "계약" 으로 끝나는 이름 (가운데 글자 무시). 매치 예: 씨애치_계약서.pdf, 씨애엠계약.xlsx

검색창: 20?월

→ "20" + 한 글자 + "월" (예: 205월, 20A월). % 도 * 와 같습니다.

와일드카드가 든 낱말은 파일 이름(확장자 포함)에 맞춥니다. 다른 낱말·|·! 와 섞어 쓸 수 있습니다 (rep*2024 !초안). 낱말에 \ 나 / 가 있으면 전체 경로에 맞춥니다 (projects\*.pdf). 찾을 곳이 이름만 이면 검색어 전체를 경로 하나에 맞춥니다.

확장자 — *.xlsx

검색창: *.xlsx
검색창: *.{xlsx,docx,pdf}
검색창: 보고서 *.xlsx

→ xlsx 파일 전부 / 여러 확장자 한 번에 / "보고서" 가 들어간 xlsx 파일만.

OR 와 함께 쓰면 확장자는 그쪽에만 걸립니다. 보고서 *.pdf OR 견적 은 "보고서" 가 들어간 PDF 와, "견적" 이 들어간 모든 파일을 찾습니다. 앞에 빼기를 붙이면 그 형식을 제외합니다: 보고서 -*.pdf.

함수

검색어 뒤에 붙여 쓰면 그 조건으로 거릅니다.

쓰는 법 뜻
ext:pdf;docx 확장자가 pdf 또는 docx
file: · folder: 파일만 · 폴더만
path:projects 전체 경로에 그 글자가 있음 (대소문자 무시, 띄어쓰기 없이, 여러 번 쓰면 모두)
size:… 크기 — 아래 표
dm:… (datemodified: 도 같음) 수정한 날짜 — 아래 표

종류

쓰는 법 뜻
doc: 문서 (pdf · docx · xlsx · pptx · hwp · txt · md · csv …)
pic: (image: 도 같음) 그림 (jpg · png · gif · heic · psd …)
video: · audio: 영상 · 음악
zip: (archive: 도 같음) 압축 (zip · 7z · rar · alz · egg …)
exe: 실행 파일 (exe · msi · bat · cmd · ps1)

크기

쓰는 법 뜻
size:>1mb · size:<=500kb · size:2mb 연산자 > >= < <= =, 단위 b · kb · mb · gb · tb
size:1mb..5mb 범위 (양끝 포함)
size:empty 0 바이트
size:tiny · small · medium 10KB 이하 · 10~100KB · 100KB~1MB
size:large · huge · gigantic 1~16MB · 16~128MB · 128MB 넘게

날짜 (현지 시간)

쓰는 법 뜻
dm:today · dm:yesterday 오늘 · 어제
dm:thisweek · dm:thismonth · dm:thisyear 이번 주(월요일부터) · 이번 달 · 올해
dm:2026 · dm:2026-03 · dm:2026-03-15 그 해 · 그 달 · 그 날
dm:>2025-12-31 · dm:<=2026-02 그 뒤 · 그때까지
dm:2025..2026-02 범위 
검색창: 견적 ext:xlsx dm:thismonth path:거래처

→ "거래처" 폴더 아래에서 이번 달에 고친 xlsx 중 "견적" 이 들어간 파일.

다시 시도해보기
- 필터 막대의 종류(▾) 필터가 켜져 있는지 확인

미리보기

이미지(jpg·png·gif·heic 등)는 그림으로 보입니다. Windows 는 영상·PDF 도 썸네일로 보입니다.

검색 결과 한 번 클릭 → 오른쪽에 미리보기 패널.

파일 형식 미리보기 내용
TXT, MD, CSV, log 등 텍스트 앞부분 텍스트 (검색어 강조)
PDF 본문 텍스트 (30MB 까지)
워드 · 엑셀 · 파워포인트 · 한글(hwpx) 추출된 본문 텍스트 (300MB 까지)
그 외 (사진 · 동영상 등) 미리보기 없음 — 더블클릭으로 열기

미리보기 닫기: Esc 또는 다른 결과 클릭.

복사

한 파일 복사

우클릭 → "경로 복사" 또는 결과 항목 드래그.

선택 복사

Ctrl+클릭(Mac 은 ⌘+클릭)이나 Shift+클릭으로 파일을 고름 → 필터 막대 오른쪽 복사 버튼. 선택한 건수가 복사 (3) 처럼 붙음.

전체 복사 (현재 화면 결과 모두)

모두 선택 을 누른 뒤 복사. 아무것도 선택하지 않고 복사 를 눌러도 보이는 결과 전부가 복사됨.

복사 옵션 모달

복사 시 다음 선택: - 대상 폴더: 어디에 복사할지 - 모드: - 폴더로: 일반 폴더 복사 - ZIP 으로: 압축 파일로 - 구조: - 평면: 모든 파일을 한 폴더에 - 원본 구조 유지: 원본 폴더 트리 그대로 - 확장자별: 같은 확장자끼리 폴더로

즐겨찾기

자주 보는 파일은 즐겨찾기로 등록 → 검색 안 해도 1초만에 접근.

등록

파일 결과 우클릭 → "즐겨찾기 추가".

보기

모든 위치 ▾ → "★ 즐겨찾기" 클릭 → 즐겨찾기 한 파일들만 목록에 뜸.

해제

다시 우클릭 → "즐겨찾기 제거".

저장된 검색

자주 하는 검색 조합 (검색어 + 필터) 을 통째로 저장.

예시

  • 검색어: 회의록
  • 찾을 곳: 내용만
  • 종류: docx, md
  • 기간: 1개월

이 조합을 "이번달 회의록" 으로 저장 → 모든 위치 ▾ 에서 한 번 클릭으로 다시 불러옴.

저장

검색 + 필터 설정 후 필터 막대 ⋯ → 이 검색 저장 (Ctrl+D) → 이름 입력.

사용

모든 위치 ▾ → "저장된 검색" 에서 이름 클릭. 지우려면 이름을 우클릭.

폴더 관리

폴더 추가

모든 위치 ▾ → "+ 폴더 추가" → 폴더 선택 → 자동 인덱싱 시작.

네트워크 폴더 추가

모든 위치 ▾ → "네트워크 폴더 연결" → NAS 주소 + ID/비번 입력.

드라이브 전체 (Windows)

C:\ 처럼 드라이브를 통째로 넣으면 파일 이름 · 크기 · 날짜만 색인합니다. - 고정 NTFS 드라이브(C:\, D:\ …)는 자동으로 추가되고 하나씩 차례로 색인합니다. 필요 없는 드라이브는 폴더 메뉴의 목록에서 빼기 로 빼면 다시 넣지 않습니다. USB 같은 이동식 드라이브는 넣지 않습니다. - 관리자 승인 창에서 예 를 누르면 NTFS 목록을 직접 읽습니다. 파일 200만 개 드라이브가 10~20초 안팎이면 끝납니다. 아니요 면 폴더를 하나씩 훑어 몇 분 걸립니다. - 색인하는 동안 아래 상태 줄에 디스크 목록 읽는 중 NN% · 남은 시간 이 뜹니다. 한 번 만든 목록은 저장해 두었다가 다음 실행 때 1~2초 만에 다시 불러옵니다. - 드라이브 전체 색인은 기본으로 개발 폴더(node_modules · .git 등)와 «.» 으로 시작하는 파일을 뺍니다. 이것까지 찾고 싶으면 ⚙ 설정 → 색인 제외 → 드라이브 전체에 개발 폴더…와 «.» 으로 시작하는 파일도 포함 (전부 포함) 을 켜세요. 따로 추가한 폴더에는 영향이 없습니다. - 매번 승인하기 번거로우면 ⚙ 설정 → 드라이브 빠른 색인 (서비스) 를 설치하세요. 승인 없이 빠르게 색인하고 앱이 꺼져 있던 동안 바뀐 파일도 따라잡습니다. 서비스를 설치하면 그 PC 에 로그인하는 모든 사용자가 드라이브의 파일 이름을 검색할 수 있습니다.

폴더 메뉴

모든 위치 ▾ 창에서 폴더에 마우스를 올리면 오른쪽에 ⋯ 버튼이 나타납니다. 이 버튼을 누르거나 폴더를 우클릭하면 메뉴가 열립니다.

NAS 캐시를 쓰는지는 폴더에 마우스를 올리면 뜨는 설명에서 확인할 수 있습니다.

인덱스 초기화

⚙ 설정 맨 아래 인덱스 초기화 를 누르면 추가한 폴더와 색인이 모두 지워집니다. 초기화한 뒤에는 폴더를 다시 추가해야 하고, 추가하면 색인을 처음부터 새로 만듭니다.

자동 갱신

폴더에 새 파일이 추가/수정/삭제되면 자동 감지: - 로컬 폴더: 약 0.5초 안에 검색에 반영 - NAS 폴더: 약 5분 안에 반영

직접 갱신하려면 폴더 메뉴(⋯ 또는 우클릭)에서 다시 색인.

최근 파일 · 자주 연 파일

  • 검색어를 비우면 색인된 모든 파일이 최근 수정순으로 나옵니다. "방금 저장한 파일 어디 갔지?" 할 때 씁니다. 날짜·종류·폴더 필터는 그대로 걸 수 있습니다.
  • Chatda 로 연 파일은 연 횟수가 기록되어 관련도순에서 위로 올라옵니다. 정렬의 자주 연 순 으로 모아 볼 수 있고, 우클릭 «연 횟수 지우기» 로 지웁니다.

내보내기

필터 막대의 내보내기 ▾ → CSV(엑셀) 또는 TXT. 불러온 페이지가 아니라 지금 조건에 맞는 결과 전부를 저장합니다. CSV 는 엑셀에서 한글이 깨지지 않게 저장됩니다.

칸 · 필터 표시

  • 결과 표 머리글을 우클릭하면 경로·내용·크기·수정한 날짜 칸을 켜고 끕니다.
  • 기간·종류·폴더·찾을 곳 필터가 걸려 있으면 아래 상태 표시줄에 칩으로 보입니다. 칩을 누르면 풀립니다.
  • 종류 필터(모든 종류 ▾) 맨 위의 문서·이미지·영상·음악·압축 을 누르면 그 종류를 한 번에 고릅니다.

색인 제외

⚙ 설정 → 색인 제외 에서 색인하지 않을 폴더와 이름 패턴(*.tmp, ~$* 등, 한 줄에 하나)을 정합니다. 숨김·시스템 파일 빼기(Windows)도 켤 수 있습니다. 저장하면 이미 색인된 것 중 해당하는 것은 바로 빠집니다.

트레이와 자동 시작

창을 닫아도 꺼지지 않고 트레이(Mac 은 메뉴 막대) 에 남아 색인을 계속합니다. 다른 프로그램을 쓰다가 Ctrl + Shift + Space 를 누르면 창이 바로 뜨고 검색창에 커서가 가 있습니다. 트레이 아이콘을 누르면 창이 열리고, 우클릭 메뉴의 종료 로 완전히 끕니다.

⚙ 설정에서 바꿀 수 있습니다. - 창을 닫으면: «트레이에 남기» 또는 «종료» - 불러오기 단축키: 몇 가지 조합 중에서 고르거나 끄기. 다른 프로그램이 이미 쓰는 조합이면 안내가 나옵니다 - 로그인할 때 시작: 켜면 PC 를 켤 때 창 없이 트레이에서 시작합니다

검색 팁

1) 검색어를 짧게 시작

프로젝트_2024년_3분기_업무결산보고서 보다 3분기 결산 으로 시작하는 게 더 잘 찾음.

2) 띄어쓰기 무관

회의록, 회의 록, 회의 록 2024 모두 비슷하게 동작.

3) 한글 + 영어 혼용 OK

Ctrl 단축키, 엑셀 VLOOKUP, python 매뉴얼 등 자유롭게.

4) 본문 내용으로 못 찾을 때

  • 찾을 곳을 내용만 으로
  • 확장자가 TXT/MD/CSV/DOCX/XLSX/PPTX/PDF/HWPX 인지 확인 (다른 형식은 본문 인덱싱 안 됨)
  • 드라이브 전체(C:)로만 들어가 있는 파일이면 본문은 검색되지 않음 → 그 폴더를 따로 추가
  • 키워드를 더 일반적인 단어로 (결재 병목 보다 병목)

5) 너무 많은 결과

  • 종류 필터 추가 (XLSX 만 등)
  • 기간 필터 (1개월 등)
  • 모든 위치 ▾ 에서 폴더 좁히기
  • 검색어를 더 구체적으로

6) 같은 파일 여러 버전이 보일 때

묶어 보기를 버전별 로 → 같은 파일의 v1, v2, v3 가 묶여서 한 줄에.

7) 정렬 실험

  • 최근 작업한 것부터 보고 싶으면 최근 수정순
  • 가나다 순 정리는 이름순

FAQ

Q. 검색 결과에 같은 파일이 여러 개 떠요. 실제로 NAS 에 같은 파일이 여러 폴더에 있는 경우가 많음. 묶어 보기를 폴더별 또는 버전별 로 바꾸면 정리됨.

Q. 본문 발췌가 안 보여요. - 그 파일의 형식이 본문 인덱싱 지원이 안 될 수 있음 (예: 그림 파일, ZIP) - 파일명 배지가 보이면 본문 인덱싱 안 된 것 - 지원 형식: TXT · MD · CSV · DOCX · XLSX · PPTX · PDF · HWPX - 드라이브 전체(C:)로 들어간 파일은 이름만 색인 — 그 폴더를 따로 추가하면 본문도 검색됩니다

Q. 파일을 새로 만들었는데 검색이 안 돼요. - 로컬 폴더라면 0.5초 정도 기다리세요. 자동 감지됩니다. - NAS 라면 최대 5분 안에 반영. 급하면 폴더 메뉴에서 다시 색인 을 누르세요.

Q. 검색 속도가 느려요. - 찾을 곳을 이름만 으로 변경 (가장 빠름) - 종류 필터로 범위 좁히기 - 폴더 필터로 특정 폴더만

Q. 자동 업데이트는 어떻게 받나요? 앱 시작 시 새 버전 있으면 상단에 "v0.X.X 사용 가능 [설치]" 배너가 뜸. 클릭하면 자동.

Q. 즐겨찾기 / 최근 검색이 다른 PC 와 동기화 되나요? 안 됩니다. 각 PC 별로 따로 저장됩니다.

Q. NAS 비밀번호를 바꿨는데 어떻게 하나요? 모든 위치 ▾ → "네트워크 폴더 연결" 에서 새 비밀번호로 다시 연결하세요.

문제 해결

검색 결과가 0건

  1. 종류(▾) 필터가 켜져 있는지 확인 → 전부 해제
  2. 찾을 곳을 이름+내용 으로 (내용만이면 파일명 매치 제외됨)
  3. 모든 위치 ▾ → 맨 위 전체 클릭 (특정 폴더 선택 상태 해제)
  4. 기간이 "전체 기간" 인지 확인
  5. 검색어를 짧게 / 단순하게

NAS 폴더가 빈 채로 표시됨

  • 모든 위치 ▾ 에서 그 폴더를 우클릭(또는 ⋯) → 다시 색인
  • NAS 연결 상태 확인 (탐색기·Finder 에서 NAS 주소로 들어가지는지)
  • 회사 밖에서 회사 NAS 를 쓰는 경우 VPN 연결 확인

앱이 너무 많은 메모리를 씀

  • ⚙ 설정 맨 아래 인덱스 초기화 → 폴더 다시 추가 (색인을 새로 만드느라 시간 걸림)
  • 안 쓰는 폴더 제거

폴더 추가가 안 됨

  • 폴더 권한 확인 (NAS 라면 본인 ID/비번, 그 폴더에 접근 권한이 있는지)

어떻게 해도 안 될 때

내려받기 페이지의 Issues 에 남겨 주세요. 다음을 함께 적어 주시면 빨리 고칠 수 있습니다: - 본인 PC OS (Windows / Mac) - 어떤 화면에서 어떤 동작 했을 때 어떻게 됐는지 - 가능하면 화면 캡처
