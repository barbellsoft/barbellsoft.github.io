이 창에는 그래도 실행하는 단추가 없습니다. 스마트 앱 컨트롤은 이미 알려졌거나 서명된 프로그램만 허용하는데, 우리 프로그램은 아직 서명이 없습니다.

  1. Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정을 엽니다.
  2. 끄기를 고르면 프로그램이 실행됩니다. Windows 버전에 따라 한 번 끄면 Windows를 초기화하기 전에는 다시 켤 수 없을 수 있으니 신중히 정하세요.
  3. 계속 켜 두고 싶다면 다른 PC에서 쓰거나, 서명된 판이 나올 때까지 기다려 주세요.

  1. Windows 키 + E를 눌러 파일 탐색기를 엽니다.
