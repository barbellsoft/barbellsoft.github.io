  • 실행어디서나 Alt+Space를 누르고 몇 글자 입력한 뒤 Enter: 시작 메뉴와 Microsoft Store 앱이 바로 실행됩니다
  • 찾기이름 일부나 줄임말(카톡 → 카카오톡, vsc → Visual Studio Code)로 찾고, 자주 실행하는 앱을 위에 표시합니다
  • 계산Enter를 누르면 결과를 복사합니다. 만·억 단위와 백분율도 됩니다(1억2천만*0.1, 1,500,000*3.3%)
  • 날짜오늘+30, D-day(12/31), 공휴일·대체공휴일을 제외한 영업일(+10영업일)
  • 바로가기자주 여는 사이트·공유 폴더·파일을 키워드로 등록하고, 키워드 뒤에 입력한 글자로 검색하는 주소도 만들 수 있습니다
  • 상용구키워드를 입력하고 Enter를 누르면 저장한 문구를 입력하던 곳에 붙여넣습니다
  • 팀 공유바로가기를 파일 하나로 팀과 공유합니다. 상용구는 선택할 때만 들어가고, 가져올 때 프로그램을 실행하는 항목은 선택이 해제돼 있습니다
  • 한국 사무용초성 검색(ㅋㅋㅇ), 한/영 전환 없이 친 글자, 부가세, 3.3% 원천세, 평↔㎡, 금액 한글 표기(일금 …원정)
