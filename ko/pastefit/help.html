PasteFit 도움말

사용법

  • 글이나 표를 복사합니다(Ctrl+C).
  • 붙여넣을 곳을 클릭하고 단축키를 누릅니다(변경하지 않았다면 Win+Alt+V).
  • 작은 창에 정리된 모양이 표시됩니다. Enter를 누르면 붙여넣고, Esc를 누르면 취소합니다.

정리 방법

  • 텍스트만 유지: 글꼴·색·링크를 제외하고 불필요한 공백을 정리합니다.
  • 줄바꿈 정리: PDF에서 복사한 글처럼 문장 가운데서 끊긴 줄을 연결합니다. 빈 줄과 목록 항목은 그대로 둡니다.
  • 한 줄로 변환: 모든 내용을 한 줄로 바꿉니다. 검색 칸, 입력 칸, 셀 하나에 입력할 때 사용합니다.
  • 표로 붙여넣기: 웹 페이지나 엑셀의 표를 워드·Outlook·브라우저에는 깔끔한 표로, 엑셀에는 셀로 붙여넣습니다.

클립보드 내용 보호

  • 단축키를 누를 때만 클립보드를 읽습니다. 클립보드를 계속 감시하지 않습니다.
  • 복사한 내용을 저장하지 않고 기록도 남기지 않습니다.
  • 인터넷으로 아무것도 전송하지 않습니다.
  • 비밀번호 관리 프로그램이 표시한 내용은 미리보기에서 가립니다.

자동으로 붙여넣지 않는 경우

  • 관리자 권한으로 실행 중인 창이나 원격 데스크톱 창에는 자동으로 붙여넣을 수 없습니다. 정리한 내용은 클립보드에 있으니 Ctrl+V를 누르세요.
  • 붙여넣은 뒤에도 정리한 내용은 클립보드에 남습니다. 되돌리려면 붙여넣은 프로그램에서 Ctrl+Z를 누르세요.
