Barbell Launcher FAQ

Does Barbell Launcher keep what I type?

No. It does not save what you type in the search box. It saves only how often you start each app (to put your usual apps first), its settings, and the shortcuts and snippets you add, all in a file on your PC. It never connects to the internet by itself; only a web search line opens your browser.

Alt+Space does nothing. What should I do?

Another program, such as PowerToys Run, may already use Alt+Space. The first time it starts, Barbell Launcher picks a free shortcut (Ctrl+Alt+Space or Win+Alt+Space) and shows it in the guide. You can change it any time in Settings, from the icon in the notification area.

Why was a snippet not pasted?

Barbell Launcher does not type into windows that run as administrator. The snippet is then on the clipboard, so press Ctrl+V. The same happens if you opened the search box from the notification area icon instead of the shortcut.

Can my team use the same shortcuts?

Yes. In Manage shortcuts, choose Export and send the file. Others choose Import and pick which entries to add. Snippets stay out of the file unless you include them, and entries that open a program are unchecked when importing, so check who sent the file.

How are working days counted?

Weekends and Korean public holidays, including substitute holidays and election days, are skipped. The holiday list comes from the Korea Astronomy and Space Science Institute and is built into the program for this year and next. Holidays announced later need a newer version.
