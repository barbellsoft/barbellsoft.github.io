If Windows warns you

PasteFit is not code-signed yet, so Windows SmartScreen may say it does not recognize the app. Check that the file is the one published here by comparing its SHA-256 in PowerShell:

Get-FileHash .\PasteFit.exe -Algorithm SHA256

If the value matches, choose More info, then Run anyway. PasteFit does not need administrator rights.
