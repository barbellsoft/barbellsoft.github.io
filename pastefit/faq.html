PasteFit FAQ

Does PasteFit keep a history of what I copy?

No. It reads the clipboard only at the moment you press the shortcut, keeps nothing, and sends nothing over the internet. If a password manager marks what you copied, the preview hides it.

The shortcut does nothing. What should I do?

Another program may already use Win+Alt+V. The first time PasteFit starts, it picks a free shortcut and shows it in the guide. You can change it any time in Settings, from the PasteFit icon in the notification area.

Why did it not paste into some windows?

PasteFit does not type into windows that run as administrator or into remote desktop windows. In those cases the cleaned text is already on the clipboard, so press Ctrl+V.

Can I undo a paste?

Yes. Press Ctrl+Z in the program you pasted into. The cleaned text stays on the clipboard, so copy again if you need the original.

Which programs does it work with?

Any program you can paste into. Tables paste as real tables in Word, Outlook and web browsers, and as cells in Excel. In other programs a table pastes as text separated by tabs.
