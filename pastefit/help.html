PasteFit help

How to use

  • Copy text or a table (Ctrl+C).
  • Click where you want to paste it and press the shortcut (Win+Alt+V unless you changed it).
  • A small window shows how the text will look. Press Enter to paste, or Esc to cancel.

Ways to clean

  • Keep text only: removes fonts, colors and links, and cleans up stray spaces.
  • Fix line breaks: joins lines that were cut in the middle of a sentence, as in text copied from a PDF. Blank lines and list items stay.
  • Make one line: puts everything on one line, for a search box, an input field or one cell.
  • Paste as table: pastes a table from a web page or Excel as a clean table in Word, Outlook or a browser, and as cells in Excel.

Your clipboard stays private

  • It reads the clipboard only when you press the shortcut. It does not watch the clipboard.
  • It does not save what you copy and keeps no history.
  • It sends nothing over the internet.
  • If a password manager marks what you copied, the preview hides it.

When it does not paste by itself

  • It cannot paste into a window that runs as administrator, or into a remote desktop window. The cleaned text is on the clipboard, so press Ctrl+V.
  • After pasting, the cleaned text stays on the clipboard. To undo, press Ctrl+Z in the program you pasted into.
