Se o Windows mostrar um aviso

O ReviveFix ainda não tem assinatura de código, então o Windows SmartScreen pode dizer que não reconhece o aplicativo. Confirme que o arquivo é o mesmo publicado aqui comparando o SHA-256 dele no PowerShell:

Get-FileHash .\ReviveFix.exe -Algorithm SHA256

Se o valor for igual, escolha Mais informações e depois Executar assim mesmo. O ReviveFix abre sem direitos de administrador. O Windows só pede quando uma correção precisa deles, como iniciar o spooler de impressão.
