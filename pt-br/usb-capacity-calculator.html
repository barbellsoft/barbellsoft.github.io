Calculadora de capacidade USB: por que uma unidade de 64 GB mostra 59,6 GB

Os fabricantes contam 1 GB como 1.000.000.000 bytes. O Windows conta em unidades de 1.073.741.824 bytes (1024 × 1024 × 1024), mas continua chamando de GB. Por isso, a mesma unidade mostra um número menor no Windows, e não falta nada.

64 GB na embalagem ≈ 59,6 GB no Windows

Este é o tamanho da unidade inteira. O espaço livre que você vê depois de formatar é um pouco menor ainda, porque o sistema de arquivos usa parte do espaço para si. Muitas unidades também informam um pouco menos do que o número redondo da embalagem.

Quando desconfiar de capacidade falsa

  • O Windows mostra mais ou menos o número desta calculadora, mas arquivos copiados depois somem ou não abrem, principalmente arquivos grandes ou copiados quando a unidade estava quase cheia.
  • O preço é muito mais baixo do que o de outras unidades do mesmo tamanho.
  • Pastas ou nomes de arquivos viram texto embaralhado depois que você enche a unidade.

Uma unidade falsa mostra o tamanho anunciado no Windows, então esta calculadora não consegue detectá-la. Para verificar, use uma ferramenta de verificação por gravação e leitura: ela preenche todo o espaço livre com dados de teste e lê de volta. Se os dados gravados depois substituíram dados anteriores, a unidade é falsa. O Testar drive do ReviveUSB faz isso no Windows quando você escolhe testar todo o espaço livre.
