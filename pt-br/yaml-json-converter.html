Conversor de YAML para JSON (e de JSON para YAML)

Cole YAML ou JSON e escolha a direção.

Bom saber

  • O YAML é lido com o esquema core do YAML 1.2. Datas e palavras como yes ou on ficam como texto, e as chaves de mesclagem (<<) são aplicadas.
  • Tags personalizadas (!nome) e vários documentos separados por --- não são suportados e mostram um erro.
  • Comentários não são mantidos. Inteiros maiores que 9007199254740991 em JSON podem perder precisão.

Esta ferramenta não envia o texto nem os arquivos que você insere.
