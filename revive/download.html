If Windows warns you

ReviveUSB is not code-signed yet, so Windows SmartScreen may say it does not recognize the app. Check that the file is the one published here by comparing its SHA-256 in PowerShell:

Get-FileHash .\ReviveUSB.exe -Algorithm SHA256

If the value matches, choose More info, then Run anyway. ReviveUSB asks for administrator rights because it reads drives directly.

What's new

0.2.11 · 2026-10-21

  • After files come back, the log shows a short thank-you line with the Buy Me a Coffee link.
  • The built-in help now describes the Help menu's website and update items, and lists Buy Me a Coffee as the only support link.

0.2.10 · 2026-10-21

  • The Help menu now has ReviveUSB website and Check for updates.
  • Support links: Buy Me a Coffee only. Ko-fi was removed because it cannot accept payments for this project.

0.2.9 · 2026-10-21

  • Deleted files that were overwritten by newer files after deletion are now listed with a warning that their contents are probably wrong (FAT32, exFAT and NTFS). Before, exFAT and NTFS recovered the newer file's data without any warning.
  • Large external drives that use 4096-byte sectors are read in their own sector size, and their partition tables and backup boot sectors are found. Before, such a drive could look entirely unreadable.
  • Tested on a real USB stick: 12,000 files, a 4.6 GB video, fragmented files, and names with emoji, Japanese, Arabic and paths over 260 characters all came back intact.

0.2.8 · 2026-10-20

  • Tested on a real USB stick with 11 kinds of damage. If the partition table at the start of a GPT drive is damaged, the program reads the backup copy at the end of the drive, even when the start of the volume is damaged too.
  • After a quick format, names-and-folders recovery no longer stops at "saved 1/1" (a Windows system file). It now says it found nothing and suggests signature recovery, which brought back photos, documents and videos in testing.
  • Signature recovery no longer saves 4-byte fake JPEG files.

0.2.7 · 2026-10-20

  • When the start of a drive (its boot sector) is damaged, a common reason Windows asks you to format it, names-and-folders recovery now reads the backup copy Windows keeps, so the files come back with their names. Tested on a real USB stick.
  • With a disk selected, Recover files now asks whether to read that disk directly or a disk image file. Before, Cancel in the image window meant "read the disk", which was easy to miss. The image window shows all files by default.
  • The selected disk stays selected when the list refreshes, and the test files that Test drive writes are no longer recovered.
  • After recovering names and folders from a FAT32 drive that Windows deleted files from, the log lists the files whose start the program could not be sure of, so you can open them before you rely on them. Videos (MP4, MOV) now land in the right place more often.
  • The Diagnosis box no longer recommends factory tools for a drive in ROM mode: they did not work on the drive we tested. It now says ReviveUSB cannot revive such a drive, and suggests a data recovery lab if the files matter, or replacing the drive.

0.2.6 · 2026-10-19

  • Repair now checks the drive first by reading only. If the controller looks like it is failing, it does not repair and tells you to recover your files and replace the drive, because a large write can stop such a drive for good. Test drive says so too if the drive stops responding mid-test.
  • A USB whose controller could not load its firmware (ROM mode) or that reports no storage now shows as such in the disk list. Selecting it opens a Diagnosis box with the device ID, the likely controller and what to do next, and turns off buttons that cannot work.
  • New Help menu: F1 opens the manual in your browser, even offline. Support links (Ko-fi, Buy Me a Coffee) are in the menu and at the top right.

0.2.5 · 2026-10-19

  • New After repair row: Test drive writes test data, reads it back from the drive (not from the Windows cache) and deletes it. It finds drives that lose data or fake their capacity.
  • Copy files back puts the recovered files on the repaired drive with their folders, then reads each one back and checks it matches.
  • Full rebuild no longer stops with "The disk has already been initialized" on USB sticks.

0.2.4 · 2026-10-19

  • Recover files (names/paths) now copies the files that are still on the drive, not only deleted ones, so you can get files off a drive Windows will not open. Deleted files go into a separate _deleted_files folder.
  • Signature recovery also finds videos and photos in MP4, MOV, 3GP, M4A and HEIC files.
  • Damaged FAT32 drives: both copies of the file table are compared, and entries that point outside the drive are ignored instead of producing fake files.
  • Health check no longer shows a USB stick's empty counters as 0% wear and 0°C; it says the drive reports no health data.

0.2.3 · 2026-10-18

  • Language box at the top right of the window with 11 languages. Starts in English and remembers your choice.
  • New icon.
  • Recovers files inside folders that were deleted as a whole on FAT32 and exFAT drives.
  • Many reliability fixes from testing on Windows.
