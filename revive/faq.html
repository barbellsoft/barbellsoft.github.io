ReviveUSB FAQ

Windows says "You need to format the disk before you can use it". Should I format?

No, not yet. The message usually means the filesystem is damaged, not that the drive is dead. Formatting can overwrite the data you want back. Make an image first, recover from the image, and format only after that.

Where should I save the recovered files?

On a different, healthy drive with enough free space. Never save them back to the failing drive, because that can overwrite the files you are still trying to recover.

Why does chkdsk fail on my RAW drive?

chkdsk repairs a filesystem that exists, and a RAW drive has none it can read. Recover your files first. Then use Full rebuild to recreate the partition and filesystem.

What makes ReviveUSB different?

It is built around a safe order of work. It copies the failing drive to an image first, skips unreadable regions instead of stalling on them, and lets you resume after an interruption. It copies current and deleted files with their names and folders when the filesystem can still be read, even if Windows will not open the drive, and finds files by signature when it cannot. The repair tools are in the same window.

Is it really free? Is there a recovery limit?

It is free, and there is no cap on the total amount of data you can recover. Donations are optional and unlock nothing.

Can this damage my original drive?

Backup and recovery are read-only. Only the repair buttons change the original drive, and they ask you to type a confirmation first.

What does "don't write to the drive" mean?

Do not save new files to the failing drive before you recover. Running ReviveUSB is fine, because it only reads. A new file can land on top of the data you want back, and then it cannot be recovered.

Can file names be recovered?

Recover files (names/paths) copies current and deleted files with their names and folders. Recover files (signature) restores contents only and numbers the files. Try names/paths first.

Imaging is very slow. What can I do?

ReviveUSB already skips bad regions, so steady slowness usually comes from the drive or the connection. Plug the drive straight into a USB 3.0 port on the back of the PC, swap the cable, or try another PC. Back up again to the same image file and it continues where it stopped.

My drive shows as RAW. What now?

Windows cannot read the filesystem, but names/paths recovery may still be able to, and then the files come back with their names. Try it on the image first. If it says it cannot detect the filesystem, use signature recovery on the image. After recovery, bring the drive back with Full rebuild or Format.

Recovered files will not open.

The file may have been fragmented, so only its first part came back. Try both recovery methods. Parts of the drive that could not be read are missing from the image.

When is recovery impossible?

If the data has been overwritten, or the flash chip itself is dead, software cannot help. A professional data recovery service is the answer then.
