If Windows warns you

ReviveFix is not code-signed yet, so Windows SmartScreen may say it does not recognize the app. Check that the file is the one published here by comparing its SHA-256 in PowerShell:

Get-FileHash .\ReviveFix.exe -Algorithm SHA256

If the value matches, choose More info, then Run anyway. ReviveFix starts without administrator rights. Windows asks only when a fix needs them, such as starting the print spooler.
