ReviveFix FAQ

A network drive shows a red X. What does ReviveFix do?

It asks Windows to reconnect the drive with the address and account Windows remembers. If the server answers, the drive opens again and its line shows ✔. If not, ReviveFix tells you which step failed: the server name, the network connection, the shared folder, or the sign-in.

Does ReviveFix ask for my password?

No. When a saved password no longer works, ReviveFix removes only the saved password for that server and opens the folder, so Windows asks you in its own sign-in window. ReviveFix never sees what you type.

An old NAS needs SMB1 or guest access. Why doesn't ReviveFix turn it on?

Those settings make the whole PC easier to attack. ReviveFix explains the problem instead, and “Copy for IT” gives you the details to send to your IT staff or the NAS administrator.

Will restarting the print spooler delete print jobs?

It can. Before it restarts the spooler, ReviveFix lists the waiting jobs, including jobs other people sent, and asks you first. Send them again if they do not print.

Does ReviveFix send anything over the internet?

No. It only checks this PC and the servers and printers this PC already uses. “Copy diagnosis” puts the results on the clipboard, and you decide where to paste them.
