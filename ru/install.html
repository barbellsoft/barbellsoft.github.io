Если загрузка или установка заблокирована

Наши программы новые и пока не подписаны цифровой подписью, поэтому Windows и Edge их не узнают. Выберите окно, похожее на то, что вы видите.

Сначала проверьте файл

Прежде чем обходить предупреждение, убедитесь, что это файл, который опубликовали мы. На каждой странице загрузки указан SHA-256. Выполните в PowerShell команду ниже и сравните.

Get-FileHash .\<file> -Algorithm SHA256

Удалить

  1. В панели загрузок справа вверху наведите указатель на файл и нажмите ··· (три точки).
  2. Нажмите «Сохранить».
  3. В открывшемся окне не нажимайте «Удалить». Нажмите «Показать больше».
  4. Нажмите «Все равно сохранить». Файл сохранится, и его можно открыть.

Интеллектуальное управление приложениями заблокировало приложение, которое может быть небезопасным.

OK

В этом окне нет кнопки, чтобы всё равно запустить программу. Интеллектуальное управление приложениями пропускает только известные или подписанные программы, а наши пока не подписаны.

  1. Откройте «Безопасность Windows» → «Управление приложениями и браузером» → параметры интеллектуального управления приложениями.
  2. Если выбрать «Выкл.», программа запустится. В зависимости от версии Windows включить функцию снова, возможно, удастся только после сброса Windows, поэтому решайте осторожно.
  3. Если хотите оставить её включённой, используйте программу на другом компьютере или дождитесь подписанных версий.

Не удаётся найти скачанный файл

  1. Нажмите клавишу Windows + E, чтобы открыть проводник.
  2. Слева нажмите «Загрузки». При сортировке по дате изменения новые файлы будут вверху.
  3. В Edge или Chrome можно также нажать Ctrl + J и выбрать «Открыть файл» или «Показать в папке».
