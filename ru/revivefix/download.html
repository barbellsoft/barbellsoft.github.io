Если Windows выдаёт предупреждение

ReviveFix пока не подписан цифровой подписью, поэтому Windows SmartScreen может сообщить, что не распознаёт приложение. Убедитесь, что это файл, опубликованный здесь, сравнив его SHA-256 в PowerShell:

Get-FileHash .\ReviveFix.exe -Algorithm SHA256

Если значения совпадают, нажмите «Подробнее», затем «Выполнить в любом случае». ReviveFix запускается без прав администратора. Windows спрашивает их, только когда они нужны для исправления, например для запуска диспетчера печати.

С сертификатом подписи кода (около 200 долларов США в год) это предупреждение будет появляться гораздо реже. Помочь пожертвованием
