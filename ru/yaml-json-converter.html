Конвертер YAML в JSON (и JSON в YAML)

Вставьте YAML или JSON и выберите направление.

Полезно знать

  • YAML читается по базовой схеме (core) YAML 1.2. Даты и слова вроде yes или on остаются текстом, ключи слияния (<<) применяются.
  • Пользовательские теги (!имя) и несколько документов, разделённых ---, не поддерживаются и дают ошибку.
  • Комментарии не сохраняются. Целые числа больше 9007199254740991 в JSON могут потерять точность.

Этот инструмент не отправляет введённый текст и файлы.
