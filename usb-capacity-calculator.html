USB capacity calculator: why a 64 GB drive shows 59.6 GB

Drive makers count 1 GB as 1,000,000,000 bytes. Windows counts in units of 1,073,741,824 bytes (1024 × 1024 × 1024) but still calls them GB. The same drive therefore shows a smaller number in Windows, and nothing is missing.

64 GB on the package ≈ 59.6 GB in Windows

This is the size of the whole drive. The free space you see after formatting is a little smaller again, because the file system uses some space for itself. Many drives also report slightly less than the round number on the package.

When to suspect fake capacity

  • Windows shows about the number from this calculator, but files copied later go missing or won't open, especially large files or files copied when the drive was nearly full.
  • The price is far below what other drives of the same size cost.
  • Folders or file names turn into garbled text after you fill the drive.

A fake drive shows the advertised size in Windows, so this calculator can't catch it. To check, use a write-and-read verification tool: it fills all free space with test data and reads it back. If the data written later replaced earlier data, the drive is fake. ReviveUSB's Test drive does this on Windows when you choose to test all free space.
