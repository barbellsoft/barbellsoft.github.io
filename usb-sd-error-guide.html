USB and SD card error messages: what they mean and what to do

Find the message or symptom you see below. Each one has the usual cause, what to do, and where ReviveUSB, our free recovery tool for Windows, can and can't help.

Whatever the message, if the drive holds files you need: don't format it, don't run chkdsk, and don't save anything new to it. Copy the drive first, recover from the copy, and repair last.

Messages on this page

  • "You need to format the disk before you can use it"
  • The drive shows as RAW
  • 0 bytes or "No Media"
  • The drive isn't recognized or has no drive letter
  • "The disk is write-protected"
  • Recovered files won't open
  • Files disappear or turn corrupt on a new, cheap drive

"You need to format the disk before you can use it"

Usual cause
Windows can't read the drive's file system. This usually follows unplugging without ejecting, a power cut while writing, or a drive that is starting to fail. The files are often still there.
What to do
Click Cancel. Formatting can overwrite the files you want back. Copy the whole drive to an image file first, recover the files from that image to another drive, and format only after that.
Where ReviveUSB helps
ReviveUSB backs up the drive to an image (it only reads the drive), then recovers current and deleted files with their names and folders from NTFS, FAT32 and exFAT. When names can't be read, it finds photos, videos, PDFs and ZIP files by their content. Format and full rebuild are in the same window for afterwards.
Where it can't help
If the data has been overwritten, or the flash chip itself is dead, no software can bring it back. A professional data recovery service is the answer then.

The drive shows as RAW

Usual cause
File Explorer or Disk Management shows the file system as RAW: Windows can't recognize the partition or file system. chkdsk then says it is not available for RAW drives.
What to do
chkdsk can't repair a drive with no file system it can read, so don't keep retrying it. Recover the files first, then recreate the partition and file system.
Where ReviveUSB helps
ReviveUSB reads NTFS, FAT32 and exFAT itself and can often read a file system that Windows won't mount. Try names/paths recovery on the image first. Afterwards, Full rebuild recreates the partition and file system.
Where it can't help
If ReviveUSB can't detect a file system either, signature recovery still finds photos, videos, PDFs and ZIP files, but without their names and folders.

0 bytes or "No Media"

Usual cause
Disk Management lists the disk, but with a size of 0 bytes or as "No Media". The small chip that runs the drive, its controller, could not load its firmware, or the drive reports no storage at all.
What to do
Cancel any format prompt. Unplug the drive and plug it back in, and try another port or PC. If it comes back with its normal size, don't write to it; back it up straight away.
Where ReviveUSB helps
ReviveUSB shows a Diagnosis box for such a drive with the device ID, the likely controller and what to do next, and checks again every 5 seconds. If the drive comes back, back it up and recover from the image.
Where it can't help
While the drive reports no storage, there is nothing to read, so backup, recovery and repair stay off. If it never comes back, only a recovery lab can try to read the chip.

The drive isn't recognized or has no drive letter

Usual cause
Nothing appears in File Explorer, or Windows says the USB device isn't recognized. The cause can be the port, the cable, a missing drive letter, a damaged partition, or a failing drive.
What to do
Plug the drive straight into another port, ideally on the back of the PC, and try another cable or PC. Open Disk Management: if the disk shows its real capacity but no drive letter, the drive is answering and the damage is usually in the partition or file system. If it doesn't appear at all, the problem is the connection or the hardware.
Where ReviveUSB helps
When the disk shows its real capacity, ReviveUSB works on the disk itself, not on the drive letter, so it can back it up and recover from the image even without a letter.
Where it can't help
If the disk doesn't appear in Disk Management on any port or PC, no program can reach it.

"The disk is write-protected"

Usual cause
SD cards and some adapters have a small lock switch on the side. A read-only attribute on the disk or a Windows policy can also block writing. Some flash drives lock themselves into read-only mode when they start to fail.
What to do
Check the lock switch first. If the drive still refuses writes, copy your files off it while it still reads, and then replace it. A drive that keeps turning read-only by itself shouldn't be trusted with new files.
Where ReviveUSB helps
Backup and recovery only read the drive, so you can still copy a write-protected drive to an image and recover the files from it.
Where it can't help
ReviveUSB has no function to remove write protection, and its repair tools need to write to the drive.

Recovered files won't open

Usual cause
A file came back but is damaged: a photo turns grey halfway, a video won't play. The data may have been overwritten, the file may have been stored in pieces, or parts of the drive couldn't be read.
What to do
Recover again from the same image with the other method, and save the results on a different drive from the one you're recovering.
Where ReviveUSB helps
ReviveUSB has two recovery methods: names/paths reads the file system and keeps names and folders, and signature recovery finds files by their content. Trying both on the same image costs nothing, because the image is only read.
Where it can't help
Data that was overwritten is gone, and parts of the drive that couldn't be read are missing from the image.

Files disappear or turn corrupt on a new, cheap drive

Usual cause
Some drives report more capacity than they really have. Files copied past the real capacity are lost or overwrite earlier files, often without any error message.
What to do
First check how much space Windows should show for the advertised size with the capacity calculator, then test the whole drive with a write-and-read verification tool before trusting it.
Where ReviveUSB helps
After a repair, ReviveUSB's Test drive writes test data to all free space, reads it back without the Windows cache and compares it. The full test is the one that finds drives that fake their capacity.
Where it can't help
No program can turn a fake-capacity drive into a real one. Don't keep files on it.
