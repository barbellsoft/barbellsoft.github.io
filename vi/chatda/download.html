Tải xuống

Đây là chương trình cho máy tính, không cài được trên điện thoại. Hãy gửi liên kết trang này cho chính bạn rồi tải về trên máy tính.

Cách dễ nhất trên Mac, không có cảnh báo bảo mật:

  1. Nhấn Command (⌘) + Phím cách để mở Spotlight, gõ Terminal rồi nhấn Return.
  2. Bấm Sao chép bên dưới, bấm vào cửa sổ Terminal, nhấn Command (⌘) + V để dán rồi nhấn Return.
  3. Chờ khoảng một phút. Chatda sẽ được cài vào thư mục Ứng dụng và tự mở.
curl -fsSL https://github.com/barbellsoft/chatda-releases/releases/latest/download/install.sh | bash

Bắt đầu tải xuống. Nếu công cụ hữu ích với bạn, một ly cà phê giúp nó tiếp tục được phát triển. Tiền ủng hộ sẽ dùng để mua chứng chỉ ký mã, giúp Windows cảnh báo ít hơn nhiều. Ủng hộ bằng một khoản đóng góp

Nếu Windows cảnh báo

Chatda chưa được ký mã, nên Windows SmartScreen có thể báo không nhận ra ứng dụng. Hãy kiểm tra tệp đúng là bản phát hành ở đây bằng cách so sánh SHA-256 trong PowerShell:

Get-FileHash .\Chatda_x64-setup.exe -Algorithm SHA256

Nếu giá trị trùng khớp, hãy chọn Thông tin khác, rồi Vẫn chạy. Chatda được cài cho mọi người dùng cùng với dịch vụ lập chỉ mục ổ đĩa, nên khi cài đặt và cập nhật sẽ cần quản trị viên phê duyệt. Trên Mac, nếu thông báo không thể mở Chatda, hãy bấm Xong, mở Cài đặt hệ thống > Quyền riêng tư & Bảo mật, cuộn xuống và bấm Vẫn mở, rồi mở lại Chatda.

Với chứng chỉ ký mã, chi phí khoảng 200 USD mỗi năm, cảnh báo này sẽ hiếm hơn nhiều. Ủng hộ bằng một khoản đóng góp

Có gì mới

9.34.5 · 2026-10-23

  • Fixed words mixing Korean with digits or letters (like 1차 or 회의록v2) not matching the middle of file names
  • Fixed OR acting like AND when combined with extension groups (*.{pdf,docx}, doc: and so on); excluding an extension (-*.pdf) now matches it exactly
  • Fixed the results list shrinking to the first 300 when files changed, and results not growing while indexing
  • Fixed files named like build or env being ignored by change tracking
  • Fixed a password typed into the server address (user:password@) being saved by the app
  • Links now refuse more runnable file types (.settingcontent-ms, disk images and more)
  • Windows: fixed moving many files to the trash taking a long time, and changes made during a drive re-index being missed
  • Fixed NAS server searches returning nothing when a wildcard (*) was mixed with other words (needs Chatda server 0.1.15)

9.34.4 · 2026-10-23

  • Fixed new files in a network (NAS) folder not appearing in search when a subfolder inside it was added separately
  • Windows service: fixed one stalled connection stopping drive updates for every user account (replace the service when prompted)

9.34.3 · 2026-10-22

  • Fixed searches with only filters and exclusions (-word) returning no results
  • Fixed results for short search terms stopping at 500 or 1,000
  • Fixed the Today and 1 week date chips staying anchored to the moment the app was started
  • Fixed copying being refused when the destination is a parent folder of the source
  • Fixed every file under a folder dropping out of search on Windows after the folder failed to open once
  • Fixed the app running out of memory while indexing folders with many large text files
  • Fixed documents that briefly could not be read during indexing staying without searchable text
  • Fixed the index file and memory use not shrinking after removing folders or deleting many files

  • Fixed renaming a symbolic link to its target's name deleting the original file
  • Fixed undo (Ctrl+Z) not bringing back a folder that was trashed together with files inside it

  • Links now refuse more runnable file types (.tool, .chm, app installer packages and more)
