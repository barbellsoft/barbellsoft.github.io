在 Mac 上不出现安全警告、最简单的安装方法：

  1. 按 Command（⌘）+ 空格键打开“聚焦搜索”，输入“终端”并按 Return 键。
  2. 点按下方的“复制”按钮，在“终端”窗口中点按一下，按 Command（⌘）+ V 粘贴，然后按 Return 键。
  3. 等待约一分钟，Chatda 会安装到“应用程序”文件夹并自动打开。
curl -fsSL https://github.com/barbellsoft/chatda-releases/releases/latest/download/install.sh | bash

如果 Windows 发出警告

Chatda 尚未进行代码签名，因此 Windows SmartScreen 可能会提示无法识别此应用。请在 PowerShell 中比对 SHA-256，确认文件与本站发布的一致：

Get-FileHash .\Chatda_x64-setup.exe -Algorithm SHA256

如果数值一致，请依次选择“更多信息”和“仍要运行”。Chatda 会连同驱动器索引服务一起为所有用户安装，因此安装和更新时会请求管理员批准。在 Mac 上如果提示无法打开 Chatda，请点按“完成”，然后打开“系统设置 > 隐私与安全性”，向下滚动并点按“仍要打开”，再重新打开 Chatda。
