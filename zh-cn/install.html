下载或安装被拦截时

我们的程序刚发布，还没有代码签名，所以 Windows 和 Edge 不认识它。请选择和你现在看到的窗口相似的一项。

  • Edge 不让保存“通常不会被下载”

先核对文件

跳过警告之前，请确认文件是我们发布的。每个下载页面都列出了 SHA-256。在 PowerShell 中运行下面的命令进行比较。

Get-FileHash .\<file> -Algorithm SHA256

删除

  1. 在右上角的下载面板中，把鼠标移到文件上，点击 ···（三个点）。
  2. 点击“保留”。
  3. 弹出的窗口中不要点“删除”，点击“显示更多”。
  4. 点击“仍然保留”，文件就会保存并可以打开。

被智能应用控制拦截

此应用的部分内容已被阻止

智能应用控制阻止了可能不安全的应用。

OK

这个窗口没有“仍要运行”的按钮。智能应用控制只允许已知的或已签名的程序，而我们的程序还没有签名。

  1. 打开 Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置。
  2. 选择“关”后程序就能运行。根据 Windows 版本，一旦关闭，可能要重置 Windows 才能再次打开，请慎重决定。
  3. 如果想保持开启，可以在另一台电脑上使用，或等待已签名的版本。

找不到下载的文件

  1. 按 Windows 键 + E 打开文件资源管理器。
  2. 点击左侧的“下载”。按修改日期排序时，新文件在最上面。
  3. 在 Edge 或 Chrome 中也可以按 Ctrl + J，然后点击“打开文件”或“在文件夹中显示”。
