Barbell Launcher 帮助

使用方法

  • 在任何地方按 Alt+Space，搜索框会在屏幕顶部打开。
  • 输入几个字后按 Enter。第一行已预先选中。
  • 用 ↑ 和 ↓ 选择其他行，按 Esc 关闭。

可输入的内容

  • 应用名称或其中一部分：“excel”，Visual Studio Code 可输入“vsc”。也支持韩文首辅音（ㅋㅋㅇ），以及在错误的韩/英输入模式下输入的文字。
  • 计算：“123+5”、“1,500,0003.3%”。按 Enter 复制结果。
  • 韩国办公计算：“부가세 110000”（增值税）、“3.3% 1000000”（代扣税）、“30평”（坪）、“1234500”（金额韩文写法）。
  • 日期：“today+30”、“+10bd”（工作日，不含韩国法定节假日）、“12/31”（倒计时，月/日）、“11/1~12/31”。
  • 网页：“g 搜索词”在 Google 搜索，“n 搜索词”在 Naver 搜索，“example.com”打开该网站。
  • 命令：lock（锁定）、sleep（睡眠）、settings（设置）、shutdown（关机）、restart（重启）、sign out（注销）。关机、重启和注销需要按两次 Enter。

快捷方式和常用语

  • 从托盘图标打开“管理快捷方式”。为网址、文件夹或文字设置关键字，然后输入该关键字即可。
  • 在网址中加入 {검색어}，即可用关键字后面输入的文字搜索。
  • 在常用语上按 Enter，会粘贴到之前输入的位置。
  • 导出为文件即可与团队共享快捷方式。除非选择，否则不包含常用语。
  • 常用语以未加密方式保存在此电脑上。请勿保存密码。

数据仅保存在此电脑上

  • 不会保存在搜索框中输入的内容。
  • Barbell Launcher 仅保存各应用的启动次数、设置和快捷方式。
  • 不会自行连接互联网。只有网页搜索结果会打开浏览器。

无法正常使用时

  • 如果按快捷键后搜索框没有打开，可能是其他程序占用了该快捷键。请在设置中选择其他按键。
  • 无法将常用语粘贴到以管理员身份运行的窗口中。内容已在剪贴板中，请按 Ctrl+V。
