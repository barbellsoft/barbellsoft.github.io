在浏览器中直接使用的免费工具

每个工具都在浏览器中运行。工具不会发送你输入的文字或文件。

  • 字数统计
    统计含空格和不含空格的字数、词数、行数和字节数。可删除多余的空格和空行，也可把从 PDF 复制时断开的行接起来。
  • 卖家利润计算器
    输入售价、商品成本、平台佣金和运费，即可算出到账金额、利润和利润率，还能算出达到目标利润率所需的售价。
  • 时薪年薪换算器
    把时薪换算成周薪、月薪和年薪，或把年薪换算回时薪。按每周工时和每年周数计算，不扣税。
  • 图片压缩
    把照片重新保存为 WebP 或 JPG，降低画质或尺寸来减小文件大小。工具在浏览器中运行，不会上传你的照片。
  • 图片压缩到指定大小
    按上传表单的大小限制（如 20KB、50KB、100KB）压缩照片，并在限制内找出最高画质。工具在浏览器中运行，不会发送你的照片。
  • PDF 合并与拆分
    把多个 PDF 文件合并为一个，或把选定的页面另存为新的 PDF。工具在浏览器中运行，不会上传你的文件。
  • 二维码生成器
    把链接或文字生成二维码，并保存为 PNG 或 SVG。工具在浏览器中运行，不会上传你输入的内容。
  • YAML ↔ JSON 转换器
    在浏览器中把 YAML 转成 JSON 或把 JSON 转成 YAML，并复制结果。YAML 出错时会显示行号。工具不会发送你输入的内容。
  • U 盘错误指南
    U 盘或 SD 卡出现“需要将其格式化”、RAW、写保护、0 字节、无法识别时分别意味着什么，应该先尝试什么，以及恢复软件在什么情况下能帮上忙、什么情况下帮不上。
  • U 盘容量计算器
    输入包装上的容量，看看 Windows 会显示多少。说明 1000 与 1024 的差别、文件系统占用的空间，以及如何检查驱动器是否虚标容量。
