U 盘容量计算器：为什么 64 GB 的驱动器显示 59.6 GB

驱动器厂商把 1 GB 算作 1,000,000,000 字节。Windows 以 1,073,741,824 字节（1024 × 1024 × 1024）为单位计算，却仍然称之为 GB。因此同一个驱动器在 Windows 中显示的数字更小，但并没有少任何东西。

包装上的 64 GB ≈ Windows 中的 59.6 GB

这是整个驱动器的大小。格式化后看到的可用空间还会再小一点，因为文件系统自己要占用一些空间。许多驱动器报告的容量也会比包装上的整数略小。

什么时候该怀疑虚标容量

  • Windows 显示的数字和本计算器差不多，但后来复制的文件丢失或打不开，尤其是大文件或驱动器快满时复制的文件。
  • 价格远低于同容量的其他驱动器。
  • 把驱动器装满后，文件夹名或文件名变成乱码。

虚标驱动器在 Windows 中显示的就是标称容量，所以本计算器发现不了。要检查，请使用写入并读取校验的工具：它用测试数据填满全部空闲空间，再读回来。如果后写入的数据替换了先写入的数据，这个驱动器就是虚标的。在 Windows 上，选择测试全部空闲空间时，ReviveUSB 的 “测试驱动器” 就会做这件事。
