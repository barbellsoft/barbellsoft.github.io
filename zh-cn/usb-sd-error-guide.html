U 盘和 SD 卡错误提示：含义与处理方法

请在下面找到你看到的提示或症状。每一项都列出常见原因、处理方法，以及我们的 Windows 恢复工具 ReviveUSB 能帮上忙和帮不上忙的地方。

无论出现什么提示，只要驱动器里有你需要的文件：不要格式化，不要运行 chkdsk，也不要往里面保存任何新东西。先复制整个驱动器，再从副本中恢复，最后才修复。

本页列出的提示

  • “使用驱动器中的光盘之前需要将其格式化”
  • 驱动器显示为 RAW
  • 0 字节或“无媒体”
  • 无法识别驱动器或没有盘符
  • “磁盘被写保护”
  • 恢复的文件打不开
  • 新买的便宜驱动器上文件消失或损坏

“使用驱动器中的光盘之前需要将其格式化”

常见原因
Windows 无法读取驱动器的文件系统。这通常发生在没有弹出就直接拔出、写入时断电，或者驱动器开始损坏之后。文件往往还在。
处理方法
点击取消。格式化可能会覆盖你想找回的文件。先把整个驱动器复制成镜像文件，再从镜像中把文件恢复到另一个驱动器，之后再格式化。
ReviveUSB 能帮上忙的地方
ReviveUSB 用 “备份为镜像” 把驱动器保存为镜像（只读取驱动器），然后从 NTFS、FAT32 和 exFAT 中连同名称和文件夹恢复现有文件和已删除的文件。名称无法读取时，它会根据内容找出照片、视频、PDF 和 ZIP 文件。之后要用的 “格式化” 和 “完全重建” 也在同一个窗口里。
帮不上忙的地方
如果数据已被覆盖，或者闪存芯片本身已经损坏，任何软件都无法找回。这时只能求助专业的数据恢复服务。

驱动器显示为 RAW

常见原因
文件资源管理器或磁盘管理中文件系统显示为 RAW：Windows 无法识别分区或文件系统。此时运行 chkdsk 会提示它不能用于 RAW 驱动器。
处理方法
chkdsk 无法修复没有可读文件系统的驱动器，所以不要反复尝试。先恢复文件，再重新创建分区和文件系统。
ReviveUSB 能帮上忙的地方
ReviveUSB 自己读取 NTFS、FAT32 和 exFAT，所以常常能读取 Windows 无法挂载的文件系统。请先对镜像尝试 “恢复文件（名称/路径）”。之后可以用 “完全重建” 重新创建分区和文件系统。
帮不上忙的地方
如果 ReviveUSB 也检测不到文件系统，“恢复文件（特征码）” 仍能找到照片、视频、PDF 和 ZIP 文件，但找不回它们的名称和文件夹。

0 字节或“无媒体”

常见原因
磁盘管理中列出了这个磁盘，但大小为 0 字节或显示“无媒体”。驱动器内部负责运行的小芯片（主控）没能加载固件，或者驱动器根本不提供存储空间。
处理方法
如果提示格式化，请取消。拔下驱动器再重新插上，并换个端口或电脑试试。如果它恢复了正常大小，不要写入任何东西，立即备份。
ReviveUSB 能帮上忙的地方
对于这样的驱动器，ReviveUSB 会显示 “诊断” 框，列出设备 ID、推测的主控和下一步操作，并每 5 秒重新检查一次。驱动器恢复后，先备份，再从镜像中恢复。
帮不上忙的地方
驱动器不提供存储空间时没有任何内容可读，所以备份、恢复和修复都会保持关闭。如果它一直没有恢复，只有数据恢复实验室才能尝试读取芯片。

无法识别驱动器或没有盘符

常见原因
文件资源管理器中什么都没出现，或者 Windows 提示无法识别 USB 设备。原因可能是端口、数据线、缺少盘符、分区损坏，或者驱动器正在损坏。
处理方法
把驱动器直接插到另一个端口上（最好是电脑背面的端口），并换一根数据线或换一台电脑试试。打开磁盘管理：如果磁盘显示了实际容量但没有盘符，说明驱动器有响应，损坏通常在分区或文件系统上。如果根本不出现，问题在连接或硬件上。
ReviveUSB 能帮上忙的地方
磁盘显示实际容量时，ReviveUSB 直接处理磁盘本身而不是盘符，所以即使没有盘符也能备份并从镜像中恢复。
帮不上忙的地方
如果在任何端口或电脑上，磁盘管理中都看不到这个磁盘，任何程序都无法访问它。

“磁盘被写保护”

常见原因
SD 卡和部分读卡器侧面有一个小的锁定开关。磁盘的只读属性或 Windows 策略也可能阻止写入。有些闪存驱动器在开始损坏时会把自己锁定为只读模式。
处理方法
先检查锁定开关。如果仍然无法写入，趁还能读取时把文件复制出来，然后更换驱动器。自己反复变成只读的驱动器，不应再放入新文件。
ReviveUSB 能帮上忙的地方
备份和恢复只读取驱动器，所以即使驱动器被写保护，也能把它复制成镜像，再从中恢复文件。
帮不上忙的地方
ReviveUSB 没有解除写保护的功能，它的修复功能需要写入驱动器。

恢复的文件打不开

常见原因
文件找回来了但已损坏：照片从中间开始变灰，视频无法播放。可能是数据已被覆盖、文件是分散存储的，或者驱动器有部分无法读取。
处理方法
从同一个镜像用另一种方法再恢复一次，并把结果保存到与正在恢复的驱动器不同的驱动器上。
ReviveUSB 能帮上忙的地方
ReviveUSB 有两种恢复方法：“恢复文件（名称/路径）” 读取文件系统，保留名称和文件夹；“恢复文件（特征码）” 根据内容找出文件。镜像只会被读取，所以在同一个镜像上两种都试也没有任何损失。
帮不上忙的地方
被覆盖的数据已经没有了，驱动器无法读取的部分在镜像中也是缺失的。

新买的便宜驱动器上文件消失或损坏

常见原因
有些驱动器报告的容量比实际容量大。超出实际容量复制的文件会丢失或覆盖之前的文件，而且往往没有任何错误提示。
处理方法
先用容量计算器确认标称容量在 Windows 中应该显示多少，再用写入并读取校验的工具测试整个驱动器，之后才放心使用。
ReviveUSB 能帮上忙的地方
修复之后，ReviveUSB 的 “测试驱动器” 会向全部空闲空间写入测试数据，绕过 Windows 缓存读回并比较。能发现虚标容量驱动器的是完整测试。
帮不上忙的地方
没有任何程序能把虚标容量的驱动器变成真的。不要在上面存放文件。
