下載或安裝被封鎖時

我們的程式剛推出，還沒有程式碼簽章，所以 Windows 和 Edge 不認得它。請選擇和您現在看到的視窗相似的一項。

  • Edge 無法保留檔案「不常被下載」
  • 出現藍色視窗「Windows 已保護您的電腦」
  • 被智慧型應用程式控制封鎖「可能不安全的應用程式」
  • 找不到下載的檔案開啟「下載」資料夾

先核對檔案

略過警告之前，請確認檔案是我們發布的。每個下載頁面都有 SHA-256。在 PowerShell 執行下面的命令來比對。

Get-FileHash .\<file> -Algorithm SHA256

刪除

  1. 在右上角的下載面板中，將滑鼠移到檔案上，按 ···（三個點）。
  2. 按「保留」。
  3. 跳出的視窗中不要按「刪除」，按「顯示更多」。
  4. 按「仍要保留」，檔案就會儲存並可以開啟。

仍要執行2不要執行

  1. 即使只有「不要執行」一個按鈕，也不要關閉視窗。按「其他資訊」。
  2. 程式沒有簽章，發行者會顯示為「未知的發行者」。按「仍要執行」。

回到清單

被智慧型應用程式控制封鎖

此應用程式的部分內容已被封鎖

智慧型應用程式控制已封鎖可能不安全的應用程式。

OK

這個視窗沒有「仍要執行」的按鈕。智慧型應用程式控制只允許已知或已簽章的程式，而我們的程式還沒有簽章。

  1. 開啟 Windows 安全性 → 應用程式與瀏覽器控制 → 智慧型應用程式控制設定。
  2. 選擇「關閉」後程式就能執行。依 Windows 版本，關閉後可能要重設 Windows 才能再開啟，請謹慎決定。
  3. 如果想保持開啟，可以在另一台電腦使用，或等待已簽章的版本。

回到清單

找不到下載的檔案

  1. 按 Windows 鍵 + E 開啟檔案總管。
  2. 按左側的「下載」。依修改日期排序時，新檔案在最上面。
  3. 在 Edge 或 Chrome 也可以按 Ctrl + J，再按「開啟檔案」或「在資料夾中顯示」。

回到清單
