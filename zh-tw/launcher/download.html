如果 Windows 跳出警告

Barbell Launcher 尚未進行程式碼簽章，因此 Windows SmartScreen 可能顯示無法辨識此應用程式。請在 PowerShell 中比對 SHA-256，確認下載的檔案與此處發佈的相同：

Get-FileHash .\BarbellLauncher.exe -Algorithm SHA256

如果值相同，請按「其他資訊」，再選擇「仍要執行」。Barbell Launcher 不需要系統管理員權限。
