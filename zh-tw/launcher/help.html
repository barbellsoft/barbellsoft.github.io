Barbell Launcher 說明

使用方式

  • 在任何地方按 Alt+Space，搜尋方塊會在畫面頂端開啟。
  • 輸入幾個字後按 Enter。第一行已預先選取。
  • 用 ↑ 和 ↓ 選擇其他行，按 Esc 關閉。

可輸入的內容

  • 應用程式名稱或其中一部分：「excel」，Visual Studio Code 可輸入「vsc」。也支援韓文初聲（ㅋㅋㅇ），以及在錯誤的韓/英輸入模式下輸入的文字。
  • 計算：「123+5」、「1,500,0003.3%」。按 Enter 複製結果。
  • 韓國辦公計算：「부가세 110000」（營業稅）、「3.3% 1000000」（扣繳）、「30평」（坪）、「1234500」（金額韓文寫法）。
  • 日期：「today+30」、「+10bd」（工作天，不含韓國國定假日）、「12/31」（倒數天數，月/日）、「11/1~12/31」。
  • 網頁：「g 搜尋字詞」在 Google 搜尋，「n 搜尋字詞」在 Naver 搜尋，「example.com」會開啟該網站。
  • 命令：lock（鎖定）、sleep（睡眠）、settings（設定）、shutdown（關機）、restart（重新啟動）、sign out（登出）。關機、重新啟動和登出需要按兩次 Enter。

捷徑與常用語

  • 從系統匣圖示開啟「管理捷徑」。為網址、資料夾或文字設定關鍵字，然後輸入該關鍵字即可。
  • 在網址中加入 {검색어}，即可用關鍵字後面輸入的文字搜尋。
  • 在常用語上按 Enter，會貼到先前輸入的位置。
  • 匯出成檔案即可與團隊共用捷徑。除非選擇，否則不包含常用語。
  • 常用語以未加密方式儲存在這台電腦。請勿儲存密碼。

資料只會儲存在這台電腦

  • 不會儲存在搜尋方塊中輸入的內容。
  • Barbell Launcher 只會儲存各應用程式的啟動次數、設定和捷徑。
  • 不會自行連線到網際網路。只有網頁搜尋結果會開啟瀏覽器。

無法正常運作時

  • 如果按快速鍵後搜尋方塊沒有開啟，可能是其他程式正在使用此快速鍵。請在設定中選擇其他按鍵。
  • 無法將常用語貼到以系統管理員身分執行的視窗。內容已在剪貼簿中，請按 Ctrl+V。
