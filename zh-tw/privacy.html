隱私權

本網站沒有 Cookie，網站本身不會收集個人資料。瀏覽次數由 GoatCounter 統計，它不使用 Cookie，也不儲存 IP 位址，只記錄瀏覽的頁面、來源網站、瀏覽器、螢幕尺寸和國家。

意見回饋表單中你寫的內容，以及你填寫時的電子郵件，會透過 FormSubmit 送到我們的信箱。只用於閱讀和回覆你的訊息。

你選擇的主題只儲存在你自己的瀏覽器（localStorage）中，不會傳出去。

贊助按鈕會連到第三方網站，這些網站有各自的隱私權政策。

這些程式不會把你的檔案或個人資訊傳送給我們或任何人。Chatda 會向 GitHub 檢查是否有新版本，並且只連線到你自己設定的網路資料夾或伺服器。ReviveUSB 只在電腦上的一個小設定檔裡儲存所選語言，「檢查更新」選單只是用瀏覽器開啟本網站。
