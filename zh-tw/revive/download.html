目前版本

系統需求
Windows 10 或 11（64 位元）。需要系統管理員權限。

下載

適用 Windows 10 / 11 的 64 位元 exe 8.3 MB

下載 ReviveUSB.exe

SHA-256 b9702a40ff4cfc7c14e3755a1ae10482b9a9b535ca294d0698637d81644b9f6d

如果 Windows 跳出警告

ReviveUSB 尚未進行程式碼簽署，因此 Windows SmartScreen 可能會顯示無法辨識此應用程式。請在 PowerShell 中比對 SHA-256，確認檔案就是這裡發布的版本：

Get-FileHash .\ReviveUSB.exe -Algorithm SHA256

如果數值相符，請選擇「其他資訊」，再選「仍要執行」。ReviveUSB 會直接讀取磁碟機，因此需要系統管理員權限。

新功能

0.2.11 · 2026-10-21

  • 檔案找回後，記錄會顯示一句簡短的感謝和 Buy Me a Coffee 連結。
  • 內建說明新增了說明選單中首頁和檢查更新的說明，贊助連結改為只有 Buy Me a Coffee。

0.2.10 · 2026-10-21

  • 說明選單新增「ReviveUSB 首頁」和「檢查更新」。
  • 贊助連結只保留 Buy Me a Coffee。Ko-fi 無法為本專案收款，已移除。

0.2.9 · 2026-10-21

  • 刪除後被新檔案覆寫的檔案，會另外提示其內容很可能不正確（FAT32、exFAT、NTFS）。以前 exFAT 和 NTFS 會不加警告地取出新檔案的內容。
  • 使用 4096 位元組磁區的大容量外接硬碟會依其磁區大小讀取，並能找到磁碟分割表和備份開機磁區。以前這類硬碟可能看起來完全無法讀取。
  • 已在真實 USB 隨身碟上測試：12,000 個檔案、4.6 GB 影片、片段化檔案，以及含表情符號、日文、阿拉伯文的名稱和超過 260 個字元的路徑都完整找回。

0.2.8 · 2026-10-20

  • 已在真實 USB 隨身碟上測試 11 種損壞。GPT 磁碟機開頭的磁碟分割表損壞時，即使磁碟區開頭也已損壞，也會讀取磁碟機尾端的備份副本。
  • 快速格式化後的 USB，依名稱和資料夾復原不再以「已儲存 1/1」（Windows 系統檔案）結束，而是說明找不到並建議使用簽章復原。測試中簽章復原找回了照片、文件和影片。
  • 簽章復原不再儲存 4 位元組的假 JPEG 檔案。

0.2.7 · 2026-10-20

  • 磁碟機開頭（開機磁區）損壞時，Windows 常會要求格式化。現在依名稱和資料夾復原會讀取 Windows 保留的備份副本，檔案能連同名稱一起找回。已在真實 USB 隨身碟上驗證。
  • 選了磁碟後按復原檔案，會先詢問要直接讀取該磁碟還是讀取磁碟映像檔。以前映像視窗中的「取消」代表讀取磁碟，不容易察覺。映像視窗預設顯示所有檔案。
  • 重新讀取清單後所選磁碟維持選取，磁碟機測試寫入的測試檔案不再被復原。
  • 從被 Windows 刪除過檔案的 FAT32 磁碟機依名稱和資料夾復原時，記錄會列出無法確定起始位置的檔案，請在使用前先開啟檢查。影片（MP4、MOV）也更常能找到正確位置。
  • ROM 模式磁碟機的診斷方塊不再推薦工廠工具，因為它們在我們測試的磁碟機上沒有成功。現在會說明 ReviveUSB 無法救回這類磁碟機，檔案重要時建議找資料救援公司，否則建議更換磁碟機。

0.2.6 · 2026-10-19

  • 修復前會先以唯讀方式檢查磁碟機。如果控制器看起來正在故障，就不修復，並提示先復原檔案再更換磁碟機，因為這種磁碟機可能在一次大量寫入中完全停止運作。測試磁碟機途中失去回應時也會這樣提示。
  • 控制器無法載入韌體（ROM 模式）或儲存空間為 0 的隨身碟會在磁碟清單中如實顯示。選取後會開啟診斷方塊，顯示裝置 ID、推測的控制器和下一步該做的事，並關閉無法使用的按鈕。
  • 新增說明選單：按 F1 即使沒有網路也能在瀏覽器中開啟說明書。贊助連結（Ko-fi、Buy Me a Coffee）在選單和視窗右上角。

0.2.5 · 2026-10-19

  • 新增「修復後」一列：測試磁碟機會寫入測試資料，從磁碟機（而非 Windows 快取）讀回後刪除，可找出遺失資料或虛標容量的磁碟機。
  • 寫回檔案會把復原的檔案連同資料夾放到修復後的磁碟機，並逐一讀回驗證。
  • 完全修復在隨身碟上不再因「磁碟已初始化」而中止。

0.2.4 · 2026-10-19

  • 「復原檔案（名稱/路徑）」現在不只復原已刪除的檔案，也會取出磁碟機上仍在的檔案，Windows 打不開的磁碟機也能救出檔案。已刪除的檔案另外放在 _deleted_files 資料夾。
  • 特徵碼復原也能找到 MP4、MOV、3GP、M4A、HEIC 影片和照片。
  • 損毀的 FAT32：比對檔案配置表的兩份副本，指向磁碟機以外的項目會被略過，不再產生假檔案。
  • 健康檢查不再把隨身碟的空計數顯示為磨損 0%、溫度 0°C，而是說明該磁碟機不提供健康資訊。

0.2.3 · 2026-10-18

  • 視窗右上角新增語言選單（11 種語言）。預設以英文啟動，並記住您的選擇。
  • 新圖示。
  • 在 FAT32 與 exFAT 磁碟上，也能救回整個被刪除的資料夾中的檔案。
  • 修正在 Windows 上測試時發現的多項穩定性問題。
