ReviveUSB 使用手冊

ReviveUSB 可以從故障的 USB 隨身碟或外接硬碟救回檔案，需要時還能修復磁碟機，讓它重新可用。所有操作都在同一個視窗中完成：選擇磁碟，再按下按鈕即可。請依照本手冊從頭到尾操作。

0. 快速入門

  1. 執行 ReviveUSB.exe，Windows 詢問時允許系統管理員權限。
  2. 按 🔄 重新整理，然後在磁碟清單中點選你的 USB 磁碟機。
  3. 按 備份為映像檔，把映像檔存到另一個空間足夠的磁碟機。
  4. 按 復原檔案(名稱/路徑)，選擇映像檔，再選擇健康磁碟機上的資料夾。如果什麼都沒救回，改用 復原檔案(簽章) 做一次同樣的步驟。
  5. 確定所有檔案都救回後，才用其中一個修復按鈕讓磁碟機重新可用。

最重要的一條規則：如果想救回資料，就不要把任何新東西存到損壞的磁碟機。先建立映像檔，再從映像檔復原。

如果你不需要資料，只想讓磁碟機恢復可用，可以跳過步驟 3 和 4。第 7 章會說明。

1. 這個程式能做什麼

磁碟機出現以下狀況時可以使用：

  • 不小心刪除了檔案。
  • 插上磁碟機時，Windows 顯示「您必須先將磁碟格式化，才能使用。」這表示檔案系統損毀，會顯示為 RAW。
  • 大容量磁碟機只顯示成一小塊 RAW，或沒有磁碟機代號，因為分割區已損毀。
  • 系統認得磁碟機，但看不到你的檔案。

它有兩個目標，一個工具就能處理。

目標 意思 按鈕
救回資料 復原已刪除或看不到的檔案 先按 備份為映像檔，再按其中一個 復原檔案 按鈕
救回磁碟機 重新格式化磁碟機，讓它能再次使用 檢查(chkdsk)、格式化、完整重建

順序是固定的：先救回資料，再修復磁碟機。先修復的話，資料就永遠消失了。

2. 開始前必讀的安全守則

真正毀掉復原機會的，是寫入損壞的磁碟機。執行這個程式沒有問題，因為備份與復原只會讀取磁碟機。

原因如下。刪除檔案時，資料本身通常仍留在磁碟機上，被移除的只是指向它的索引項目，這也是復原之所以可能的原因。如果之後你又把新檔案存到磁碟機，系統會把舊資料所在的位置視為可用空間，可能直接把新檔案寫在上面。一旦發生，舊資料就無法復原。

復原之前，請不要做以下任何一件事：

  • 把新檔案存到或複製到磁碟機。
  • 格式化磁碟機，不論是在 Windows 中，還是用修復按鈕。
  • Windows 提議掃描並修復磁碟機時按「是」。

以下按鈕是安全的，因為它們只會讀取：🔄 重新整理、健康檢查、備份為映像檔，以及兩個 復原檔案 按鈕。

損壞的 USB 磁碟機 --(唯讀)--> disk2.img（備份副本） --> recovered\（你的檔案）
   原始磁碟不受影響            在這份副本上作業            結果

4. 啟動程式

4.1 下載並檢查檔案

從下載頁面下載 ReviveUSB.exe。這個檔案尚未進行程式碼簽署，因此 Windows SmartScreen 或防毒軟體可能會發出警告。執行前，請確認檔案與下載頁面上顯示的 SHA-256 相符。在 PowerShell 中執行：

Get-FileHash .\ReviveUSB.exe -Algorithm SHA256

如果雜湊值相符而 SmartScreen 出現，請選擇 其他資訊，再選擇 仍要執行。

4.2 系統管理員權限

程式啟動時會要求系統管理員權限，因為讀取原始磁碟需要這個權限。請允許。之後視窗上方會顯示 系統管理員：開啟。如果顯示關閉，請按 以系統管理員身分重新啟動。

清單中只會列出 USB 磁碟。除非勾選 顯示內接磁碟（請小心），否則內接磁碟會保持隱藏。除非你很清楚自己在做什麼，否則請不要勾選。

工作執行期間，動作按鈕會變成灰色，進度列與記錄會持續更新。沒有停止按鈕。要停止備份，請關閉視窗；第 5 章會說明之後如何接續。

5. 五個步驟救回磁碟機

步驟 1. 選擇磁碟機

插上磁碟機並按 🔄 重新整理，在清單中點選你的磁碟機。記錄會確認你選了哪個磁碟，例如 已選擇磁碟 2：SanDisk Ultra。

請看 檔案系統 欄。RAW 表示檔案系統已損毀。

現在可以按 健康檢查。它會顯示磁碟機的狀態；如果磁碟機有提供，還會顯示 SMART 計數器，例如磨損度與無法更正的讀取錯誤。許多 USB 磁碟機不會傳遞 SMART 資料，這時記錄會加以說明。

步驟 2. 備份為映像檔

按 備份為映像檔。選擇映像檔的儲存位置，必須是另一個空間足夠的磁碟機。建議的檔名是 diskN.img，N 為磁碟編號。

原始磁碟機只會被讀取。壞區會被快速略過，所以複製會持續進行而不會卡住。進度列會顯示百分比與已複製的量。

如果有區域無法讀取，程式會詢問是否要逐磁區重試。重試可以救回更多資料，但在嚴重損壞的磁碟機上可能需要很長時間。如果在重試期間關閉視窗，之後再次備份到同一個檔案，就會接著重試。對已完成的映像檔再次備份時，絕不會重新讀取整個磁碟機，只會詢問是否重試無法讀取的區域。若要重新開始，請選擇新的檔名。

如果你選的位置在要復原的磁碟機上，程式會拒絕並要求你換一個磁碟機。存在那裡可能會覆寫你想救回的檔案。

你可以隨時關閉視窗來停止。進度每兩秒儲存一次。若要繼續，請重新啟動程式，選擇同一個磁碟機，按 備份為映像檔，再選擇同一個檔案。如果 Windows 詢問是否要取代，請按「是」：記錄會顯示 繼續建立映像檔，並從中斷處繼續複製。程式會檢查是否為同一個磁碟機。如果檔案屬於其他磁碟機，或磁碟機回報的大小已經不同，程式會停止，而不會混用或覆寫先前的副本；這時請選擇新的檔名。

步驟 3. 從映像檔復原檔案

有兩個按鈕。請先試 復原檔案(名稱/路徑)，如果什麼都沒找到，再用 復原檔案(簽章)。

  1. 按下按鈕。
  2. 選擇映像檔（.img）。
  3. 選擇存放復原檔案的資料夾，必須在健康的磁碟機上。位於要復原之磁碟機上的資料夾會被拒絕。如果磁碟機有多個分割區，各分割區的檔案會放進各自的子資料夾，例如 volume2_exfat。

名稱/路徑方式會複製它能找到的所有檔案，不只是已刪除的檔案。Windows 顯示磁碟機「無法存取」或要求格式化時，正適合用這種方式：檔案通常都還在，而且會連同名稱一起救回。如果同時找到現有檔案和已刪除檔案，已刪除的檔案會放進另外的 _deleted_files 資料夾，舊的副本就不會和現有檔案放在一起。儲存用的資料夾需要和這些檔案一樣多的可用空間；空間不足時，開始前記錄會先發出警告。如果是在 Windows 中刪除過檔案的 FAT32 磁碟機，記錄裡可能會列出「內容可能不對」的檔案：Windows 抹掉了它們起始位置的一部分，而 .bin 這類沒有檔案簽章的格式無法判斷正確位置。使用前請先開啟檢查。

復原檔案(名稱/路徑) 復原檔案(簽章)
救回的內容 檔案名稱、資料夾路徑與內容 只有內容，以流水號命名，例如 jpg_00001_@...
適用對象 NTFS、FAT32 與 exFAT 任何磁碟機，即使檔案系統已經不見
最適合的情況 檔案系統仍可讀取，即使 Windows 打不開磁碟機 檔案系統本身已毀損
順序 先試這個 第一種找不到時使用

即使磁碟機顯示為 RAW，也請先試試名稱/路徑方式。只要 Windows 無法掛接檔案系統，即使其中只有一個值出錯，也會顯示為 RAW；而本程式往往仍能讀取，並連同名稱一起救回檔案。如果顯示無法偵測檔案系統，或什麼都沒找到，再改用簽章方式。

簽章方式可找出 JPEG、PNG、GIF、BMP、PDF 與 ZIP 檔，以及 MP4、MOV、3GP、M4A 與 HEIC 檔（手機與行車記錄器的影片、iPhone 照片）。docx、xlsx、pptx 等 Office 檔案內部其實是 ZIP 檔，所以會以 .zip 名稱救回；請把副檔名改回正確的名稱。結尾沒有寫入的影片（錄影中途中斷，或磁碟機遺失了資料）會儲存到讀得到的地方為止，但少了結尾，多數播放器無法播放。

如果在清單中選了磁碟，程式會先詢問是否直接讀取該磁碟。按 否 選擇映像檔，按 是 直接讀取磁碟。直接讀取磁碟需要系統管理員權限，而且對故障中的磁碟機風險較高，所以使用映像檔是比較好的選擇。

步驟 4. 修復磁碟機（僅在復原完成後）

選擇磁碟機，使用其中一個修復按鈕。要選哪一個，請看第 7 章。格式化 與 完整重建 會清除資料，所以程式會要求你準確輸入確認文字，例如 FORMAT E。使用前請確定所有檔案都已救回。

修復按鈕（檢查(chkdsk)、格式化、完整重建）在寫入磁碟機之前，會先以唯讀方式檢查磁碟機。如果出現控制器正在故障的跡象，就不進行修復，並在記錄中說明原因。這些跡象是：磁碟機不回應讀取或容量顯示為 0，或者磁碟機有部分無法讀取。如果是 FAT32 磁碟機，還會檢查檔案系統記錄的容量是否大於磁碟機實際容量、檔案配置表（FAT）的兩份副本是否在許多位置不一致、應該存有檔案的位置是否有一半以上讀出來是空值。此時無法強制修復。修復會大量寫入，而正在故障的磁碟機可能在大量寫入途中完全停止運作。請先用步驟 2、3 取回檔案，再更換磁碟機。只因無法辨識檔案系統而顯示為 RAW 的磁碟機不會被擋下。不取回資料直接修復時（第 7 章）也會做同樣的檢查。

步驟 5. 把檔案放回去（修復之後）

完整的順序是：救回資料，把救回的檔案保存在電腦上，修復磁碟機，再把檔案放回修復好的磁碟機。這個步驟就是最後一環。在你重新信任這台磁碟機之前，它也會檢查磁碟機是否真的能保存資料。

格式化 或 完整重建 完成後，記錄會提示：按 🔄 重新整理，接著按 測試磁碟機，再按 寫回檔案。這兩個按鈕位於 修復後： 這一列，會針對所選磁碟的磁碟機代號操作，不需要系統管理員權限。

  1. 按 🔄 重新整理，選擇修復好的磁碟機。磁碟機代號可能已經改變。
  2. 按 測試磁碟機。選「是」會測試全部可用空間，選「否」則快速測試 1 GB（選「取消」則不做任何事）。完整測試很慢，但只有它能找出虛報容量的磁碟機。程式會把測試資料寫入磁碟機上的 _revive_test 資料夾，不經過 Windows 快取讀回並比對，然後刪除該資料夾。先前中斷的測試留下的資料夾也會一併刪除。如果磁碟機寫滿了，寫入就在那裡停止，並檢查已寫入的資料。
  3. 在記錄中查看結果。通過時，記錄會顯示寫入並讀回了多少資料，沒有錯誤。失敗時，記錄會顯示有多少資料沒能正確讀回；請更換這台磁碟機。如果後寫入的資料出現在先寫入資料的位置，記錄會說明這台磁碟機實際上大約只能存放多少，比它宣稱的少。這是虛報容量的磁碟機，不要把檔案放上去。如果測試途中磁碟機停止回應，記錄會說明處理多少資料後停止，並提示這台磁碟機無法可靠地保存資料。不要把檔案放上去，請更換磁碟機。
  4. 按 寫回檔案，選擇電腦上存放救回檔案的資料夾。程式不接受位於同一台磁碟機上的資料夾。如果磁碟機的可用空間不足，程式會在寫入任何內容之前告知。它會依原本的資料夾結構複製所有內容，但最上層的 System Volume Information 與 $RECYCLE.BIN 資料夾除外，Windows 會自行重新建立它們。
  5. 複製完成後，程式同樣不經過快取，從磁碟機讀回每個檔案，並將其 SHA-256 與原始檔案比對。如果全部相符，記錄會說明。如果有檔案讀回的內容不同，記錄會列出這些檔案，並說明這台磁碟機無法可靠地保存資料。不要在這台磁碟機上存放重要檔案。

即使複製成功，也請把救回的檔案留在電腦上，這樣你仍有第二份副本。

測試磁碟機 在全部可用空間或 1 GB 寫入測試資料，不經過 Windows 快取讀回並比對，然後刪除。可找出會遺失資料或虛報容量的磁碟機 寫入測試資料，之後刪除 否
寫回檔案 把電腦上資料夾中的救回檔案依相同的資料夾結構複製到磁碟機，然後逐一讀回並比對 SHA-256 寫入檔案 否

完整重建 會自動選擇分割樣式：2 TB 以下的磁碟機用 MBR，更大的用 GPT。記錄會顯示選了哪一種。

7. 不需要資料時修復磁碟機

如果你不需要裡面的檔案，只想讓故障的 USB 磁碟機或外接硬碟恢復可用，可以跳過備份與復原步驟，直接修復。

7.1 先診斷

按 🔄 重新整理，選擇磁碟機，查看清單與記錄。以一台 WD 外接硬碟的實際例子來說：清單顯示 3.6 TB、狀態 Healthy/Online，而且只有一塊沒有磁碟機代號的 200 MB RAW 區塊。

解讀方式：狀態為 Healthy/Online 表示硬體運作正常，只有分割結構損壞，這通常可以用軟體修復。如果大容量磁碟機只顯示一小塊 RAW，或沒有磁碟機代號，表示主要分割區已經不見了。

7.2 選擇修復方式（由輕到重）

症狀 按鈕 功能
有磁碟機代號，但檔案損毀或出現讀取錯誤 檢查(chkdsk) 修正檔案系統錯誤並保留資料
有磁碟機代號，想要清空 格式化 只重新格式化該磁碟區
RAW、沒有磁碟機代號、分割區損毀 完整重建 清除整個磁碟並重新建立。這是最常用的解法

檢查(chkdsk) 與 格式化 需要磁碟機代號。如果磁碟機沒有代號，程式會提示改用 完整重建。chkdsk 也無法修復 RAW 磁碟機，因為已經沒有可修復的檔案系統。

7.3 救活 RAW 磁碟機

這是最常見的情況。選擇磁碟機，按 完整重建，出現提示時輸入 ERASE DISK 2（換成你的磁碟編號）。通常只需要幾秒到一分鐘。完成後，磁碟機會取得新的磁碟機代號。把檔案放上去之前，請按 🔄 重新整理，選擇磁碟機，然後執行 測試磁碟機。結果怎麼看以及如何把檔案放回去，請看第 5 章的步驟 5。

新的檔案系統是 NTFS，Windows 可以讀寫。如果需要在 Mac 或其他裝置上使用，之後再用該裝置或 Windows 內建的格式化對話方塊重新格式化即可。

7.4 清理

如果先前建立的映像檔已經不需要，請刪除映像檔以及旁邊的進度檔，例如 disk2.img 與 disk2.img.state.json。

7.5 如果修復失敗

  1. 拔下磁碟機再插回去，按 🔄 重新整理，然後再試一次。Windows 可能正鎖定該磁碟。
  2. 關閉其他可能正在使用磁碟機的程式，例如防毒軟體或檔案總管的預覽。
  3. 如果仍然失敗、狀態一直是 Unhealthy，或磁碟機反覆出現又消失，硬體很可能正在故障。軟體無法修好這種情況，請考慮更換磁碟機。

7.6 降低再次故障的風險

沒有任何軟體能保證磁碟機不會再壞。健康檢查 會讀取磁碟機自己記錄的計數器：重新配置的磁區、讀取錯誤與磨損度。出現無法更正的讀取或寫入錯誤，或磨損度偏高，代表再次故障的風險高，建議更換。

許多 USB 外接盒因為橋接晶片的限制，不會傳遞 SMART 資料。這時健康檢查會顯示磁碟機不提供 SMART 資料。CrystalDiskInfo 等專用工具或許仍能讀取。

請記住以下幾個原則：

  • 軟體只能避開已經損壞的記憶單元，無法延長磁碟機的實體壽命。
  • 不要把重要資料的唯一一份副本放在曾經故障過的磁碟機上。務必另外備份一份。
  • 如果重建後不久磁碟機又變成 RAW，或一直斷線，請更換。

8. 疑難排解

磁碟清單是空的

記錄顯示 找不到磁碟。請確認磁碟機已插好，並且在 Windows 的磁碟管理中看得到，然後再按一次 🔄 重新整理。如果磁碟機不是 USB 磁碟機，請勾選 顯示內接磁碟（請小心）。

清單中顯示「韌體故障（ROM 模式）」或「無儲存空間（0）」

隨身碟的控制器沒能載入韌體，或磁碟機不提供儲存空間。Windows 通常會把這種磁碟機顯示為「沒有媒體」或 0 位元組的磁碟，也可能詢問是否要格式化；這時請選擇取消。在清單中選擇這台磁碟機後，磁碟清單下方會開啟 診斷 方塊，顯示裝置 ID、推測的控制器和下一步該做的事。這種狀態下沒有可讀寫的內容，因此備份、復原和修復按鈕會被關閉。

  1. 拔下磁碟機再重新插上。方塊每 5 秒會自動重新檢查（也可以按 重新檢查）。如果它以原本的名稱回來，不要寫入任何東西，先備份。方塊會保持開啟並告訴你它已恢復，同時顯示 備份為映像檔 和 測試磁碟機（全部可用空間） 按鈕。大量寫入可能讓它再次停止，所以在這個磁碟機通過 測試磁碟機（全部可用空間）之前，即使關閉方塊，修復和 寫回檔案 也維持關閉。
  2. 如果重新插上也回不來，ReviveUSB 就無法救回它，也讀不出其中的檔案。如果檔案很重要，資料救援公司或許能直接讀取記憶體晶片；否則請更換磁碟機。ReviveUSB 不推薦工廠工具（量產工具）：它們在我們測試的磁碟機上沒有成功，而且不是官方發布的。
  3. 如果步驟 1 中它回來了，而你還想繼續使用，請先備份，再用 測試磁碟機 測試全部可用空間。測試無錯誤通過後，該磁碟機的修復和 寫回檔案 會開啟，方塊也會自動關閉。1 GB 快速測試不會開啟它們。

複製診斷 會複製方塊的內容，求助時可以貼上。按 × 關閉方塊。

有些裝置會以灰色顯示「空（0）」。這表示程式不認識的裝置回報沒有儲存空間，沒插卡的讀卡機插槽通常就是這樣。這不是故障，插入記憶卡即可。如果隨身碟這樣顯示，請拔下後重新插入。由於沒有可讀取的內容，此時備份、復原和修復按鈕都會關閉。

備份非常慢（例如預估要 100 小時以上）

程式已經會略過壞區，所以變慢通常是磁碟機或連線造成的。如果從頭到尾速度都很低（每秒幾百 KB），請依序嘗試：

  1. 把磁碟機直接插在電腦背面的 USB 3.0 連接埠（藍色）。避免使用集線器與延長線。
  2. 更換傳輸線。
  3. 改用另一台電腦。

要換連接埠時，請關閉 ReviveUSB，移動磁碟機，再次備份到同一個映像檔。它會從中斷處繼續。

磁碟機顯示為 RAW

Windows 無法讀取檔案系統，但本程式往往仍讀得到。請先備份為映像檔，再先試試 復原檔案(名稱/路徑)；如果什麼都沒找到，再使用 復原檔案(簽章)。復原完成後，再用 完整重建 讓磁碟機恢復可用。

「無法偵測檔案系統」

名稱/路徑方式只認得 NTFS、FAT32 與 exFAT，而且需要能讀取檔案系統索引。請改用 復原檔案(簽章)。（訊息中可能會出現 carve 或 --fs 等命令列名稱；在視窗中，簽章按鈕就是同一個功能。）

「此操作需要系統管理員權限」

按 是，以系統管理員身分重新啟動程式；或關閉程式後重新執行，並允許 Windows 的提示。

復原的檔案打不開

檔案可能原本就分散存放，所以只救回了前半段。兩個復原按鈕都試試看。磁碟機上無法讀取的部分，映像檔中也不會有，存放在那裡的檔案無法完整救回。

9. 常見問題

Q. 我想救回 USB 磁碟機，「不要寫入」是什麼意思？ A. 意思是不要把新資料存到磁碟機。執行這個程式沒有問題，因為備份與復原只會讀取。請參閱第 2 章。

Q. 這會損壞原始磁碟機嗎？ A. 備份與復原都是唯讀的。只有修復按鈕會變更原始磁碟機，而且會先要求確認。

Q. 檔案名稱救得回來嗎？ A. 復原檔案(名稱/路徑) 會還原名稱與資料夾。復原檔案(簽章) 只還原內容，並以流水號為檔案命名。

Q. 我的磁碟機有 114 GB，一定要整個做成映像檔嗎？ A. 完整備份是最安全的做法。如果時間不夠，可以中途關閉程式，對目前已有的映像檔執行 復原檔案(簽章)；它會從已複製的部分救回檔案。

Q. 有沒有無法復原的情況？ A. 有。如果資料已被覆寫，或快閃記憶體晶片本身已經損壞，軟體就無能為力。這時請找專業的資料救援服務。

名詞 意思

RAW 檔案系統索引已損壞，Windows 無法讀取磁碟機

磁區與叢集 最小的儲存單位（通常為 512 位元組），以及由多個磁區組成的群組
