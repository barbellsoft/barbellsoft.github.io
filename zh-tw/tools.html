在瀏覽器中直接使用的免費工具

每個工具都在瀏覽器中執行。工具不會傳送你輸入的文字或檔案。

  • 字數計算
    計算含空格與不含空格的字數、字詞數、行數和位元組數。可刪除多餘的空格和空行，也能把從 PDF 複製時斷開的行接起來。
  • 賣家利潤計算器
    輸入售價、商品成本、平台手續費和運費，就能算出撥款金額、利潤和利潤率，也能算出達到目標利潤率所需的售價。
  • 時薪年薪換算器
    把時薪換算成週薪、月薪和年薪，或把年薪換算回時薪。依每週工時和每年週數計算，不扣稅。
  • 圖片壓縮
    把照片重新儲存成 WebP 或 JPG，降低畫質或尺寸來縮小檔案。工具在瀏覽器中執行，不會上傳你的照片。
  • 圖片壓縮到指定大小
    依上傳表單的大小限制（如 20KB、50KB、100KB）壓縮照片，並在限制內找出最高畫質。工具在瀏覽器中執行，不會傳送你的照片。
  • PDF 合併與分割
    把多個 PDF 檔案合併成一個，或把選取的頁面另存成新的 PDF。工具在瀏覽器中執行，不會上傳你的檔案。
  • QR 碼產生器
    把連結或文字轉成 QR 碼，並儲存為 PNG 或 SVG。工具在瀏覽器中執行，不會上傳你輸入的內容。
  • YAML ↔ JSON 轉換器
    在瀏覽器中把 YAML 轉成 JSON 或把 JSON 轉成 YAML，並複製結果。YAML 出錯時會顯示行號。工具不會傳送你輸入的內容。
  • USB 錯誤指南
    USB 隨身碟或 SD 卡出現「必須先將磁碟格式化」、RAW、防寫保護、0 位元組、無法辨識時分別代表什麼，應該先試什麼，以及復原軟體在什麼情況下幫得上忙、什麼情況下幫不上。
  • USB 容量計算器
    輸入包裝上的容量，看看 Windows 會顯示多少。說明 1000 與 1024 的差別、檔案系統佔用的空間，以及如何檢查磁碟機是否灌水容量。
