USB 容量計算器：為什麼 64 GB 的磁碟機顯示 59.6 GB

磁碟機廠商把 1 GB 算成 1,000,000,000 位元組。Windows 以 1,073,741,824 位元組（1024 × 1024 × 1024）為單位計算，卻仍然稱為 GB。因此同一台磁碟機在 Windows 中顯示的數字比較小，但並沒有少任何東西。

包裝上的 64 GB ≈ Windows 中的 59.6 GB

這是整台磁碟機的大小。格式化後看到的可用空間還會再小一點，因為檔案系統自己要佔用一些空間。許多磁碟機回報的容量也會比包裝上的整數略小。

什麼時候該懷疑灌水容量

  • Windows 顯示的數字和本計算器差不多，但之後複製的檔案遺失或打不開，尤其是大檔案或磁碟機快滿時複製的檔案。
  • 價格遠低於同容量的其他磁碟機。
  • 把磁碟機裝滿後，資料夾名稱或檔案名稱變成亂碼。

灌水磁碟機在 Windows 中顯示的就是標示容量，所以本計算器抓不出來。要檢查，請使用寫入並讀取驗證的工具：它會用測試資料填滿全部可用空間，再讀回來。如果後寫入的資料取代了先寫入的資料，這台磁碟機就是灌水的。在 Windows 上，選擇測試全部可用空間時，ReviveUSB 的「測試磁碟機」就會做這件事。
