USB 隨身碟和 SD 卡錯誤訊息：代表什麼、該怎麼做

請在下面找到你看到的訊息或症狀。每一項都列出常見原因、處理方法，以及我們的免費 Windows 復原工具 ReviveUSB 幫得上忙和幫不上忙的地方。

無論出現什麼訊息，只要磁碟機裡有你需要的檔案：不要格式化，不要執行 chkdsk，也不要往裡面儲存任何新東西。先複製整個磁碟機，再從副本復原，最後才修復。

本頁列出的訊息

  • 「您必須先將磁碟格式化，才能使用」
  • 磁碟機顯示為 RAW
  • 0 位元組或「沒有媒體」
  • 無法辨識磁碟機或沒有磁碟機代號
  • 「磁碟有防寫保護」
  • 復原的檔案打不開
  • 新買的便宜磁碟機上檔案消失或損壞

「您必須先將磁碟格式化，才能使用」

常見原因
Windows 無法讀取磁碟機的檔案系統。這通常發生在沒有退出就直接拔除、寫入時斷電，或磁碟機開始故障之後。檔案往往還在。
處理方法
按「取消」。格式化可能會覆寫你想找回的檔案。先把整個磁碟機複製成映像檔，再從映像檔把檔案復原到另一台磁碟機，之後才格式化。
ReviveUSB 幫得上忙的地方
ReviveUSB 用「備份為映像檔」把磁碟機儲存成映像檔（只讀取磁碟機），然後從 NTFS、FAT32 和 exFAT 連同名稱和資料夾復原現有檔案和已刪除的檔案。名稱無法讀取時，它會依內容找出相片、影片、PDF 和 ZIP 檔案。之後要用的「格式化」和「完整重建」也在同一個視窗裡。
幫不上忙的地方
如果資料已被覆寫，或快閃記憶體晶片本身已經損壞，任何軟體都無法找回。這時只能求助專業的資料救援服務。

磁碟機顯示為 RAW

常見原因
檔案總管或磁碟管理中檔案系統顯示為 RAW：Windows 無法辨識磁碟分割或檔案系統。這時執行 chkdsk 會說它不能用於 RAW 磁碟機。
處理方法
chkdsk 無法修復沒有可讀檔案系統的磁碟機，所以不要一再重試。先復原檔案，再重新建立磁碟分割和檔案系統。
ReviveUSB 幫得上忙的地方
ReviveUSB 自己讀取 NTFS、FAT32 和 exFAT，所以常常能讀取 Windows 無法掛載的檔案系統。請先對映像檔試試「復原檔案(名稱/路徑)」。之後可以用「完整重建」重新建立磁碟分割和檔案系統。
幫不上忙的地方
如果 ReviveUSB 也偵測不到檔案系統，「復原檔案(簽章)」仍能找到相片、影片、PDF 和 ZIP 檔案，但找不回它們的名稱和資料夾。

0 位元組或「沒有媒體」

常見原因
磁碟管理中列出了這個磁碟，但大小為 0 位元組或顯示「沒有媒體」。磁碟機內部負責運作的小晶片（控制器）沒能載入韌體，或者磁碟機根本不提供儲存空間。
處理方法
如果要求格式化，請取消。拔下磁碟機再重新插上，並換個連接埠或電腦試試。如果它恢復了正常大小，不要寫入任何東西，立刻備份。
ReviveUSB 幫得上忙的地方
對於這樣的磁碟機，ReviveUSB 會顯示「診斷」方塊，列出裝置 ID、推測的控制器和下一步該做的事，並每 5 秒重新檢查一次。磁碟機恢復後，先備份，再從映像檔復原。
幫不上忙的地方
磁碟機不提供儲存空間時沒有任何內容可讀，所以備份、復原和修復都會維持關閉。如果它一直沒有恢復，只有資料救援實驗室能嘗試讀取晶片。

無法辨識磁碟機或沒有磁碟機代號

常見原因
檔案總管裡什麼都沒出現，或 Windows 顯示無法辨識 USB 裝置。原因可能是連接埠、傳輸線、缺少磁碟機代號、磁碟分割損壞，或磁碟機正在故障。
處理方法
把磁碟機直接插到另一個連接埠（最好是電腦背面的連接埠），並換一條傳輸線或換一台電腦試試。開啟磁碟管理：如果磁碟顯示了實際容量但沒有磁碟機代號，表示磁碟機有回應，損壞通常在磁碟分割或檔案系統。如果完全沒出現，問題在連接或硬體。
ReviveUSB 幫得上忙的地方
磁碟顯示實際容量時，ReviveUSB 直接處理磁碟本身而不是磁碟機代號，所以即使沒有代號也能備份並從映像檔復原。
幫不上忙的地方
如果在任何連接埠或電腦上，磁碟管理中都看不到這個磁碟，任何程式都無法存取它。

「磁碟有防寫保護」

常見原因
SD 卡和部分轉接卡側面有一個小的鎖定開關。磁碟的唯讀屬性或 Windows 原則也可能阻止寫入。有些隨身碟在開始故障時會把自己鎖定成唯讀模式。
處理方法
先檢查鎖定開關。如果仍然無法寫入，趁還能讀取時把檔案複製出來，然後更換磁碟機。會自己反覆變成唯讀的磁碟機，不應該再放新檔案。
ReviveUSB 幫得上忙的地方
備份和復原只讀取磁碟機，所以即使磁碟機有防寫保護，也能把它複製成映像檔，再從中復原檔案。
幫不上忙的地方
ReviveUSB 沒有解除防寫保護的功能，它的修復功能需要寫入磁碟機。

復原的檔案打不開

常見原因
檔案找回來了但已損壞：相片從中間開始變灰，影片無法播放。可能是資料已被覆寫、檔案是分散儲存的，或磁碟機有部分無法讀取。
處理方法
從同一個映像檔用另一種方法再復原一次，並把結果儲存到與正在復原的磁碟機不同的磁碟機上。
ReviveUSB 幫得上忙的地方
ReviveUSB 有兩種復原方法：「復原檔案(名稱/路徑)」讀取檔案系統，保留名稱和資料夾；「復原檔案(簽章)」依內容找出檔案。映像檔只會被讀取，所以在同一個映像檔上兩種都試也不會有任何損失。
幫不上忙的地方
被覆寫的資料已經沒有了，磁碟機無法讀取的部分在映像檔中也是缺少的。

新買的便宜磁碟機上檔案消失或損壞

常見原因
有些磁碟機回報的容量比實際容量大。超出實際容量複製的檔案會遺失或覆寫之前的檔案，而且往往沒有任何錯誤訊息。
處理方法
先用容量計算器確認標示容量在 Windows 中應該顯示多少，再用寫入並讀取驗證的工具測試整個磁碟機，之後才放心使用。
ReviveUSB 幫得上忙的地方
修復之後，ReviveUSB 的「測試磁碟機」會在全部可用空間寫入測試資料，略過 Windows 快取讀回並比較。能找出灌水容量磁碟機的是完整測試。
幫不上忙的地方
沒有任何程式能把灌水容量的磁碟機變成真的。不要在上面存放檔案。
